# KLineChart Script

Deterministic, data-source- and render-agnostic time-series script engine for
KLineChartQuant. Scripts are written in plain TypeScript, so they carry the type
system, debugger, and npm ecosystem with them.

> Scaffold placeholder. The public contracts and implementation are not in place
> yet, so the package exports nothing.

| Command | What |
| --- | --- |
| `pnpm build` | TypeScript declaration + JS emit to `dist/` |
| `pnpm test` | Vitest, Node environment |
| `pnpm lint:publish` | `publint --strict` package check |
