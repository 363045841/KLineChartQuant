# history — 图元事务历史

`DrawingHistory` 每张图表实例一份，由 `DrawingCommands` 持有。所有已确认图元写入在命令层统一经过 `run`；只有文档真的改变才记一条记录。批量修改和一次指针拖拽各占一条；预览、悬停和选择不记历史。

每条记录保存受影响图元的完整前后模型、前后 ID 顺序以及选中集合。回放通过文档的专用恢复入口一次提交，不再生成图元/锚点 ID，也不重新执行锁定与交易日解析。新编辑清空 redo，最多保留 100 条；同步外部权威文档或检测到底层绕行写入时清空历史。

`types.ts` 是文档与历史之间的结构契约；`impl/DrawingHistory.ts` 不依赖 `model/impl/`。图元之外的 Pane 删除和布局导入会重设历史基线；工作区切换不会。Controller 暴露撤回、重做和可用状态供界面使用。
