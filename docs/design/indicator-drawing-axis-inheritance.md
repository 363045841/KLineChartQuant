# 指标绘图继承所属指标的轴

指标输出的 drawings 是派生图元，图元 ID 只标识绘图内容，不声明或注册轴。
指标实例已经具有轴绑定，输出包装中的 ownerId 是图元使用该坐标系的依据。

此前范围收集和几何投影均按图元 ID 查询对象轴，而运行时轴声明不包含指标图元，
导致 PVP、SVP 等输出绘图的指标在渲染时抛出未绑定轴异常。

范围收集和几何投影统一使用 resolveDrawingRenderAxis：指标图元通过 ownerId
查询指标轴；用户绘图直接取所在窗格的主右轴，也就是第一条右轴。绘图图元不添加
逐图元绑定。仅有绘图的窗格提供一条共享轴。owner 在当前 Pane 中无绑定时明确
报错，不使用图元 ID 或主轴代替，避免多轴场景下使用错误坐标。

窗格按量纲合并行情序列和指标的轴声明，每条轴统一持有刻度格式和可见性，
并记录使用该轴的数据对象。轴列、刻度和十字线使用合并后的窗格轴配置。

回归验证使用真实 Pane 的两条不同范围的轴，确认没有图元绑定时仍使用指标轴
生成正确的屏幕坐标，并验证缺失 owner 不会借用其他对象的轴。
