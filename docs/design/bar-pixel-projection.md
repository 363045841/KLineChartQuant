# K 线与指标柱状图的物理像素投影

K 线实体、影线、MACD 和 VOL 共用矩形绘制入口。业务层准备双精度世界坐标；绘制入口投影后才转换为 Float32 整数屏幕物理像素，避免非整数 DPR 在 Float32 中再次损失精度。

每帧将滚动量转换为一个整数物理像素偏移。世界左边界按物理像素还原后减去该偏移，宽度单独取整；右边界由左边界加宽度得到。禁止分别取整左右边界，也禁止在 Float32 世界坐标中相减。整数槽距因此保持固定柱间距。

K 线实体和影线使用同一像素列，宽度保持同奇偶，左边界由像素列和半宽派生，确保几何中心重合。粗影线仍采用两物理像素。

Canvas2D、WebGL 和 WebGPU 消费同一屏幕批次。Canvas2D 在调用 fillRect 时除以 DPR；GPU 用 DrawInstancesParams.physicalPixels 契约跳过二次投影和 DPR 缩放。原有其他世界坐标原语仍由后端投影。后端不可用时只在公共入口选择一次 Canvas2D，业务层不再重复实现矩形回退。

矩形随滚动以一个物理像素为步长移动，保留惯性平移与连续缩放状态。测试覆盖半像素两侧、DPR 1/1.25/1.5/2/3、大世界坐标、粗细影线和正负零值柱。
