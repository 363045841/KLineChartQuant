# TA 增量滑动窗口

`ta.*` 是脚本唯一的技术分析入口。实现位于 script 包的 VM 运行时，公开类型位于 `Library/types.ts`；脚本不维护窗口或累计器。

此前 SMA、SUM、WMA、VWMA、最高/最低值和标准差都逐根扫描完整窗口，复杂度为 O(N × L)。VWMA 每个窗口元素还读取价格和成交量，每次读取跨越 QuickJS/WASM 与宿主边界。派生缓存只避免重复求同一个下标，无法消除相邻窗口的重复工作；整轮 1000ms 限制因此容易触发。

`runtime/rolling.ts` 统一负责窗口推进、过期样本移除和结果缓存。求和使用补偿累计，WMA 利用旧窗口和更新权重，VWMA 复用价格乘成交量及成交量的滚动求和，标准差使用可增删的 Welford 统计量，最高/最低值使用单调队列。每个样本只处理常数次，整轮为摊销 O(N)。窗口状态占 O(L)，历史结果沿用派生序列的 O(N) 缓存。

首次跳读通过迭代补齐之前的结果，补齐过程只递入一层，不随历史长度增长调用栈；回读命中同一缓存。完整窗口前返回 NaN；无效样本移出后恢复计算，VWMA 的窗口成交量和非正时留空。初始化与逐 bar 执行继续共用原有时限。

测试对照独立整窗参考计算覆盖跳读、回读、重复读取、周期 1 和无效值恢复，并统计真实行情读取次数，避免只依赖机器负载相关的耗时断言。
