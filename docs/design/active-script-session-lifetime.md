# 活跃计算身份拥有脚本执行会话

真实页面只启用 PVP、MACD 时，Worker 堆快照的模块级 scripts Map 仍有 62 个内置指标对象，重复动态运行时工厂源码约 10.95MiB。移除全部指标后，运行态没有随之释放。根因是目录注册使用 prepare 安装执行会话，而计算身份的删除只丢弃 core 的闭包，没有脚本侧释放入口。

prepare 增加 metadata / execution 意图。线程池默认 prepare 只读取元数据，临时运行态在读取声明后立即销毁；端口仍保留编译产物租约，首次执行或读取请求计划时才安装执行会话。直接 ScriptWorker.prepare 默认 execution，保持独立端口调用的生命周期契约。

公共指标定义提供 createCompute 工厂，返回具有 dispose 的独立计算闭包。core 为每个去重计算身份创建一份闭包；身份离开活动计划、定义被替换或执行仓库销毁时调用 dispose。脚本服务为每份闭包分配独立执行句柄，首次计算才向池准备运行态。相同参数身份可在 core 内去重，不同图表和计算身份不会共享可变会话。直接 compute 调用使用临时会话并在结束后释放。

Worker 池在槽位空闲时清理已经释放的句柄，不再等待下一份计算任务。清理期间槽位不领取新任务；最后一个句柄归还后销毁物理线程。忙碌槽位仍由原任务生命周期控制，回到空闲时完成清理。

Pane overlay 的后备存储也改为跟随实际绘制：Scene 观察覆盖层原语提交，首次非空提交确保分配，帧结束没有提交则归零。自定义 context 覆盖层在进入前确保分配。坐标轴动态层只操作自己的轴表面，声明为 draw-list，避免空轴操作被误判为整幅 pane overlay 的使用。重新分配时按当前布局恢复尺寸和 DPR。

验证使用真实 Binance 数据、三轮 PVP/MACD 移除恢复、三后端切换和堆快照，另覆盖计算器释放与 overlay DPR 恢复。不同范围和跨轮的进程内存不当作严格 A/B；Worker 堆与源码 self size 单独报告。

修改后的真实页面中，约 900 根行情、PVP+MACD 的计算 Worker 已用堆合计约 6.6MiB，修改前约 29.5MiB；大块运行时工厂源码由 67 份约 11.85MiB 降到 4 份约 0.71MiB。三轮移除恢复均能返回有效指标输出，后两轮全部移除后 Worker 数量归零。空 MACD 副图 overlay 后备存储为 0×0，开启两个指标时 DOM 画布像素汇总约 18.30→16.18MiB。数值为同场景跨轮观测，不承诺等量的进程私有内存下降。
