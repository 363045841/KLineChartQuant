# 对象、Pane 与独立 Y 轴

## 身份与归属

Pane 只有容器身份、顺序、尺寸和交互能力，不再保存 price / indicator 角色。
指标实例只保存 paneId，不再保存 main / sub 运行时身份；移动目标必须指定 paneId。
定义目录的默认创建位置只用于初始化，不解释实例当前的位置或能力。
main 只是初始容器 ID，移走内容后可以回收，不是行情的业务身份。

对象先归入量纲组，量纲组才是一条 Y 轴：

- `price` 组：K 线价格序列与主图（`position: main`）指标共用价格轴；
- 指标定义组：同一个 Pane 内同一定义的多个实例共用一条轴，不同定义各占一列；
- 没有其它对象可依附的 Pane，其绘图共享该 Pane 的绘图轴。

轴身份 = （Pane，量纲组）：价格 Pane 的价格组沿用价格序列对象轴，其余为 `axis:<paneId>:<组键>`。
轴是 Pane 的标尺，范围、变换和手动区间都按 axisId 保存，因此对象迁移到别的 Pane 会重绑
目标 Pane 的同组轴，旧轴的配置不随对象迁移。

品种行情只有一个对象。K 线、单日分时、五日分时和足迹是它的不同画法。
保留既有 candle / plugin:candle 作为稳定存档身份；身份名称不参与画法或位置判断。
`priceSeries.ts` 组装主层、足迹、比较线、最新价虚线、价签与极值标记。
系统对象管理器拥有整组 Layer 的生命周期、归属和显隐；只有主层声明对象树入口。
主层带的内部相对顺序取自各 Layer 的初始声明，不重复手写偏移。

## 绘图借轴

绘图图元不拥有轴，也不新增右轴列：有 owner 的脚本绘图跟随 owner 的轴，
其余绘图跟随所在 Pane 的主轴。声明阶段为绘图写入借用后的轴身份，渲染、命中与
拖拽都读同一份投影。

用户手绘图元不扩张所属轴的自动范围，拖动图元不会牵动价格窗口；脚本绘图借助 owner
轴参与范围。选中图元的上下边界以半透明区间带画在所属轴列底层，数据与时间轴共用同一份
每帧合并结果（提交层 + 指标层 + 会话层），因此拖拽过程中区间带实时跟随。

## 轴 API 与状态

`ObjectAxesApi` 是公开的轴查询、配置和交互入口，挂在 `ChartController.axes`。
`ObjectAxisBinding` 声明 objectId、paneId、axisId，坐标绑定与轴资源使用同一份投影。
`axisResolver.ts` 校验对象与轴身份唯一、所属 Pane 存在，再生成每个容器的对象轴声明；
同一条轴可以挂多个对象（价格类、同定义指标、绘图）。
`Pane.setAxes` 管理对象到轴的绑定与运行时 PriceScale 资源；`Pane.setAxisColumns` 接收
本帧提交的列几何；`axisState.ts` 保存按 axisId 寻址的范围状态。
命中、拖拽、复制与绘图投影都通过对象轴投影取轴，图元不自行派生轴身份。
命中、拖拽与复制通过绑定后的坐标端口使用对象自己的轴。

轴配置不区分行情或指标，格式化回调只是轴的展示配置。
旧的指标刻度 Layer 和专用刻度渲染器工厂已移除。
按 Pane 操作轴的便捷方法只接受单轴容器；多轴时抛异常，调用方必须使用 axisId。
菜单在多轴时要求明确选择目标；滚轮与拖拽按已提交的轴列几何命中目标。

## 单帧标签与绘制

1. 对象 Layer 绑定所属轴的轴身份，提交图形与附属标签。
2. `AxisFrameApi` 为每条轴生成一次刻度和十字线标签。
3. `AxisLabelRegistrar` 要求 Y 标签明确指定 axisId，并验证该轴属于当前 Pane。
4. 标签收集器、轴宽估算与标签保留帧都按 axisId 隔离。
5. 完成本帧所有 Layer 后统一提交轴宽与列几何，清理轴表面并按提交后的列宽绘制
   区间带与所有轴列标签。

没有任何业务 Layer 自行清轴或提前消费标签，因此后注册的最新价签不会丢失，
同一条轴上的多个对象共用一列刻度，不会争用其它列。X 标签仍属于图表唯一时间轴，
不接受 Y 轴参数。

百分比变换必须有非零有限基准。对象数据尚未提供基准时，调用方通过
`axes.setScaleType(axisId, ScaleType.Percent, baseValue)` 显式配置；缺失基准由 API 拒绝，
不能把所有值静默转换为零。显式基准随轴配置保存和恢复，轴菜单据此展示可用性。

Layer role 只有 content、drawing、overlay，表达合成职责，与业务类型无关。
内部 main 画布层带名称表示合成目标，不表示 Pane 身份。

## 异常与验证

不存在的对象轴、非法绑定、重复轴或 Layer 身份在 API 入口抛异常。
Scene 不再吞掉绘制错误；释放资源时先完成整组清理，再抛聚合错误。
新建容器后的迁移若抛异常，组合命令回收新容器并重新抛出原异常。

回归覆盖量纲组合并、主图指标并入价格轴、同定义实例共轴、绘图绑定主轴且不新增列、
迁移后重绑目标轴、删除回收、非法绑定的原子拒绝，以及复用现有行情源夹具完成整帧绘制后，
最新价签落在正确轴列、选中图元的区间带与时间轴同帧跟随拖拽的实际行为。
Canvas 夹具遵循浏览器约束：同一画布重复 getContext 返回同一上下文。

几何夹具必须显式声明对象轴，查询未声明轴时抛异常，不从被测 Store 自动补绑定。
缓存验证观察路径是否复用、GPU 缓冲是否重新上传，不绑定坐标函数的内部调用次数。
原有新窗口初始 3:1 比例保留，只删除了其对 Pane 角色的依赖。
