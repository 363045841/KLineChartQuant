# 每个 Pane 独立的价格轴

刻度类型复用 `kernel.pane.paneScaleTypes`，快捷命令仅写目标 Pane。主图设置只决定主图，副图默认线性，不再继承主图对数设置。已有工作区快照继续保存各 Pane 的刻度类型。

主副图快捷按钮与菜单统一调用逐 Pane 轴命令。选中态和渲染均读取 Pane 状态；主图设置仅记录用户偏好，不用于判定轴命令是否需要执行。恢复工作区后，即使偏好已经为 Linear、实际刻度为 Log，关闭对数命令仍必须更新实际刻度。主图命令完成后向宿主通知当前偏好，用于保存设置。

范围状态以 Pane ID 为键原子保存 `rangeMode` 和 `handRange`。主图原有范围信号由这份状态派生。关闭自动时锁定该 Pane 当前显示范围，开启自动时清除手动范围和纵轴变换。渲染时先计算对应数据的范围，再应用该 Pane 的手动范围。品种变化清除所有手动范围，保留模式；移除 Pane 时释放状态。手动范围属于本次展示，不持久化。

绘图区拖动在所有 Pane 中共享时间视口的横向滚动；纵向平移仅修改按下时所在 Pane，且该 Pane 必须处于 HAND。不再通过主图 ID 限制纵向平移。

指标图形与指标刻度只读取 Pane 的当前显示范围，不向 `getDisplayRange` 传入自动范围。指标状态里的极值仅用于 Core 自动范围计算，避免绘制时旁路覆盖手动范围。

每个轴底部有自己的 A / L 悬停快捷按钮。A 控制范围来源，与刻度类型独立；L 选中表示对数轴，再次点击取消选中切回常规价格轴。主图百分比选项只保留在设置菜单。按钮的位置使用 Core 轴画布的实际几何，随调整高度和排序变化。齿轮设置入口只保留一个，位于轴栏最下方；轴类型与范围菜单操作主图，位置菜单控制整个价格轴栏左右摆放。
