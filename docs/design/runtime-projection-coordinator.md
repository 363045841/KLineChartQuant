# 运行时投影协调者

## 问题

指标迁移原先由 Pane 布局订阅、指标资源 effect、左轴 effect 和帧入口分别投影。
轴声明可以已经属于目标 Pane，而配置轴的订阅执行时运行时轴尚未安装。
`batch` 只合并业务状态通知，原 `runRuntimeProjection` 只延迟绘制，均不能建立跨模块依赖顺序。

## 决策

Chart 持有内部 `RuntimeProjectionCoordinator`，公共 Pane 与 Axis API 保持业务命令职责。
协调者是结构投影的唯一订阅与执行入口，固定执行：

1. 捕获 Pane、轴声明、指标实例、颜色、定义版本和轴范围状态快照。
2. 同步 Pane 容器及布局。
3. 安装轴与对象绑定，初始化或释放轴范围状态。
4. 应用轴配置与左轴显示配置。
5. 同步指标计算实例与指标图层。
6. 标记帧几何失效，合并请求完整绘制。

帧准备再次经过同一协调者，处理没有独立状态通知的会话预览；不再调用另一套轴安装入口。
帧范围和坐标计算仍属于 ChartRenderer，发生在结构投影完成之后。
ResizeObserver 的尺寸提交仍在绘制帧内执行，避免提前清空画布像素。

## 边界

- 指标管理器不再订阅归属变化、不创建 Pane 轴、不自行安排跨模块事务。
- 范围、轴标签及图层消费已经安装的轴声明，不重新派生可能超前的绑定。
- 比例和配置更新不重新挂载指标图层；图层只随实例、绑定、定义或颜色变化更新。
- 布局提交不按 Pane ID 清理轴偏好。偏好使用轴 ID 保存，可独立于当前资源保留；
  运行时轴和范围状态依据完整轴声明回收。主价格轴未保存偏好时从 settings 派生，
  投影不再为了补默认值回写布局。
- 运行时投影过程中产生的通知延后到阶段完成，重入请求随后重新捕获快照。
- 完整提交成功后才发布已完成快照和绘制请求；失败继续抛错，禁止默认轴回退。
- 投影不是资源回滚事务。失败后的资源不能视为已提交，下次同步必须完整重建。

## 验证契约

验证真实指标在主图、新副图、已有副图之间迁移、源空 Pane 回收、轴配置、布局恢复与
纯比例调整。检查不存在订阅异常、每个对象绑定的轴已安装、图层与轴归属一致，
同一数值的曲线投影和刻度投影一致。测试按这些行为契约编写，不保留旧投影入口。
