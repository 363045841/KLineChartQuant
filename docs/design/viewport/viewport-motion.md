# 拖动惯性与平滑缩放

横向平移采样最近约 100 毫秒的实际视口位移。松手速度达到 0.15 CSS 像素/毫秒后启动惯性，最大初速度为 3 CSS 像素/毫秒；停住 100 毫秒后松手不会启动。
惯性采用时间常数 240 毫秒的指数衰减，速度低于 0.02 CSS 像素/毫秒或触及边界时停止。帧位移按实际经过时间积分，并对齐到整数物理像素。
边界取当前 `ScaleXSnapshot.scrollBounds`，滚动通过模型的 `scrollToLogical` 提交。惯性期间隐藏 hover，鼠标会话结束后恢复；停止后才检查可见区域行情缺口。

滚轮及放大、缩小按钮使用 180 毫秒的三次缓出过渡，目标为完整缩放档位。连续输入累积目标档位，重新从当前尺寸开始过渡。
模型支持动画过程中的连续级别，由同一横向标尺策略派生实体宽度、间距和槽位；每帧保持过渡开始时的鼠标连续槽位，超出边界时由策略裁决。
双指缩放直接提交连续级别以跟随手指；程序化 `zoomToLevel` 保持即时定位。
渲染仍遵循整数物理像素边界，缓动不会改变影线的固定 1/2 物理像素宽度。

再次按下停止两种动画，开始缩放停止惯性。重置数据、切换视图及销毁图表都会取消待执行帧；动画也会检测外部导航和尺寸状态变更，避免覆盖新状态。

内容宽度与原生滚动位置由渲染帧通过 `ViewportScrollBridge` 一次提交。不能提前在模型 effect 中缩窄 DOM 内容：浏览器自动夹取滚动量产生的事件会覆盖锚点导航，并中断缩放。桥接器持续确认同一程序提交值，直到遇到不同的外部滚动量。
过去与未来的一屏缓冲取当前绘图区宽度；末端 K 线与其他槽位使用同一缩放变换，不额外收紧缩放边界。
