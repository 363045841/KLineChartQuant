# 拖动惯性与平滑缩放

横向平移采样最近约 100 毫秒的实际视口位移。松手速度达到 0.15 CSS 像素/毫秒后启动惯性，最大初速度为 3 CSS 像素/毫秒；停住 100 毫秒后松手不会启动。
惯性采用时间常数 240 毫秒的指数衰减，速度低于 0.02 CSS 像素/毫秒或触及边界时停止。帧位移按实际经过时间积分，并对齐到整数物理像素。
边界取当前 `ScaleXSnapshot.scrollBounds`，滚动通过模型的 `scrollToLogical` 提交。惯性期间隐藏 hover，鼠标会话结束后恢复；停止后才检查可见区域行情缺口。

滚轮保留 delta 大小，line 单位按 16 CSS 像素换算，page 单位按绘图区高度换算；每 500 像素改变两倍宽度，单次输入限制在 ±500 像素。缩放在对数宽度中进行，相同输入对应相同比例。公开档位与宽度的线性映射保持原义，按钮仍定位完整档位，滚轮目标允许小数。
鼠标滚轮与按钮共享一个动画循环，响应频率为 0.035/ms。轨迹采用临界阻尼解析残差乘以平滑终点窗 `(1-p)²(1+2p)`，p 为 300ms 内的进度；窗函数两端导数为零，起点继承当前速度，终点精确到达目标且速度为零。同向新输入以当前连续位置和速度更新轨迹，不取消或重建 rAF；反向输入清除旧方向积压并归零旧速度。取消“误差足够小后另写精确目标”的结束分支，避免最后一次写入跨过像素阈值。精确目标帧先按动画帧呈现，下一轮只发布结束通知，不再修改尺寸和导航；随后重绘复用同一份终点几何。
像素模式下小于 4px 的增量与 ctrlKey 捏合输入直接跟手，后者使用 10 倍灵敏度；识别后整段手势保持直接跟手，空闲超过 150ms 才重新判断，避免随增量大小切换动画路径。浏览器没有可靠的滚轮设备类型字段，这只是输入特征启发式，尚未出现小增量的大增量触控板事件仍会走弹簧路径。
模型支持动画过程中的连续级别，由同一横向标尺策略派生实体宽度、间距和槽位；连续槽位用于计算轨迹与理想锚点。导航保留未取整的锚点变换，只由策略裁剪边界；显示中心在共享快照内扣除连续导航后统一量化到物理像素。导航不得先取整，否则与中心的取整阈值交错会在尾部产生 1px 往返。像素对齐约束作用于实际显示几何，而非内部导航参数。
双指缩放直接提交连续级别以跟随手指；程序化 `zoomToLevel` 保持即时定位。
K 线理想槽距保留连续精度；实际显示中心在每帧 `ScaleXSnapshot` 内统一采样到屏幕物理像素列，positions、bars、worldAtIndex 和所有绘制消费者读取这份已对齐的几何。相邻显示中心的间隔可以相差一个物理像素，避免先取整统一槽距而将误差放大到远端。每帧的实体尺寸与显示中心均已对齐，无需在结束帧切换坐标规则。影线保持固定 1/2 物理像素宽度。多日分时槽宽累积连续输入，交易时段的网格适配规则保持不变。

再次按下停止两种动画，开始缩放停止惯性。重置数据、切换视图及销毁图表都会取消待执行帧；动画也会检测外部导航和尺寸状态变更，避免覆盖新状态。

横向像素对齐统一使用 `round((worldX - scroll) * dpr) / dpr`。对齐发生在共享视图快照生成阶段，OHLC 和 Plot 不得各自改变中心；屏幕矩形批次保留取整作为公共原语入口的幂等约束。世界投影缓存按尺寸、已对齐中心与数据版本复用，屏幕矩形缓冲每次重写；三角化缓存精确比较归一化坐标，不能复用已改变形状的几何。不再用尾部位移阈值提前收敛来掩盖对齐问题。

实现先转换为物理单位再做一次减法与取整，即 `round(worldX*dpr - scroll*dpr)/dpr`；避免大世界坐标在 CSS 单位相消后放大半像素附近的浮点误差。两条柱状图投影入口都调用同一个函数。回归必须同时检查逐帧像素对齐与“最后动画帧→首个空闲帧”几何不变，不能只证明坐标是整数。预览页内置数据源在 2→3、3→4、5→6、10→11、15→16 五组缩放中，结束帧、空闲帧与强制重绘的 Canvas PNG 内容一致。

内容宽度与原生滚动位置由渲染帧通过 `ViewportScrollBridge` 一次提交。不能提前在模型 effect 中缩窄 DOM 内容：浏览器自动夹取滚动量产生的事件会覆盖锚点导航，并中断缩放。桥接器持续确认同一程序提交值，直到遇到不同的外部滚动量。
过去与未来的一屏缓冲取当前绘图区宽度；末端 K 线与其他槽位使用同一缩放变换，不额外收紧缩放边界。
