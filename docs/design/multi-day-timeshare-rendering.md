# 多日分时渲染设计

## 决策

多日分时使用首个交易日的第一笔有效价格作为全局基准。价格轴继续显示原始价格，百分比轴显示相对该基准的涨跌幅。

每个交易日保留独立的分时数据组。X 坐标使用 `dayIndex * sessionSlots + intraDaySlot` 的全局槽位，避免不同交易日相同墙钟时间重叠。

## 滚动

分时内容宽度至少为总槽位数对应的一个物理像素宽度。当 `days * sessionSlots` 超过视口物理宽度时，viewport 产生横向滚动范围；否则保持完整展示。

## 兼容性

单日分时继续使用昨收作为基准，并保留原有日内时间标签。多日数据仍向旧渲染链路发布平铺点列，同时在 `TimeShareBuffer` 保留按交易日分组的数据，供多日几何与基准计算使用。
