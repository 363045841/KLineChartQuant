# Script Plot 运行错误

脚本的 `ctx.plot` 统一拒绝 `Infinity` 与 `-Infinity`，抛出携带错误码、Plot ID 和 bar 下标的错误。`NaN` 继续作为空点处理，避免将指标预热和断线误判为运行失败。诊断仅提示可能除以零，不推断具体表达式。

共享计算执行核心按任务捕获计算异常，将可序列化的错误随结果池分发到实例；Worker 与 inline 使用相同语义。失败实例不保留部分结果或旧绘图，也不参与价格范围计算，其他任务继续执行。参数或数据变化后的成功结果自然替换错误状态。

图例从实例错误投影生成，保留名称、参数和操作按钮，在名称旁直接显示主题危险色错误横幅，无需悬浮或点击；成功计算后清除横幅。主副图及自定义图例共用错误字段。
