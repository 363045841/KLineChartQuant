# Pane 配置、几何与指标实例的边界

本次修复落实现有 StateKernel、只读投影和领域命令规则，不改变布局文档格式。

- `paneSpecs` 是配置的唯一事实来源，`paneRatios` 只派生。布局提交接收一份完整规格，补丁中的新比例必须参与归一化；配置相同不发布通知。
- ratio 表示可见 pane 的相对权重。隐藏 pane 保留配置权重，不参与可见比例归一化。新副图继续沿用现有初始分配：只有一个 price pane 时，新份额为已有总权重除以“已有可见 pane 数量 + 2”，因此首个副图为 3:1；已有 pane 之间的权重比不变。
- Core 布局统一生成 `paneGeometry`，只包含高度大于零的可见 pane；坐标相对绘图区，单位为 CSS 像素。几何不进入布局持久化。轴列宽由渲染测量直接更新，Vue 不再观察 canvas、读取 offset 或 CSS 变量。
- 隐藏 pane 的运行时矩形归零，表面后备存储释放；命中和分隔线只消费已提交的可见几何。pane 内部命中采用半开区间，分隔线位于上侧 pane 底边。
- 布局按相对权重和最小高度分配。最小高度总和超过预算时，统一等比压缩最小高度；累计边界取整确保总高度守恒。极小容器允许零高度。gap 同样受总预算限制。
- 分隔线拖拽捕获按下时的规格、像素高度和绘图区高度，以总位移计算，只调整相邻两 pane，到最小高度停止。回到原点时恢复原始配置权重。外部配置、gap、默认最小高度或绘图区高度改变后旧会话失效。pointercancel 保留已提交结果，沿用现有行为。
- 布局投影由 Chart 管理；指标管理器仅按实例、定义和容器结构投影图层。比例、显隐、最小高度变化不拆装指标资源。
- 容器身份以 paneId 为准，主图默认角色按 MAIN_PANE_ID 确定，不按数组索引推断。重排 API 不新增主图必须位于索引零的限制。
- Vue 容器投影保留全部实例。定义开关关闭该定义的全部实例，实例删除只回收变空的用户副图；显式删除 pane 才删除整个容器。更换指标入口以 instanceId 寻址，避免首实例特判。
- 清空副图复用聚合命令，完整重排按 paneId 一次提交。删除选择器已不再发出的旧“按定义重排副图”事件链路，以及无消费者的布局反推函数。Vue 上下移动仅交换用户副图槽位，保留主图与系统容器的位置。

验收覆盖比例更新与无变化通知、隐藏命中、拖拽事件拆分一致性、邻接限制、容器高度不足、多实例开关以及批量操作的提交次数。布局恢复、指标晚加载和 resize 不得改写用户比例配置。
