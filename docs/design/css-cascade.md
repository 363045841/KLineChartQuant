# 共享控件与业务外观的 CSS 层叠规则

共享按钮及输入控件的默认外观放在 `@layer kline-primitives` 中，业务组件的局部外观保留为无层样式。普通无层声明的优先级高于具名层，因此业务样式无需追加父选择器或重复共享 class 来压住默认值，也不依赖 Vite 同步与懒加载 CSS 分块的到达顺序。

作用域仍由 Vue scoped 样式保证。层只定义默认值与业务定制之间的关系，不修改选择器匹配范围；共享控件内部的尺寸、交互状态和媒体查询仍遵守原有顺序。新增共享默认样式沿用 primitives 层，业务组件负责明确声明自己需要覆盖的属性，不通过 `!important` 提权。

产品验收在真实源码和 tarball 页面中反转已加载样式表的顺序，再逐像素比较完整工作台截图；正常顺序的源码与打包页面也继续做截图对比。验收覆盖自选列表按钮、Agent 模型菜单和输入框。比较只忽略视口边缘圆角抗锯齿在 ±1 色阶内的抖动：Chromium 对同一构建重复加载也会出现这种单像素噪声，任何成片或更大色差的差异仍然失败。

该规则适用于普通声明。不要在共享默认值中使用 `!important`，因为重要声明的层顺序与普通声明相反，会破坏业务覆盖约定。
