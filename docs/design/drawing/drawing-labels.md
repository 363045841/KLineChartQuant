# 绘图附属文本与标签

绘图标签随图元的移动、复制、可见性和删除一起变化。`DrawingObject.labels` 以图元目标命名，值为 `{ text, position }`。每个目标可挂一个多行标签。

单条线和箭头用 `line`。十字线用 `horizontal` 和 `vertical`。矩形用 `top`、`right`、`bottom`、`left` 和 `inside`。通道按几何定义提供基准线、对侧线、中线、上轨、下轨或内部。斐波那契回撤按比例寻址，例如 `level:0.5` 对应 50% 水平线，调整层级排列不会移动这条标签。

## 工具、绘制与编辑

`drawings_write` 在创建时写入指定目标。在更新时按目标合并，省略的目标沿用旧值，`null` 删除指定目标。工具根据图元类型和参数校验可用目标，拒绝整笔含有无效目标的请求，并在错误中给出可用目标。

几何定义在生成线、箭头和填充区域时标明 `labelTarget`。帧投影按目标名把 `DrawingObject.labels` 附到相应原语。矩形延伸时，省略的侧边不绘制，相邻边继续使用自己的标签。绘制和文本命中共用矩形边界计算。图元设置和就地编辑按同一目标读写标签。核心图元更新接受完整标签快照，删除文字时从快照中移除相应条目。

线和箭头根据 `start`、`center` 或 `end` 选取几何起点、中点或终点。绘制与命中共用 `resolveLineLabelLayout`，以同一锚点、法线偏移、旋转和对齐定位文字。区域文字按填充包围盒定位。文档统一用字面量 `\n` 保存换行，设置框显示为真实换行，绘制按行拆分。

图元设置的文本页默认选中该图元第一个可用目标，矩形默认内部；默认目标只由 `defaultLabelTarget` 决定，不再由 Vue 层的静态配置声明。图元有哪些目标也只来自 `drawingLabelTargets`，设置页不再维护第二份清单。

## 布局数据迁移

工作区布局读入时把旧 `labels.line` 和 `labels.area` 数字键转换为命名目标。迁移按旧版本的几何顺序解释索引，包含矩形延伸时省略侧边的情况。未绑定到任何旧目标的索引无法自动确定含义。已使用目标名的图元可直接读入。后续保存写入新形状，沿用现有 IndexedDB 数据库版本、对象仓库与记录键。

迁移只负责读取，是布局边界的一次性兼容层。布局文档不再接受 v3 旧形状时，连同 `migrateDrawingLabels.ts` 与对应迁移测试一起删除。
