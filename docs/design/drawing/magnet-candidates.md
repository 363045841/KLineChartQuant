# 绘图磁吸（magnet）候选模型

磁吸把指针落点吸附到图表上已有的价格参照：候选来源、坐标空间、选择规则与写回语义如下。

## 定位

磁吸是**值轴吸附**：所有候选都落在同一个 X 上，各自给出一个可写回的价格；
少数候选（图元端点这类时间锚点）额外给出可写回的时间。

因此候选之间只比较屏幕距离，不区分图形种类，也不需要为每种图元单独实现
「求 X 处的 Y」。

## 候选来源

| 来源 | 产出的值 | 数据出处 |
|------|----------|----------|
| OHLC | 当前 Bar 的四值 | 行情数据 |
| 图元的线 | 线段在 Bar 中心 X 处的 Y | 已提交层的帧投影 |
| 指标值 | 该指标在当前 Bar 的标量 plot 值 | 指标渲染状态快照 |

图元的线来自 `DrawingFrameProjection.snapLines`：帧投影在计算几何时顺手收集线段，
磁吸直接复用，不再做第二次几何计算。这样一来「线在哪个范围内有效」——射线、
延伸线、fib 各档位——完全由既有几何定义决定，磁吸不重复实现。

中点、边沿不是独立候选：它们是线的一部分，按线求交即覆盖。

指标值按 K 线下标对齐（`Plot.data[barIndex]`），直接取值即可。

## 坐标空间

磁吸内部只有一套坐标：**Pane 局部逻辑像素**。

- 容器局部 → Pane 局部的换算只在 `resolveDrawingPointer` 入口发生一次；
- `DrawingPointerAnchor.x/y`、候选的 `x/y`、手柄、命中测试同处一个空间。

`priceToY` / `yToPrice` 本身就是 Pane 局部，因此候选与落点之间不需要任何偏移运算。

## 选择规则

1. **距离**：点候选按二维距离（hypot），值线只比 Y，时间锚点只比 X。
2. **档位**：两档都按半径过滤，strong 的门槛更大（weak 8px / strong 24px）。
   候选集合不随档位变化，strong 不是「无限吸附」。
3. **同距离**：先比来源优先级（图元线与指标值优先于 OHLC），再比候选 id，
   结果不随遍历顺序漂移。

X 的落点：命中的候选自带时间时用它自己的 X；否则落 Bar 中心。
没有任何候选命中且 Bar 中心不可解析时返回 null，调用方使用原始坐标。

## 写回语义

`SnapCandidate` 携带 `price` / `time` 原值，命中时直接覆盖解析出的领域值，
不再用屏幕坐标反算——这是「端点 price 精确等于水平线 price」的来源。

- 水平线段：帧投影在收集 `snapLines` 时把该线段对应的锚点价格一并带上，
  写回的是领域原值，不经过 `yToPrice(priceToY(price))` 的浮点回环；
- 其它线段与指标值：价格由 Y 反算，属于派生值；
- OHLC：原始值；
- 时间锚点：命中时同时丢弃 `futureOffset`，因为它引用的是真实 Bar。

## 排除集合

拖拽中的图元必须排除在候选之外。它们的**已提交**几何仍在帧投影里，
不排除会让落点吸到自己，形成反馈回路。

因此候选源统一读 committed 层投影，`sessionDrawingProjection` 不进入候选；
拖拽方再按 id 补充排除（例如整组选中一起拖动的图元）。

整线拖拽是位移增量语义，没有单一落点，不参与磁吸。

## 与 Shift 锁角的关系

磁吸只做值吸附；Shift 是方向约束，见 [angle-lock.md](./angle-lock.md)。

## 命中反馈

命中点在会话层投影为一枚圆点（`point` 原语），位置就是磁吸结果本身，
颜色取交互标记 Token。反馈只走会话覆盖，不写 kernel、不进撤销历史。

## 依赖方向

```text
interaction/   —— 档位与修饰键分发、排除集合、命中反馈的会话态
geometry/      —— 坐标换算；调用磁吸并把领域值写回锚点
magnet/        —— 候选采集 → 选择 → 落点（纯函数）
render/frame   —— 提供 committed 层线段（snapLines）
```

magnet 不依赖文档、指标或工作区，只消费 `MagnetSnapSources` 的两个只读查询。
