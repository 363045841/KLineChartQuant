# 图元复制、粘贴与克隆

图元复制有四个入口，共用同一套落点与克隆实现：

- **复制到剪贴板**：Canvas Toolbar 的复制按钮与 `Mod+C` 只把选中图元快照写入 `ChartController` 的内部剪贴板，不写文档、不产生撤回历史。
- **粘贴**：`Mod+V` 从内部剪贴板取快照，按当前视口解析落点后克隆；原图元已删除时仍可粘贴。
- **克隆**：Canvas Toolbar 的克隆按钮与 Agent 的 `drawings_copy` 立即复制并粘贴，不依赖剪贴板。
- **Ctrl 拖动复制**：光标工具下按住 Ctrl/Meta 拖动图元，越过 4px 阈值后立即生成真实副本，再由普通拖拽移动副本；原图元不动。

## 落点

- 剪贴板粘贴与克隆共用 `resolveCopyPlacements`：默认向右偏移约 16 CSS px、向下偏移 48 CSS px。时间轴落在整槽位上，横向取最接近 16px 的槽位距离，至少移动一槽。
- 水平锚点只改价格，垂直锚点只改时间。多选使用共同偏移，保留相对位置。
- 对正向和反向的锚点出界量求和，选择出界较少的方向。跨度超过视口时优先保留组内几何关系。
- 任一图元或锚点不可解析时整批不写入。
- Ctrl 拖动复制不使用偏移策略：副本从原锚点生成，立即进入普通拖拽，最终位置由指针决定。

## 模型边界

- `DrawingDocument.duplicateDrawings` 是唯一克隆实现：生成新的图元与锚点 ID，副本可见且自身未锁定，写入当前工作区；源快照可以已不在文档中。
- `ChartController.copyDrawings` 按文档内 id 解析源图元后走同一克隆命令；`pasteDrawings` 直接用剪贴板快照走同一命令。
- 整组副本与选中集合通过同一个 State Action 发布，命令层记录一条撤回历史。
- Ctrl 拖动复制由交互层调用 `duplicateDrawings` 生成真实副本，再走既有 `DragHandler` 与 `commitDrags`；交互层不生成 ID，也不持有未提交图元。复制与拖动各记一条历史。
- 剪贴板按图表实例隔离，不跨图表共享。
