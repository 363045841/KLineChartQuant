# 绘图会话层独立重绘

## 问题与决策

图元拖拽只写会话覆盖，抬起鼠标才提交文档。帧去重原先只比较正式文档，遗漏拖拽和预览；同时正式图元与十字线共享 canvas，动态层清屏后必须重画所有图元。

每个 Pane 增加正式图元 drawingCanvas，位于行情表面之上、动态 overlayCanvas 之下。Drawing Layer 消费正式投影；Drawing Session Layer 消费拖拽覆盖、绘图预览和框选投影。画布由现有 Pane 生命周期管理，尺寸与 DPR 统一经 PaneRenderer 更新。

## 失效与生命周期

- 帧去重比较会话图元引用，捕获每次移动、预览替换和覆盖移除；不比较每次读取新建的外层数组。
- 正式层版本包含文档引用、选中集合和会话覆盖成员 ID。覆盖坐标变化不使正式层失效。
- 正式层排除被会话覆盖的同 ID 图元。首次移动刷新正式层并清除原位置；后续移动仅投影、清屏和绘制动态层，复用正式层投影和像素。
- 抬起鼠标提交文档并移除覆盖，正式层在最终位置重画；取消会话则在原位置重画。
- 行情、缩放、视口、布局、主题或 DPR 改变时重新投影和绘制正式层；重建 Pane 时通过画布上下文变化使旧投影失效。
- 两份投影的坐标轴装饰合并到同一帧，拖动中的价格和时间范围跟随临时坐标。

独立层不意味着为每个图元增加画布。每个 Pane 只增加一张正式图元画布，现有动态表面承担会话图元与十字线，避免按图元数量增长的表面开销。

## 验证

回归测试覆盖移动过程持续绘制、正式层复用、拖拽提交与取消、画布分流以及 DPR 尺寸同步。界面验证应检查多选、锚点、水平线、预览和缩放时的重影与层级。
