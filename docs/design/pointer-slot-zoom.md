# 指针槽位缩放

缩放只有一条规则：鼠标的连续槽位坐标在缩放前后保持不变。整数槽位通过最近中心取得，负索引表示首根行情之前的过去槽位，超过数据末尾的索引表示未来槽位。三者不按有无 OHLC 分流。

网格由第零槽位中心 origin 和相邻中心距离 step 定义，世界坐标为 origin + index × step。缩放先保存 (scroll + pointer - origin) / step，再根据目标网格计算新的 scroll。计算不对鼠标或滚动量取整；物理尺寸的取整只发生在网格派生时。

所有缩放入口共用此变换。控制器在写入前算出目标网格，缩放级别、分时槽宽及滚动位置在一次 batch 内提交，避免批量通知延迟时读取旧几何。

原生 DOM 的非负 scrollLeft 不是世界坐标边界。过去区域不足时增加左侧内容偏移，并等量补偿 DOM 滚动位置；未来区域内容宽度根据当前滚动请求自动扩展，始终保留一屏可继续滚动的空间。移除强制保留末尾两根数据的限制。

渲染的数据索引范围仍保持非负，整屏过去区域得到空数据区间。槽位交互直接使用网格，不依赖可见 K 线数组，不跳过中心在屏外的槽位。过去十字线和刻度显示 T- 相对索引，未来保留 T+ 或权威日历日期；空槽位没有行情 tooltip。

验证覆盖正负索引、两侧内容扩展、连续往返缩放、槽内分界附近、非整数鼠标坐标、非整数 DPR 和分时绘制网格。

实时行情更新不再因视口位于数据区之外而自动回拉。前插历史数据仍按增加的槽位数补偿滚动位置，以保持已有行情的屏幕位置。
