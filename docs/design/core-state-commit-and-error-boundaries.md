# Core 状态提交与异常边界

行情选择、命令绑定、MTF 计算和工具栏操作在发布前准备并校验候选结果。提交涉及多个信号时，使用同一批次发布。K 线分页同时扩展两端时发布一个 `extend` 变更，携带前置数量用于滚动补偿。分时请求直接使用活动序列中的交易日键。

状态所有者保留写入句柄，读取端通过只读 signal 和集合快照观察结果。场景的 Layer 列表由一个 signal 管理，Layer 对象继续遵循渲染接口的可变资源契约。命令的快捷键视图只提供查询和订阅，绑定由命令注册表提交。

存储读写、命令执行和渲染后端保留局部异常。Vue 偏好恢复、键盘分发和渲染合成在各自操作边界捕获并报告失败，宿主据此使用默认值或 Canvas。分时指标请求在行情切换和销毁时取消，取消的结果失去提交资格。释放操作收集失败并继续执行剩余清理。
