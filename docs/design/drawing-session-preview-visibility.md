# 绘制会话预览的可见性

绘制中的 `PREVIEW_ID` 图元只存在于会话 overlay，没有持久化标的归属。正式图元的标的过滤规则曾将它排除，导致首点之后移动鼠标也无法显示预览。

帧投影将无标的归属的预览视为当前会话图元，继续执行 Pane、工作区、坐标有效性与视口裁剪。正式图元以及显式绑定标的的预览仍遵守原有标的过滤规则，不放宽文档归属约束。

多锚点工具每次累积未完成的落点后立即构造预览；首点与跟随点初始重合，后续 pointermove 保持已确认锚点并更新跟随点。预览继续只写会话 overlay，不进入文档和撤回历史。绘制完成、切换工具或取消时沿用会话清理逻辑。

回归验证覆盖双点与三点工具的首点即时预览、鼠标跟随、工具切换清理，以及具体标的下预览连线和端点的投影，并确认正式图元的标的隔离仍然生效。
