# 窄 K 线实体与影线合并

主图的实体、边框和影线使用相同涨跌色。当最终整数物理像素中的实体宽度等于影线宽度时，原有实体及上下影线覆盖一条连续竖条，分别生成和提交没有视觉收益。

共享 OHLC 投影接受显式 `mergeWick` 参数，主图启用；只有等宽且未要求独立边框时返回一个实体矩形和空影线数组。脚本指标不启用，保留独立设色和隐藏各部分的语义。判断使用最终物理宽度，适配 DPR、配置和连续缩放。

竖条上边界取最高价与实体顶部的较小值，下边界取最低价与实体底部的较大值，保留十字星至少一个物理像素的覆盖。空心蜡烛在此宽度下没有内部空白，同样适用。美国线沿用原有单竖条路径。

继续使用现有矩形批次及 GPU/Canvas 绘制路径，无需新增线条管线。每根窄蜡烛最多三个矩形减少到一个；涨跌都有时最多四个非空批次减少到两个。测试覆盖多种 DPR、涨跌方向、实心/空心、十字星及不满足合并条件的几何。
