# Plot 渲染层绑定实例轴

同一个 Pane 可以包含多个量级不同的指标，例如 MACD 与 ENE。框架通过轴解析器为实例派生轴身份，并分别计算可见范围。

`createPlotLayer` 必须把收到的 `axisId` 传入 `createIndicatorRendererLayer`，由公共的 `bindIndicatorAxis` 同步切换 `pane.yAxis` 和数据空间变换。这样屏幕空间投影与数据空间图元都使用实例所属的轴，避免错误使用 Pane 首轴后落到可视区域之外。

轴身份继续由框架统一派生，Plot 渲染层只负责传递，不自行推导轴或合并不同指标的数值范围。

GPU 表面合成必须保留每次提交的坐标变换，仅合并裁切、DPR 和变换相同的相邻提交。不得按裁切查找历史批次并覆盖变换，否则不同指标会被最后一次提交的轴范围投影，仍然落在视图之外。相邻合批同时保持图层绘制顺序；直出失败时使用同一批次的变换回退到 Canvas。
