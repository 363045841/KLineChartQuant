# 最新价倒计时

## 帧时间快照

每个实际执行的帧在 derive 开始时从可注入的 Clock 读取一次 Unix 毫秒时间。同步 draw 和 rAF flush 共用该入口；generation 0 占位不读取时间。倒计时剩余时间、显示文本和 timer 延迟都使用本帧的 now，Layer 只读取 RenderContext 中已派生的 countdown。

ChartRenderer 继续作为倒计时 timer 的唯一所有者，在帧事务的副作用阶段管理 timer，不在 paint 内安排刷新。timer 只请求 Overlay 帧，实际绘制仍经过 FrameTransaction。保留现有每秒 Overlay 刷新，不新增通用时间驱动注册机制，也不改变交互帧的强制刷新规则。

Overlay 仅复用几何缓存，时间和倒计时每帧重新派生；版本键使用倒计时文本，绘制后的版本记录使用同一帧文本。收线、无数据、不支持的视图或周期、销毁时停止 timer。后台延迟后直接显示当前值，不补播过期秒数。

## 开关

main 分组的布尔设置 `showLastPriceCountdown` 默认 `true`。关闭时 derive 不输出倒计时，也不安排 timer，右轴价签自然恢复单行。设置 UI 和持久化沿用 `DEFAULT_SETTINGS` 的通用链路，Vue 无需改动。

## K 线周期计算

倒计时表示本根 K 线从开线时间起经过一个周期前的剩余时间。输入只有周期、开线时间戳和本帧 now；市场、交易所、交易日历、午休、夜盘与显示时区均不参与计算。未配置市场时段的品种也可显示倒计时。

`lastPriceCountdown.ts` 用受 `KLinePeriod` 完整约束的周期表定义长度：分钟及小时按对应固定时长，日线为 24 小时，周线为 7 天；月、季、年按 UTC 日历增加 1、3、12 个月，保留原始开线时刻，目标月份缺少对应日期时截到月末。

例如 10:00 开始的 5 分钟 K 线以 10:05 为结束点，11:00 开始的 60 分钟 K 线以 12:00 为结束点，14:30 开始的 4 小时 K 线以 18:30 为结束点。即使跨休市或周末，也按同一规则计算。

时间戳必须表示 K 线开线时间。尚未开线、已经到期、无效时间戳及非标准 K 线周期返回空值；到期后隐藏并停止 timer，直到新 K 线到来，不按当前时间取模循环。此功能不预测交易所实际收盘时间。

每帧只调用一次 `getLastPriceRemainingMs`，格式化函数仅消费该剩余毫秒值，timer 也消费同一数值。显示保留 `mm:ss` / `hh:mm:ss`，不足一秒向上取整，长周期允许小时数超过 24。

## 验证

覆盖所有标准周期、跨午休与周末、夏令时、UTC 午夜、闰年月末、毫秒边界及无效输入。帧测试验证已注册、未注册和空市场标识时的统一行为，以及缓存帧、开关、到期停止和新 K 线重启 timer。倒计时标签的收集与绘制见[轴标签单帧收集模块化](../rendering/axis-labels.md)。
