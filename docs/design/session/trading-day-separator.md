# 交易日分隔线

## 结论

日线以下周期在相邻两根 K 线分属不同交易日时，于两者之间的槽位边界绘制一条贯穿 Pane 的蓝色虚线。开关为外观分组的 `showTradingDaySeparator`（标签「交易日间隔」，默认开启），与「显示网格」互相独立。

交易日归属只由市场会话配置决定：`tradingDayStartMinute` 声明交易日从市场时区墙钟的哪一分钟开始，省略表示自然日 00:00。前端不读取交易日历，也不把数据源的交易日历能力接入这条链路。

## 归属规则

`createTradingDayIndexer(session, referenceTimestamp)` 返回「时间戳 → 交易日索引」：

```
dayIndex = floor((timestamp + zoneOffset(reference) - tradingDayStartMinute * 60000) / DAY_MS)
```

- 同一个交易日内的 K 线索引相同，切换交易日时索引递增；分隔线只需比较相邻两根 K 线。
- 时区偏移按可见窗口中点解析一次，与时间轴刻度共用同一取舍；DST 切换最多带来一小时差异，而内置市场的交易日起点都不落在凌晨 2 点，因此不会改变归属。
- 周末与节假日不单独处理：没有 K 线的时间段只表现为时间差，休市前后的两根 K 线自然分属不同交易日。

## 夜盘归属

昼夜盘分离的市场通过 `tradingDayStartMinute` 表达，不去改写 `sessions`：

- `sessions` 继续只描述常规盘墙钟时段，保持分时槽位「一天内按时间递增」的语义。
- 商品期货夜盘 21:00 开盘，`tradingDayStartMinute = 1200`（20:00）。该时刻位于日盘收盘之后、夜盘开盘之前，因此 21:00 的首根 K 线归入新交易日，跨零点不产生分隔。
- 日盘收盘与当晚夜盘之间（如 15:00 → 21:00）是真正的切换点，此处画一条线。
- 同一夜盘内部的 23:00 → 次日 01:00、夜盘结束 → 次日 09:00 都不画线。

内置配置覆盖国内期货交易所：`SHFE`、`INE`、`DCE`、`CZCE`、`GFEX` 使用 `tradingDayStartMinute = 1200`；`CFFEX` 无夜盘，不声明该字段。品种级夜盘收市时间差异（23:00 / 次日 01:00 / 次日 02:30）记录在各自 `notes`，不进入 `sessions`。

## 与数据源的关系

市场会话仍按品种的 `sessionId` 解析。数据源需要为期货品种下发具体交易所标识（`SHFE` 等），才能拿到夜盘归属；若仍下发股票市场的 `CN`，前端只能按自然日划分，跨零点的夜盘会被错误切分。前端不为缺省标识推断交易所，也不以内置品种代码表做映射。

## 可见性

- 只在 `isIntradayPeriod` 为真的周期绘制；日线及以上由月界网格、分时与五日分时由日界几何表达，互不重复。
- 分时数据视图不绘制。
- 虚线节奏与描边宽度沿用比较基准线的约定（`dash: [4, 4]`、`1 / dpr` 物理像素），颜色取自 Token `colors.tradingDaySeparator`。
