# 指标结果的时间轴身份与异步展示

左侧补历史后，行情立即进入新时间轴，Worker 的旧结果仍属于计算时的时间轴。数组下标只是各自快照中的位置，不能作为跨版本的 bar 身份。

结果池保留计算输入的原始 timestamps 和 dataRevision，禁止提交时覆盖为展示时间轴。每次行情更新先将已提交结果投影到当前展示时间轴，再发起异步计算。重算期间已有结果按时间身份留在原来的 bar，新位置留空；新结果通过现有请求版本门禁后整体替换。

IndicatorTimelineProjection 提供数据列重排与逻辑坐标映射。普通 K 线使用精确时间戳，分时展示沿用分钟身份。Plot、OHLC 数据列、fill 颜色明确声明为逐 bar 数据，只有这些数组参与重排；不递归猜测样式数组、图元列表、锚点或领域事件数组的含义。

line 的 logicalIndex 通过计算时间轴映射，bar_time 保持绝对时间；范围外逻辑坐标保留相对原边界的槽位距离，原 bar 不在新时间轴时不绘制。Plot.offset 保留为用户声明的绘图偏移，不能兼作数据版本修正。

Structure 和 Zones 的专用 composer 接收同一坐标映射，只转换明确的索引字段。成交分布按价格分箱，无须重排价格数组。

投影按计算结果、源时间轴和目标时间轴缓存，滚动、缩放和颜色不变时只重算可见范围。原始结果从不被反向修改，连续补历史总是从原始快照重新映射，避免累计偏移。主副图渲染、图例与价格范围都消费同一份已对齐状态。
