# Histogram 基线像素对齐

MACD 等 Histogram 原先分别计算矩形起点和高度，再由绘制入口分别取整。正柱的底边由两个取整结果相加得到，可能与统一取整后的基线相差一个物理像素。

通用 Plot 渲染器复用成交量柱使用的 `barVerticalRect`：先将数值端点与基线投影到整数物理像素，再计算矩形起点和高度。所有正负柱共享同一基线，接近零值的柱子在对应一侧保留至少一个物理像素。Canvas2D、WebGL 和 WebGPU 继续消费同一矩形批次。

验证使用 Plot 渲染、柱状几何和矩形绘制入口的现有单元测试；界面可通过缩放 MACD 面板检查零轴附近的边缘。
