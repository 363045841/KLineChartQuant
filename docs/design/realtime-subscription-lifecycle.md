# 实时订阅生命周期

MarketDataContext 持有并释放唯一的 K 线与报价订阅池。图表、自选和指标只声明需求，禁止按 Registry 隐式寻找或创建另一个池。

数据流固定为：Registry 配置和 Health 探测结果、订阅需求 → 订阅池同步 → 单次传输 → 行情与连接状态 → 消费者。池直接读取现有权威快照，不增加另一种来源数据形状。连接结果不能反向写入健康状态。

池的同步入口统一处理启用、离线、改址、注销、订阅集合变化。未确认健康或离线时只保留逻辑需求，不建立物理连接；禁用关闭连接，注销结束逻辑订阅。新来源和改址由 Context 发起健康确认；宿主启动时同样先确认健康，再允许建立连接。

SSE 错误立即关闭 EventSource，取消浏览器自动重连。池记录本次失败对应的健康确认，同一确认下的列表变化不能触发重试。下一次健康探测确认可用后，池恢复保留的需求；正常在线连接不会因重复健康确认而重建。Health 后台复查保留上一次事实，避免 checking 引起连接抖动。

恢复沿用显式健康刷新，不新增自动轮询或第二套重连定时器。宿主销毁先释放池，再注销来源、释放健康探测。成交范围查询与成交流使用独立的 TradeDataSource 契约，本次不把成交帧转换为 K 线或报价帧。
