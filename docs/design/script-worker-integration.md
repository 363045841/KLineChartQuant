# Script Worker 接入

Script 的源码编译、声明读取和行情重算统一由 Script 包的 Worker 执行。script-chart
只保存文档、管理编译句柄，并注册返回 Promise 的计算入口，不在主线程创建 QuickJS。

通用 Plot 计算端口允许返回 Promise；实例计算核心统一等待结果，复用已有调度器的请求版本
门控。结果缓存保存进行中的 Promise，使同一行情版本的并发请求共享计算，新请求不会被旧
请求的异步完成覆盖。原有同步指标继续通过同一入口执行，不增加脚本专用调度器。

每次脚本准备使用独立句柄。源码验证与持久化成功后才发布定义，失败时释放临时句柄，成功
替换后释放旧句柄。应用关闭时由 ScriptService.dispose 终止线程。Worker 失败直接报错，
不切换到主线程执行。

信任标记由宿主在 prepare 时传入，编译句柄绑定所选后端。可信脚本通过 Worker 内的
Function 工厂由浏览器原生引擎执行，不可信脚本使用 QuickJS；切换信任后保存会生成新的
句柄。内置脚本默认可信。两种后端共享编译转换、运行库源码和绘图契约，每次计算各自创建
独立运行态。原生运行库使用局部 globalThis 对象注册库和行情入口，避免污染 Worker 全局；
它不构成安全沙箱。原生执行不受 QuickJS 内存限制和超时中断保护，死循环需终止 Worker。
