# 脚本稳定身份与重命名

用户脚本的 `name` 是可编辑显示名称，不能作为持久化身份。脚本服务创建用户文档时自动分配 `script_<UUID>`，保存时同时持久化 ID、源码和版本；恢复时沿用已保存的 ID，不再从源码名称推导身份。脚本作者无需声明 ID。

注册桥接将稳定 ID 交给 core 的内部名称，显示名称仍来自源码的 `name`。脚本目录、图表实例、计算身份、默认副图和渲染器均引用稳定 ID；原生指标继续使用自身目录身份。内置脚本由框架以其固定内置名称注册，保持只读。

保存用户脚本允许修改显示名称，但必须先检查名称冲突和版本，再持久化完整文档，最后发布同一身份的新定义。注册表更新显示名称索引时移除旧索引，并通知目录及图表消费者更新；已有实例的 ID、参数和布局引用无需迁移。

用户存储采用新格式，必须包含 ID，不提供旧格式解码或数据迁移。旧工作区和用户脚本数据由使用者清空后重新创建。
