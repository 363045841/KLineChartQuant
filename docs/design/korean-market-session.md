# 韩国市场会话接入决策

## 背景

TradingView 可按 `KRX:<symbol>` 拉取韩股 K 线，但六位韩股代码与 A 股代码存在重叠。
行情后端必须以显式交易所为准，不能仅根据代码长度推断市场。V1 品种描述需要把韩国市场
归一化为 `sessionId: KR`、`currency: KRW`，Core 才能使用正确时区处理 K 线时间。

## 决策

- Core 内置 `KR` 市场会话，时区为 `Asia/Seoul`。
- 常规交易时段使用 `09:00–15:30`，无午休，共 390 个一分钟槽位。
- 裸六位代码可由数据源返回多个交易所候选，最终市场由用户选择的稳定品种描述决定。
- 显式 `KRX` 必须优先于 A 股代码推断，避免 `005930` 被重写为 `SSE` 或 `SZSE`。
- 韩国品种仍走现有 Market Data V1 Provider，不在 Core 增加数据源特例。

## 范围

本次只支持韩股搜索候选、日内外 K 线加载和市场时区。汇率转换、盘前盘后、集合竞价、
韩国节假日日历及 TradingView symbol search 不在本次范围内。

## 验证

- `KRX:005930` 保持 KRX 身份并返回 `KR/KRW/Asia/Seoul`。
- 裸 `005930` 同时保留 A 股与 KRX 候选。
- `KR` 会话解析为 390 个一分钟槽位。
- 现有 CN、HK、US 会话行为保持不变。
