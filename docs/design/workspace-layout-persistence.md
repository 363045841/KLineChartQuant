# 标签页与布局持久化

标签 ID 是持久化的稳定身份，同时作为 Layout 的 `layoutStorageId`，不另建指标、窗格或参数副本。工作区存储只保存标签集合和标题品种，Core Layout 仍是图表配置快照的唯一存储入口。

WorkspaceContent 在图表创建前传入标签 ID 并开启布局恢复。LayoutManager 以该身份选择独立的 IndexedDB 归档键；自动保存、切换具名布局、错误信号、pagehide 与销毁落盘均复用既有机制。不同标签不会以各自过期的内存归档覆盖其他标签。

控制器就绪时布局已经恢复，工作区不能再次用标签摘要覆盖其品种和周期；只有当前图表没有恢复出品种时，才用标签品种初始化。指标定义可以晚于布局注册，配置先恢复，注册后由同一投影链路挂载。

标签切换不销毁图表，移交标签保留同一 ID，因此刷新与跨窗口重新挂载都会读取原来的布局身份。关闭标签后的布局归档保留，避免移交与关闭的异步生命周期误删数据。

独立图表不传 layoutStorageId 时沿用默认归档。这里仅改变归档的寻址，不新增第二套保存实现，也不把所有标签重新接到共享的自动保存上。
