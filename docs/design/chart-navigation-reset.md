# 图表导航与视图重置

导航浮层位于 chartMain 底部中央、时间轴上方。鼠标进入底部按钮区域或键盘聚焦按钮时显示；触屏保持可见。

按钮只声明命令 id 和展示顺序。命令注册表持有名称、快捷键、可用条件和动作，按钮点击与键盘通过同一 execute 入口执行。Tooltip 订阅注册表的命令列表，改绑和移除快捷键后立即更新。

Core 的 resetTimeAxis 恢复初始缩放并复用 ChartDataManager.scrollToRight。该方法也是首次加载品种时的默认定位入口，因此重置遵循当前品种、当前数据和当前视口的默认定位规则，不保存易随前插数据、尺寸变化失效的 scrollLeft 像素快照，也不恢复切换品种前的用户视口快照。

resetChart 在一次 batch 中先恢复时间视图，再清除主图价格轴的手动范围。价格轴按恢复后的可见数据重新适配；Alt+R、导航重置按钮和其他调用方共用该入口。
