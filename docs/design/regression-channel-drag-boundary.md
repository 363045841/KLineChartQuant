# 回归通道拖拽的数据右边界

回归通道依赖两个端点之间的已有 K 线收盘价。通用拖拽允许锚点进入未来槽位，但回归计算遇到越界索引会返回空结果，使图元消失。

指针解析提供 clampDataEnd 选项，在坐标反解析和磁吸前将 X 限制在最后一根 K 线中心。回归通道的绘制预览、确认落点与单端点编辑共同启用此选项，保证实时预览持续显示，且不会保存 futureOffset。DragHandler 的整体移动也以最后一根 K 线中心为右边界，限制共同水平位移，保留端点间距。多选拖拽共用这一受限位移，保持图元之间的相对位置。边界按当前数据和坐标映射查询，不依赖端点存储顺序。

回归计算继续只接受有效数据索引，普通趋势线继续支持未来槽位。自动化用例覆盖正反端点顺序、单端点越界与回拖、整体平移、绘制预览及确认落点，以及普通趋势线行为。

坐标查询统一命名为 getXAtLogicalIndex：视口接口中的 X 表示屏幕横坐标，保留 LogicalIndex 区分逻辑槽位与数据下标。接口、委托实现、调用处及文档同步改名，坐标计算行为保持不变。
