# 持续交互期间的纵轴宽度

纵轴宽度统一由所有可见 Pane 的刻度与动态标签汇聚后提交。刻度数字位数、负号或单位变化可能使估算值在相邻宽度之间反复切换；若每帧立即收缩，纵向拖动就会反复改变绘图区的横向尺寸。

规则放在 Chart.commitAxisWidths，覆盖左右纵轴、主图与所有副图，不由指标或脚本决定。持续交互（拖动、捏合、惯性）期间，每侧提交宽度为配置下限、实际标签需求和当前宽度的最大值，因此可及时扩宽但不会收缩。估算器继续保存真实需求，不保存交互峰值；交互结束后的帧不再钳制到旧宽度，统一按实际需求收缩。

指针会话结束与惯性停止均申请一次 Overlay 帧，确保触屏、价格轴缩放、取消及没有后续鼠标移动的结束路径也能释放保留宽度。收缩继续使用既有帧内尺寸提交，避免重新引入尺寸变化与重绘分离的空白帧。
