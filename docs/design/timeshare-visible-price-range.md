# 分时纵轴按可见行情分配范围

原算法以昨收为中心对称分配上下限，并始终额外添加至少 0.5 个百分点。
低波动指数会因此被压成细线；跳空后即使日内波动明显，也会因昨收与当前价格的距离而留下大量空白。

新算法仅取当前可见价格与均价的最小值、最大值，每侧添加可见振幅的 10% 留白。
因此两条线的合计振幅占自动价格区间的约 83%，不受成交量、成交额或昨收距离影响。
昨收继续作为单日涨跌幅基准；五日分时继续使用第一日昨收。昨收不再保证位于轴中心，
超出可见范围的昨收线可以不显示。

只有所有有效值完全相同时，才按该价格绝对值的 0.01% 设置单侧留白；
零价格平盘使用单位参考价格。没有有限价格时不更新已有范围。
手动纵轴范围与平移缩放沿用现有机制。

回归测试覆盖低波动的不同价格量级、跳空、均价超出价格线、平盘、无效价格及五日基准。
