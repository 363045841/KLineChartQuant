# 脚本语义层：编译期转换与执行器、编辑器共用

指标脚本先经过一层**编译期语义处理**再进入运行时：类型检查、当前值语法糖的文本转换、参数声明推导。执行器（QuickJS 编译入口）与脚本编辑器（语言 Worker）共用这一层，区别只在谁喂源码。语义层的产出是**转换后的文本**，运行时的取数、绘图、错误语义完全不变。

## 边界

语义层负责：源码到虚拟文档的转换、目标类型的上下文判定、原文与虚拟文档的双向位置映射、参数声明推导、当前值读取记录。

语义层不负责：脚本执行与超时隔离、编辑器 UI 与协议适配、脚本 API 表面（注入到虚拟程序的全局声明）。

消费方只有两处：`quickjs` 的脚本编译入口，以及 `packages/vue` 中脚本编辑器的语言 Worker。

## 组成

| 模块 | 职责 |
|------|------|
| 语言会话 | 唯一的源码更新入口；同版本复用转换结果与类型程序，内部持有虚拟文件系统 |
| 类型环境 | 文件身份、语言级别、标准库（仅 ES2022，不含 DOM/Node）、脚本契约声明 |
| 参数推导 | 从脚本真实 `inputs` 推导参数声明，供数值上下文判定与类型查询使用 |
| 上下文判定 | 判断某个引用是否读取当前值，按父节点形态分派并回落到上下文类型 |
| 转换 | 一轮内收集候选、生成插入项；多轮收敛推导类型；记录被物化的引用 |
| 位置映射 | 原文与虚拟文档的双向映射；插入片段内部的位置收敛到对应原文边界 |
| 取值类型查询 | 按使用位置返回当前值表达式的类型，供语言服务显示 |

模块对外只有两个入口：创建会话、按位置查询当前值类型。文件身份与语言级别各自只有一处定义，转换规则、参数推导、判定规则都不在别处复述。

## 语义规则

当前值语法糖的判据是**目标类型**，不是标识符白名单：派生序列、用户别名与注入的行情序列遵循同一规则。

| 位置 | 语义 |
|------|------|
| 算术、比较、条件判断 | 读取当前值 |
| 要求数值或布尔的实参 | 读取当前值 |
| 要求完整序列的实参 | 保留序列 |
| 索引访问的基座、成员访问的基座、赋值左值 | 保留序列 |
| 显式标注了类型的声明 | 按声明处理，不参与推导 |

未标注类型的声明与未标注返回类型的函数，其类型由表达式推导而来，因此**当前值转换会反过来改变它们的类型**。转换必须多轮收敛：一轮里若某个推导类型会变成数值，对它的引用要等下一轮再判定，否则产出的代码过不了自身的类型检查。终止条件是某轮不再产生插入。

需要完整序列的位置始终保留序列；历史偏移访问不受转换影响。

## 数据流

两条入口汇入同一个会话：

- 执行器：脚本源码 → 会话 → 转换后文本 → 去类型转译 → QuickJS。
- 编辑器：文档变化 → 会话 → 虚拟 TypeScript 程序 → 诊断、悬浮、补全、签名。

参数声明每轮转换前刷新，因此执行器与编辑器看到相同的参数类型。

转换只在源码变化时发生：逐 bar 执行不做类型分析，也不重新转译。每个源码版本产出一次转换结果与一次程序增量更新，编译产物在注册层持有快照，行情重算复用。

## 对外契约

- 包入口 `./language` 只暴露会话工厂、当前值类型查询与脚本源文件身份；内部实现不作为公共面。
- 转换结果包含虚拟文档、插入项、当前值读取记录，以及双向位置映射。所有对外查询都必须经由这份映射换算位置。
- 编辑器侧只做协议适配：位置进入映射一次、返回结果映射回来。未装载文档的查询属于调用错误，不做兜底。
- 悬浮提示按**使用位置**显示类型：被物化的引用显示当前值类型，未被物化的引用显示语言服务原本的签名。判定由转换器给出，编辑器不重新识别语法糖。
- 全局声明必须与运行时注入形态一致。行情序列在运行时是 VM 全局对象上的属性，因此声明为全局变量而非常量，使 `close` 与 `globalThis.close` 解析出同一类型。

## 不变量

1. **单一事实来源**：文件身份、语言级别、转换规则、参数推导各只有一处定义，改语言级别不会漏改。
2. **只插文本**：转换以插入项拼出虚拟文档，不重新打印语法树；注释、格式与行号保持不变。
3. **没有静默降级**：映射缺失、类型程序缺失、转换记录与程序不一致，一律失败。区别于"该位置不属于当前值读取"这种合法情形，后者显式返回空。
4. **编辑器不产生第二套语义**：编译器分析出的结论以数据形式传给语言服务。
5. **声明等于运行时事实**：静态声明与实际注入形态不一致时，先修声明，而不是为它补一条解析分支。
