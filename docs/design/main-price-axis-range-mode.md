# 主图价格轴范围模式

主图价格轴使用 `auto | hand` 两种范围来源。

- `auto`：每帧依据当前可见数据计算并投影范围。
- `hand`（锁定价格对 K 线比例）：切换时将当前显示范围快照为 `handRange`；横向平移仍计算自动范围，但不改变显示范围。

`mainPriceAxisState` 是手动范围的唯一业务状态源；`PriceScale` 只投影该帧最终范围。绘图、K 线、Y 轴刻度和命中测试统一通过 `PriceScale` 的 `priceToY` 与 `yToPrice` 投影，避免为水平线引入屏幕坐标锚点或渲染层特例。

切换到 `hand` 后，主图允许纵向平移和右轴缩放；切回 `auto` 后清除手动变换并立即使用最新的 `autoRange`。

## 品种切换

手动范围只属于当前这次品种展示，不跨品种继承，也不按品种缓存。Kernel 在主品种身份变化时原子提交品种和清空手动范围，保留 `auto | hand` 模式偏好；身份沿用 `symbolSpecIdentityKey`，周期变化或相同品种的行情更新不触发重置。

空数据帧不初始化手动范围。新行情首个有效帧先计算该品种的自动范围，再清除 PriceScale 的纵向偏移和缩放，以新范围初始化 `handRange`；后续帧继续遵循手动范围。A → B → A 每次均重新初始化，即使行情 Buffer 已缓存，也不恢复旧价格轴状态。

锁定模式只保留模式偏好，不保留上一品种手动调整后的价格对 K 线比例。新品种首屏以自身可见行情的 Range 上下限初始化，让 Max、Min 均可见；之后用户可重新平移和缩放。

`handRange === null` 同时表示等待首帧初始化。在该阶段禁止价格轴交互写入范围或改变旧轴变换，避免切换后、绘制前的拖动将旧品种范围写回。只有渲染首个有效帧可以完成初始化；初始化后的交互继续通过 `setHandRange` 更新当前范围。
