# 图例半透明背景

OHLC、主副图指标标题及其他图例行以半透明背景叠加在行情上。背景使用现有主题 surface Token，保留 80% 底色和 20% 透明度，仅覆盖每行内容宽度；文字保持原有颜色和不透明度。

移除图例高度信号、布局订阅、顶部占位计算及行占位标记。图例展开、收起和指标增删不再修改价格坐标或主图裁剪边界。Pane 仅保留原有 `yPaddingPx` 视觉留白及常规内容边界。

统一行样式让 OHLC、主副图指标标题共享背景，明暗主题自动更新。背景不新增交互节点，沿用现有指针穿透和按钮交互规则。

行背景向左延伸 4px，并以同等左内边距保持文字位置不变，避免首段文字紧贴底色边缘。

数据层裁剪统一使用 Pane 的完整宽高，允许行情延伸到顶部和底部。价格坐标的 `yPaddingPx` 只负责映射留白，不定义绘制边界。

`FramePaint` 移除任意内容区 `clip` 输入，改为必填的 `bounds` 尺寸。Scene 是 Pane 裁剪矩形的唯一构造入口，Canvas、GPU 直出和 GPU 失败回退使用同一边界。GPU 批次必须保留所属边界，避免直出时丢失裁剪语义。分时绘制移除重复的 Pane 裁剪，沿用 Scene 的统一边界。

回归覆盖四种数据角色的完整上下边界，以及 GPU 成功和回退两条路径，防止价格映射留白再次被用作裁剪带。
