# 两条 Plot 之间的带状填充

填充区域必须贴合两条 Plot 的投影折线，不使用矩形或阶梯边界，也不向端点以外外推。

几何构造与 Canvas 重放分离，构造结果进入现有帧缓存。每对相邻有效点按两条边界的真实交点拆分，生成不自交的多边形；统一绕向，并将同色多边形放在同一路径中一次填充，避免透明度叠加和分次绘制的接缝。

颜色延续原始语义：相邻两点之间整段使用右端 bar 的颜色，不在中点切换。交点只决定几何，不推导颜色。右端颜色为 null 时整段留空。缺失任意边界点会断开连接，孤立点没有可填充的带状面积。

回归测试覆盖真实折线坐标、交点裁切、右端颜色整段覆盖、空值断开、同色批次、透明度和隐藏边界线。
