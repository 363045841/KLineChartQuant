# 绘图附属文字

## 背景

线和面积绘图需要展示用户输入的说明文字。文字必须随所属绘图的可见性、移动、删除和复制一起变化，不能成为独立绘图对象。组合图形（例如斐波那契回撤）由多条线组成，每条线需要独立的文本。

## 决策

文字持久化在所属 `DrawingObject.labels.line` 与 `labels.area`，键为定义输出的线段或填充区域序号，值为 `{ text, position }`。`position` 为 `start`、`center` 或 `end`，表示所属线段的语义起点、中点和终点，不使用会随绘制方向改变含义的屏幕 `left/right`。帧投影按图元定义的输出顺序，将每条文本附着到对应 `LinePrimitive` 或 `AreaPrimitive`；斐波那契回撤的每根水平线因此可独立拥有文本。

线文本锚定在原始两点的起点、中点或终点，沿当前屏幕线段的上侧法线偏移。起点使用左对齐，从锚点右侧展开；终点使用右对齐，从锚点左侧展开，避免覆盖锚点。旋转角度由当前屏幕斜率实时计算并规范到可读方向，因此缩放、拖动、延长线和视口裁剪不会污染持久化模型。

## 渲染与交互

绘图 Renderer 由宿主线图元直接绘制附属文本，不再将文本展开为独立 `TextPrimitive`。面积图元的文字在填充完成后以完整不透明度绘制，保证位于填充带上层。本设计不增加 Scene layer、RendererPlugin 或 GPU 文本管线。

用户将指针移入一条线或填充区域的当前标签热点时，Vue 宿主显示低对比度“+ 添加文本”提示；已有文本时显示当前文本。点击提示直接在该位置进入就地编辑，并选择起点、居中或终点；失焦或回车通过 `updateDrawing` 原子替换完整 `labels` 快照；提交空文本时从该快照删除对应条目。文字不是独立绘图对象，选中、拖拽和删除始终作用于所属绘图。

## 标签热点锚点

线段文本的绘制锚点与命中热点锚点必须来自同一布局函数 `resolveLineLabelLayout`（`packages/core/src/engine/drawing/labelLayout.ts`）：语义位置（`start`/`center`/`end`）沿当前屏幕线段的**上侧法线偏移 `LINE_LABEL_NORMAL_OFFSET`（6px）**。

热点除锚点外还携带绘制使用的水平对齐、基线与字号，宿主输入框据此摆放：锚点贴文本块的对应边（线段/箭头基线为 `bottom`，锚点即文本块底边；填充区域为 `middle`，锚点即文本块中心），并以同一锚点旋转。因此输入框与已绘制文字重合，不再压在线上阻塞线段本身的点选与拖拽。

热点半径（18px）大于偏移量，悬停线段本身仍可触发；指针进入输入框后不再重算命中，提示不会中途消失。填充区域的锚点仍是其包围盒中心。
