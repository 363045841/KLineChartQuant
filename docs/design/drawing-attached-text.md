# 绘图附属文字

## 背景

线和面积绘图需要展示用户输入的说明文字。文字必须随所属绘图的可见性、移动、删除和复制一起变化，不能成为独立绘图对象。组合图形（例如斐波那契回撤）由多条线组成，每条线需要独立的文本。

## 决策

文字持久化在所属 `DrawingObject.labels.line` 与 `labels.area`，键为定义输出的线段或填充区域序号，值为用户文本。该模型只保存用户内容，不保存位置、角度或可见区域等派生信息。帧投影按图元定义的输出顺序，将每条文本附着到对应 `LinePrimitive` 或 `AreaPrimitive`；斐波那契回撤的每根水平线因此可独立拥有文本。

线文本固定在原始两点之间的中点，沿当前屏幕线段的上侧法线偏移。旋转角度由当前屏幕斜率实时计算并规范到可读方向，因此缩放、拖动、延长线和视口裁剪不会污染持久化模型。

## 渲染与交互

绘图 Renderer 由宿主线图元直接绘制附属文本，不再将文本展开为独立 `TextPrimitive`。面积图元的文字在填充完成后以完整不透明度绘制，保证位于填充带上层。本设计不增加 Scene layer、RendererPlugin 或 GPU 文本管线。

用户将指针移入一条线或填充区域的中心热点时，Vue 宿主显示低对比度“+ 添加文本”提示；已有文本时显示当前文本。点击提示直接在该位置进入就地编辑，失焦或回车通过 `updateDrawing` 原子替换完整 `labels` 快照；提交空文本时从该快照删除对应条目。文字不是独立绘图对象，选中、拖拽和删除始终作用于所属绘图。
