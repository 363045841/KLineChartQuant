# 期权数据解读手册

本篇记录本仓库期权链路的行业口径、数据粒度与解读方法，供开发与日常分析共用。

## 1. 数据来源与粒度

- 采集器每分钟拉一次期权链（BTC/ETH 走 Deribit，SOL/BNB/XRP 走 Binance），聚合后写入 NAS 的 `options/aggregate/<CUR>/`；行里带 `venue`。
- alt（SOL/BNB/XRP）只有 10 天内的到期，且持仓比 BTC/ETH 小两到三个数量级：墙位与翻转位只能当薄数据参考，期限结构只有 2–4 个点。
- 一行 = 一次采样，含现价、近月与全链的翻转位、Γ 加权墙、OI 墙、最大痛点、净 GEX、P/C 持仓比、近月 ATM IV、DTE 与 ±1σ / ±2σ。
- 面板与 Agent 读的是「最新一行」；趋势读的是序列。
- schema 3 起每行带逐到期 ATM IV（期限结构）与 25Δ 偏斜；仍不落逐行权价 IV 全曲线。

## 2. 行业口径

| 指标 | 定义 | 参考 |
| --- | --- | --- |
| IV Rank | `(当前 IV − 窗口最低) / (窗口最高 − 窗口最低) × 100` | tastytrade |
| IV Percentile | 窗口内 IV 低于当前值的样本占比 | tastytrade |
| DVOL | 由微笑曲线导出的 30 天年化隐含波动率 | Deribit |
| 25Δ 风险逆转 | `IV(25Δ call) − IV(25Δ put)`，单位波动点；固定取 `7–90` 天里最接近 30 天的到期，两翼按 `|delta|` 插值 | CME |
| VRP | `隐含波动 − 已实现波动` | FlashAlpha |

两个要点：

- IV Rank 与 IV Percentile 要同时看。一次尖峰会把区间拉宽，IV Rank 掉下来而 IV Percentile 仍高。
- 股票用 252 个交易日做窗口；加密 7×24，按日历天，本仓库用 30 / 90 / 365 天三档。

## 3. 关键位的读法

| 项 | 口径 | 怎么读 |
| --- | --- | --- |
| Gamma 翻转 | 净 GEX 过零的现价 | 现价在上方为正 Gamma（对冲压制波动），下方为负 Gamma（对冲放大波动） |
| Γ 加权墙 | 该方向 OI×Γ 最大的行权价 | 日内对冲火力最密集处，主口径 |
| OI 墙 | 该方向持仓最集中的行权价 | 持仓分布口径，可能与 Γ 加权墙错位 |
| 最大痛点 | 使期权买方整体亏损最大的行权价 | 到期前的磁吸参考，不保证 |
| 净 GEX | 每 1% 价格变动的美元敞口 | 负值表示做市商对冲放大波动 |
| P/C 持仓比 | 看跌持仓 ÷ 看涨持仓 | 大于 1 偏防守，小于 1 偏进攻 |

口径冲突要明说：Γ 加权看日内对冲，OI 看持仓结构，两者错位时以 Γ 加权为日内主参考。

## 4. 净 GEX 是情景推演，不是真实承接

- 真实输入（Deribit 公开）：未平仓量、标记 IV、标的价格、行权价、到期时间、合约乘数（1 张 = 1 币）。Gamma 用黑 76 模型按 mark IV 与剩余期限现算。
- 假设输入：符号。净 GEX = Σ Γ × OI × 乘数 × 现价² × 1% ×（call 取 +1，put 取 −1），即假设「看涨持仓做市商多头 gamma、看跌持仓空头 gamma」。
- 交易所不公布做市商与客户的持仓拆分，真实 dealer 净敞口不可观测；所有公开 GEX 指标都建立在这类假设上。
- 因此：墙位与 Γ 加权分布可信；净 GEX 绝对值只作量级参考；翻转位是「该假设下的过零价」，符号反转则含义反转。
- 用法：同一币种看相对变化（例如净 GEX 从 −10M 变 −15M、翻转位上移）比看绝对值可靠。想少依赖假设，用 OI 墙 + 翻转位距离 + IV 分位。
- 翻转位算法：现价上下各 20%、41 个候选点扫描净 GEX 过零；偏离现价超过 10% 记为无有效翻转。

## 5. 波动的读法

- **ATM IV 只看变化与分位**，不看绝对值。
- IV 上升 = 市场为更大波动付钱；下降 = 情绪缓和或事件落地后回落。
- ±1σ / ±2σ 由 ATM IV 与 DTE 推出，描述「到期前一个标准差的期望范围」。
- 低 IV 分位不等于低风险：负 Gamma 贴墙时，实际波动可能超过隐含波动。
- 期限结构倒挂（近高远低）= 近期事件风险被定价；偏斜为负 = 下行保护更贵。
- 偏斜必须带期限：本仓库取 7–90 天里最接近 30 天的到期，不同期限的偏斜不能直接比大小（实测同期 0.83 天为 −6.89、38.83 天为 −5.07）。
- 期限结构看的是同一时点各到期的 ATM IV，不是历史分位；分位只回答「当前 IV 在窗口里的位置」。

## 6. 时效与限制

- 墙位与翻转位随现价与 Gamma 变化，分钟内会移动；OI 本身在交易所侧更新较慢，所以这些位是慢变锚点，适合当参照，不适合当日内触发信号。
- DTE 到期后整套价位重定价，旧墙位失效。
- 数据由 NAS 采集器与本地 8093 服务提供；任一未运行，面板与 Agent 都会显示取不到数据，不得沿用上一轮数字。

## 7. 交付给 Agent 的口径

- 分位必须带窗口与样本天数。
- 数字只引用，不自行推算。
- 墙是观察锚点，不是支撑阻力结论；翻转位只描述对冲行为，不决定方向。
- 不给入场、止损、目标价。
