# 图元复制

Canvas Toolbar 通过 ChartController.copyDrawings 复制单选或多选图元。
Agent 的 drawings_copy 工具调用相同入口，使用相同位置策略和撤回历史。

- geometry 层只解析位置，model 层复制完整图元配置并生成新的图元和锚点 ID。
- 副本可见且自身未锁定，全局锁继续生效；只选中副本。
- 整组副本和选中集合通过同一个 State Action 发布，命令层记录一条撤回历史。
- 默认向右偏移约 16 CSS px、向下偏移 48 CSS px。时间轴落在整槽位上，横向取最接近 16px 的槽位距离，至少移动一槽。
- 水平锚点只改价格，垂直锚点只改时间。多选使用共同偏移，保留相对位置。
- 对正向和反向的锚点出界量求和，选择出界较少的方向。跨度超过视口时优先保留组内几何关系。
- 任一图元或锚点不可解析时整批不写入；重复复制基于当前选中的副本。
- 保留全部持久化锚点，避免通道等图元的派生锚点在复制时被重新构造而变形。
