# 分时主图迁移统一原语引擎

自动纵轴范围必须同时包含可见价格、均价与有效昨收，再统一留白。
0% 参考线、涨跌面积和百分比轴使用同一昨收；全天上涨或下跌也不能把昨收裁到自动范围之外。
手动锁定轴范围继续尊重用户指定的范围；缺失昨收时不补造 0% 基准。

## 决策

单日与五日分时均采用 `draw-list` Layer，共享 `timeShareRendering` 投影与提交实现。
价格线、均价线、昨收参考线和涨跌面积全部提交公共原语；业务绘制层不持有 Canvas 上下文。
Scene 统一负责裁剪、层序、合批、GPU 直出和后端回落。

## 几何与生命周期

交易日和连续槽位分段继续由帧准备阶段提供，渲染器不重建交易时段规则。
投影保留世界 X、屏幕 Y；以数据版本、可见范围、横轴中心、纵轴映射、昨收与日/段边界决定复用。
主题和横向滚动在提交时绑定，不改变保留的几何。缓存属于 Layer，dispose 时释放。
无数据版本的独立调用每次重新投影，与其他已迁移渲染器一致。

面积在穿越昨收处插入准确交点，分成互不重叠的涨跌条带，使用 `fill.band` 直接绘制。
单日、日间、缺槽的边界均保持帧几何的分段；昨收缺失时只输出价格线和均价线。

## 公共渐变能力

`fill.fade` 表达屏幕逻辑 Y 上从原色到透明的线性衰减，允许向上衰减。
范围外钳制到 0/1，区间两端相等与不设置 fade 都表示纯色。
原色 alpha 和 fill.opacity 与衰减系数相乘；透明终点依靠真实背景合成，不混入主题背景 RGB。
Canvas 使用原色 RGB 的透明终点，避免向透明黑插值导致暗边；WebGL/WebGPU 在片元阶段按屏幕 Y 求透明度，保证跨越渐变边界时也正确。
GPU 网格顶点布局由共享常量定义，新增两个 float 保存渐变范围；直绘和 stencil cover 使用同一契约。
stencil cover 起始顶点也改为按共享布局计算，消除原有固定除以 6 与实际顶点步长不一致的问题。
浏览器验收同时修复 WebGL 离屏目标的原点差异：存储大于本批目标时，viewport/scissor 对齐左上角合成区域。
WebGL 解析式描边按每次 draw 的 first 实例绑定属性偏移，保证参考线、面积、价格线交错提交时不串批。

价格与均价使用屏幕空间、不透明、圆连接和圆端帽描边，满足现有 capsule SDF 路径条件。
Canvas 后端继续由浏览器描边；半透明颜色仍遵循统一引擎的三角化策略。

## 验证

单日/五日共用行为回归用例，检查无 ctx 输出、涨跌交点、昨收覆盖范围、交易日/缺槽断段、空数据与缓存更新。
删除基于 Canvas 调用次数和 GPU 内部布局的重复测试。渐变通过 bench 的真实浏览器像素用例验证，
覆盖三种后端、四种 DPR、正反向渐变、直接条带/stencil、GPU 直出和同一几何的渐变更新。
移除没有行情输入、依赖旧画布层结构并禁止可见 GPU 表面的过时整图合成用例；
小批次改为验证统一提交入口回落后的真实像素，性能基准只检查未重建几何，不绑定特定缓存命中数或 uniform 上传策略。
