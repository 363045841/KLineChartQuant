# 图表设置统一由布局持久化

图表设置曾同时写入 localStorage 和布局文档，两条链路的写入时机不同，恢复布局会覆盖另一份已保存的设置。

布局文档现在是图表设置的唯一持久化来源。所有内置设置和配色预设都随布局保存、复制和切换，包括渲染后端、行情缓存上限及 Canvas 性能分析开关。扩展业务元数据不属于布局配置。

`normalizeSettings` 只补齐默认值，不读取存储。删除原有图表设置存储入口及分层读取函数，不保留旧存储读取、迁移或双写逻辑。

恢复布局时替换整份设置，缺失项使用默认值，避免继承前一个布局的设置。新建布局使用默认设置；Vue 的显式 settings prop 仍按声明字段覆盖恢复后的布局设置。

界面提交直接更新内核，由布局管理器统一保存。工具栏、主题配色和性能分析开关读取内核设置，不维护另一份已应用设置，也不在挂载时回写默认设置。关闭布局自动保存后，设置修改需通过布局保存操作持久化。

原 localStorage 设置不再生效；已有布局缺少的三个字段恢复为默认值。验证覆盖布局切换、复制、新建及持久化后重新加载全部设置。
