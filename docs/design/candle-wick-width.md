# 影线宽度档位

影线按缩放级别选择固定物理宽度：第 1–9 级为 1 个物理像素，第 10 级及以上为 2 个物理像素，不随 DPR 增粗。
不按实体宽度渐进增长，也不超过粗档；缩小时切回细档。

实体宽度与影线保持相同物理像素奇偶性：不匹配时实体缩窄一个物理像素，实体至少与影线等宽。
细档在所有 DPR 下对应奇数宽，粗档在所有 DPR 下对应偶数宽。
两者共用对齐中心，偶数宽中心为整数物理像素、奇数宽中心为半整数物理像素；左右边界全部为整数物理像素。
此处仅调整绘制矩形，不改变槽位步长和指针缩放坐标。
实体和影线的位置、宽高、最小高度均在整数物理像素空间计算，最小实体高度为一个物理像素。
仅在向共享 Renderer/Canvas 接口输出矩形时按 DPR 换算坐标，Canvas、WebGL 和 WebGPU 消费同一组几何。
缩放级别加入投影缓存输入，即使实体宽度未变化，跨档位缩放也会重新生成影线。
