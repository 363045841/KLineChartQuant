# 分时成交量范围来自展示帧

分时量柱读取 `RenderContext.data`，原先 VOL 范围却由指标管理器的
`currentData` 合成。分时指标使用独立请求的 1min K 线计算，两份行情的
数量、索引和成交量可能不同；请求失败时甚至没有 VOL 范围。量柱因此
可能被错误的纵轴范围压缩或裁剪。

绘制帧将展示行情和可见区间传给 `createRenderStateReader`。
读取器直接派生该帧的 VOL 范围，按成交量实例身份提供给副图范围计算与刻度层。
VOL 不再写入异步指标计算结果投影，避免把计算行情当作展示行情。
其他指标继续读取已提交的计算结果。手动纵轴范围仍在自动范围之后应用。

回归测试覆盖没有指标计算结果、已有不同长度 K 线结果和空展示帧，
并检查其他成交量类指标不会被 VOL 范围覆盖。
