# 行情、计算与警报的所有权

应用组合根装配一个行情宿主、一份定义注册表、一个计算 Hub 和一套脚本服务。浏览器应用根调用 `provideBrowserAppRuntime`，工作台只读该注入。Node 进程使用相同的运行时工厂。布局 ID 只标识图表布局。警报规则按数据源、品种、周期和复权寻址，服务生命周期随宿主。

Web 页面与 Electron 渲染进程各自是一个浏览器宿主。一个宿主内的工作台共享服务。独立 Electron 窗口各自启动渲染进程，目前没有跨窗口的运行时协调。

K 线修订由 `MarketDataService` 在写入时发布。修订携带序列选择、数据变更、真实实时帧对应的时间，以及上游确认收盘的时间。计算 Hub 从唯一发布入口接收修订。图表只设置计算计划与展示投影，警报只保留所需行情的订阅租约。要求逐次接收结果的消费者保留中间修订，其余计算可合并等待更新。预览读取加入同一计算队列。

两端读取相同格式的脚本工作区。图表从定义的 Plot 声明生成渲染绑定。警报把规则状态和触发记录写进同一份文档，提交成功后才发布触发记录并发送通知。存储适配器在首次打开时将旧警报文档合并到应用级文档。
