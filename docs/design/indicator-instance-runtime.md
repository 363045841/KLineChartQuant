# 指标实例的单向运行时投影

公开实例命令在同一事务中写入指标实例与窗格配置。Kernel 是身份、归属、顺序、参数和显隐的唯一事实来源；指标分类只决定添加时的默认位置，不重新决定已存在实例的归属。

ChartIndicatorManager 从当前配置直接派生轴，并在一次渲染事务中释放原有实例资源、应用窗格布局、应用轴、同步计算输入、挂载全部可见实例和轴。所有窗格使用同一条实例生命周期链路，不再设主图与副图管理器。

不保存上一次实例投影、参数序列化键或已应用归属。运行时仅保留自己拥有的图层资源 ID，用于释放；它不参与业务决策。配置变化重新应用完整配置，不通过中间镜像决定是否传播。行情计算与帧几何缓存保留其计算用途，不决定实例位置。

系统行情图层由图表持有，跨视图保持资源身份，其可见性由 Kernel 的活动渲染器投影控制。用户实例无论处于主图或副图，都由同一资源入口挂载和释放。

业务定义只有一条装配主线：`defineIndicator` → 中立定义 → `createPlotIndicatorDefinition` → 定义对象注册 → 指标实例。Core 不再提供指标装饰器、定义类或装饰器扫描生成器，注册表直接接收 `IndicatorMetadata` 对象。

系统绘制不属于指标：主行情、最新价线、价格标签、极值标记直接注册为 Scene Layer；`CHART_VIEW_DEFINITIONS.systemLayers` 声明视图所需图层。不创建 `mode:*` 指标实例，不携带实例来源字段，不参与指标目录、计算、移动、模板或标题投影。系统与指标只共用底层 Scene / Layer，不共用业务定义模型。

窗格布局消费配置并管理画布资源；轴投影必须在目标窗格创建后执行。共享轴只复用同类型共享轴，不能与已占用窗格 ID 的独立轴合并。

多轴宽度只在同一窗格内相加；窗格垂直排列，图表右侧预留宽度取各窗格轴列总宽的最大值。不能将所有窗格的轴宽相加，否则实际绘制列之外会出现额外空白。

各窗格的自动、对数快捷入口只绑定第一条主轴。Core 在轴画布上发布主轴列的测量宽度，宿主按该列定位入口，不按整个多轴画布居中。

OHLC、分时行情、比较品种、指标与自定义标题先投影为不含坐标的行内容，再由 `layoutLegendRows` 在窗格内一次性分配连续行号。行情属于主序列标题，数据来自主行情，不注册成指标实例。各内容提供方不得保存行号或独立决定位置。

排序有两个独立动作：上移/下移副图通过窗格命令调整可见副图顺序；上移/下移指标只修改所属窗格内的实例顺序。按钮和执行入口共用相邻窗格解析规则，只有一个实例时不展示无意义的实例排序按钮。规则只读当前布局和实例集合，不区分指标的创建或迁移来源。

验证通过真实 Chart 和公开命令覆盖主图到副图、副图到主图、副图之间、上下新建、参数与显隐变化、源空窗格回收和最终资源释放，同时检查 Scene 图层与运行时轴，不能只断言配置写入。
