# 在绘制帧内提交视口表面尺寸

OBV 等指标纵向平移时，刻度文字变化可能改变自动轴宽，从而改变绘图区宽度。原来的 ResizeObserver 回调会立即执行 Pane 布局、改写 Canvas 的 width/height，同时视口状态 effect 也会立即调整共享 GPU 表面。浏览器在调整后备存储时自动清空像素，而重绘排在下一次 RAF，导致 K 线与最新价虚线出现空白帧。

Chart.resize 现在只记录待提交尺寸并使帧缓存失效。视口 effect 的 GPU 尺寸通知也进入同一入口，连续尺寸通知合并，保留当前已呈现像素。ChartRenderer 在非跳过帧的 render 阶段、收集 Pane 范围和绘制之前统一提交共享 GPU 表面与 Pane Canvas 的最新尺寸。尺寸变更与绘制处于同一次帧事务，继续保持原有正常的 Overlay 与 All 重绘语义。

尺寸变化时强制帧失效，避免尺寸提交后被内容版本判断跳过。帧几何仍由最新视口状态准备，Pane 布局在价格范围收集和交互几何封存前完成。初始化时尚无已呈现像素的首屏布局保持原有路径。

验证使用真实浏览器、原 OBV 脚本和真实行情，跟踪 Canvas 尺寸写入与最新价线绘制的顺序，确认尺寸变化均在 RAF 绘制事务中提交。
