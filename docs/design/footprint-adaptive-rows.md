# 足迹图自动分行

足迹图支持平均振幅、ATR、固定跳数三种分行方式，菜单按此顺序排列。足迹显示模式默认按最近 20 根已收盘 K 线的平均振幅除以 10 决定行高。目标行数默认 10，不设置人为范围限制；计算只要求正整数，以保证行数与除法有意义。固定模式继续使用 `ticksPerRow`；直接调用计算器且只传入 `ticksPerRow` 时，含义仍为固定跳数。

自动模式排除序列末尾的活跃柱。平均振幅为统计窗口内 `high - low` 的算术平均；ATR 复用现有 Wilder 算法，包含相对上一根收盘价的跳空。样本不足时使用已有已收盘柱；没有已收盘柱或振幅为零时使用 1 tick。

行高按最接近的 tick 整数倍取整，最低为 1 tick。整个序列共用统一价格网格，避免相邻柱的同价位无法比较。目标行数描述典型柱的价格跨度，实际有成交的行数取决于每根柱的振幅和成交分布。

有效行高纳入成交聚合缓存身份。统计参数、收盘或切换周期引起行高变化时，按新价格网格重放已有成交批次；行高不变时继续复用增量聚合结果。网格变化也重新计算对角不平衡，成交总量与 Delta 保持不变。实时活跃柱的振幅变化不调整网格。

参数表由 `DEFAULT_SETTINGS` 提供给 UI 和控制器，并随图表设置持久化。`visibleWhen` 从设置草稿推导可见项：仅足迹模式显示足迹参数；固定分行显示每行价格跳数，平均振幅和 ATR 显示统计根数与目标行数。切换模式保留隐藏参数值。渲染器消费 `FootprintSeries.rowSize`，文字是否显示仍由屏幕行距和柱宽决定。

足迹图使用 `role: 'overlay'` 和 `RENDERER_PRIORITY.OVERLAY`，成交行、价位数字与 Delta 统一绘制到 `overlayCtx`。主图 Canvas2D 在底层，GPU K 线画布在中间，覆盖画布在上方；仅修改 Scene 的 z 无法跨画布改变叠放顺序。足迹图参加覆盖画布刷新，在同一覆盖画布内按 z 排序绘制，避免柱和文字被 GPU K 线遮挡。

不平衡判定固定按成交量与相邻价位档比较，与 `metric` 展示口径无关，避免成交额把价格高低当成主动买卖强弱。聚合阶段对每档同时保留成交量和成交额，`metric` 只改变展示数值与 Delta/总量；切换口径复用同一份成交量聚合缓存，只重算已渲染柱子，不重放成交。
