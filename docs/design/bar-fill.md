# Fill 逐 bar 颜色

Fill 的颜色和 Plot 的数值一样，是逐 bar 计算结果。脚本每次调用输出当前 bar 的 CSS 颜色或 null；null 和未调用的 bar 都不绘制。颜色中的 alpha 直接决定透明度。

`PlotFill` 保存边界引用、整列显隐和稠密的 `colors` 序列。采集器按名称登记填充，每次调用写入当前下标；同一名称的边界和显隐必须固定。未提供 title 时由 from/to 生成名称，不同 title 可以引用同一对边界。

原生指标的 fill.color 回调也逐 bar 执行，接收主题颜色、位移后的两条边界值和图表下标。上下关系及颜色判断由指标实现决定。

渲染器把相邻两根 bar 的边界连成区域，使用右端 bar 的颜色。交叉形成的两侧区域使用同一颜色，不计算交点或按曲线上下关系改色。任意一个边界点缺失时该段不绘制；颜色为 null 时不延续前一颜色。

`options` 只保留整列 visible。透明度由 CSS 颜色表达，逐 bar 隐藏由 null 表达。渲染器不提供反转颜色、隐式透明度或默认颜色。渐变重载不属于本次实现范围。
