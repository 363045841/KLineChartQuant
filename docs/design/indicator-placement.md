# 指标位置的单一来源

指标定义的 category 决定主图或副图，脚本的 pane 在注册时转换为同一份定义。用户配置只保存实例身份、布局身份、参数、顺序与隐藏状态，不保存 role 或实际 paneId。

指标状态存储用户配置和模式系统配置，computed 统一生成运行时实例。用户实例的 role 从定义读取，主图 paneId 固定为 main，副图 paneId 使用独立布局身份。未注册的定义暂不产生运行时实例，目录发布后自动参与投影，不猜测位置。

Pane 状态只存布局偏好；有效副图集合从指标实例投影派生，布局偏好提供尺寸、顺序、可见性和轴类型。缺少布局偏好的副图自动生成，已无指标内容的副图不进入有效布局。绘图、图例、价格范围和交互共用这份派生结果。

添加指标 API 仅接收定义 ID 和参数，调用方不能指定位置。布局文档版本为 2，旧文档不恢复，不提供迁移分支。持久文档中的 Pane 配置不保存 role 或 capabilities。
