# 主图实例绘制层挂载

普通数值指标使用 Plot；需要专用状态的指标可以声明自己的 Layer 工厂。主图指标管理器统一负责指标实例的启停与绘制层装配。足迹属于独立的 K 线显示模式，见[足迹显示模式](footprint-display-mode.md)，不经过此链路。

`IndicatorMetadata.mainPane` 是可选的模式启停转换声明，不是主图渲染能力标记。首次挂载不能要求此字段存在，否则专用定义可能只产生计算结果和图例，却没有实际绘制层。首次启用与参数更新必须遵循相同的挂载规则。

主图实例协调负责判断实例角色、模式来源及隐藏状态；挂载函数只需解析定义并创建该实例绑定的 Layer，不再以 `mainPane` 是否存在作为门槛。专用计算器、状态投影和工厂声明的 overlay 角色继续由各自模块拥有。

回归验证通过主图 Plot 指标的实际状态和绘制行为检查挂载链路，防止仅有结果和重绘请求的测试漏过此问题。
