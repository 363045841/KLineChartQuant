# 主图实例绘制层挂载

Footprint 使用逐笔成交聚合器、专用状态投影和 overlay Layer；普通数值指标使用 Plot。两者目前共享指标实例的启停与绘制层装配。

`IndicatorMetadata.mainPane` 是可选的模式启停转换声明，不是主图渲染能力标记。主图管理器在首次挂载时要求此字段存在，会让 Footprint 等专用定义只产生计算结果和图例，却没有实际绘制层。参数更新路径没有相同判断，也造成首次启用与更新行为不一致。

主图实例协调负责判断实例角色、模式来源及隐藏状态；挂载函数只需解析定义并创建该实例绑定的 Layer，不再以 `mainPane` 是否存在作为门槛。专用计算器、状态投影和工厂声明的 overlay 角色继续由各自模块拥有。

回归验证覆盖首次启用 Footprint 后 Layer 已挂载，并将真实成交聚合结果通过挂载的 Layer 绘制到覆盖画布，防止仅有结果和重绘请求的测试漏过此问题。
