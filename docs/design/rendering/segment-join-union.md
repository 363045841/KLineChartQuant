# 折线解析式描边的拐角并集

## 问题

指标线折点在视觉上像"小结"：线身是柔和的 1px 抗锯齿边，拐点却是一圈实心硬边，折点密集时整条线像串珠。

原因是解析式描边逐段独立成实例，而圆角连接靠胶囊端帽实现：相邻两段在公共顶点生成的是**同一个圆盘**（半径等于半宽），每个像素被两段各输出一次覆盖率，再按预乘 over（`ONE / ONE_MINUS_SRC_ALPHA`）混合：

```
c + c(1 − c) = 2c − c²
```

圆盘内部 c=1 时两次混合仍是 1，所以看不出问题；但抗锯齿带里的 c 落在 (0,1)：0.5 变 0.75，0.8 变 0.96。于是拐点圆盘的一圈软边被压成硬边，与线身的软边形成明显反差。实测最大偏差 0.25，受影响像素正好落在每个顶点的圆盘外缘。

这不是参数问题：`aa = 1/dpr` 与线宽只决定结的大小和软硬，改变不了"同一像素被覆盖两次"。收窄抗锯齿带只会让结更硬，放宽则结更大。

## 决策

一个实例仍是一段折线，但覆盖率按**并集**算，并且每个像素只归一个实例。

1. **实例携带相邻端点**：每段写入 `起点、终点、前一点、后一点、半宽、颜色、数据空间标记`，共 14 个 float。前一点取最近的不同点（重复点没有方向），折线首尾没有相邻段时填自身。
2. **四边形覆盖三段 capsule**：vertex shader 把 `{prev, start, end, next}` 变换到屏幕空间后取轴对齐包围盒，外扩 `halfWidth + 1/dpr`。不再按线段方向拼紧致四边形，因为相邻段的距离也要参与覆盖率。
3. **覆盖率取并集距离**：`distance = min(capsule(prev,start), capsule(start,end), capsule(end,next))`，退化段自然退化成点，端帽仍是圆。
4. **像素归属按端点角平分面切分**：相邻两段用同一个法线 `normalize(u_prev + u_this)`，末端取背面（含平面本身），起始端严格取正面。共享圆盘因此被对半分，既不重叠也不留缝；平面上恰好取整的像素归末端，避免两端都保留而重新引入双混合。

退化处理：

- 折线首尾没有相邻段：法线为零向量，片元里 `dot(bis,bis) > 0` 为假即不裁剪，整圆端帽保留。
- 180° 折返：`u_prev + u_this` 为零，角平分面不存在，改用与两段都垂直的 `normalize(u_prev − u_this)`。相邻两段用同样的入参和同样的表达式，算出同一个平面，归属仍然互补。
- 相邻点重复：准备器向前/向后取最近的不同点，避免角平分面退化成零向量而误裁掉半个端帽。

数据空间折线在着色器里先做帧变换再算角平分面，与覆盖率使用同一个屏幕空间；滚动与轴缩放仍然只改 uniform。

## 取舍

**为什么不是一条折线一个实例、片元里对全部线段取最小距离**：那样并集是精确的，但每条线每个像素要遍历全部点，1px 指标线在整屏宽度上等于每像素上千次距离计算，成本不可接受。

**为什么不是 stencil 并集或目标级 MSAA**：这两条正是解析式描边要替代的路径。stencil 并集需要逐折线铺 cover（全宽指标线每帧多出若干次全幅填充），MSAA 让整个目标为少数边缘付 4 倍采样。解析式描边的存在前提就是"用距离场换几何"，所以必须在距离场内部解决重复混合。

**为什么不是只让关节圆盘由一段负责、另一段改 butt 端**：改动最小，但圆盘外缘与另一段侧边相切处仍会各混合一次，留 1~2px 的双混合缝，属于治标。

**成本**：实例从 10 个 float 增至 14 个 float（稳态滚动下准备器跳过重写，不上传）；片元从 1 次距离计算增至 3 次；四边形从紧致胶囊盒改为三段包围盒，多出的片段在归属测试处直接丢弃。指标线填充面积小，这三项都不改变帧成本量级。

**已知近似**：归属平面只约束同一条折线里相邻的两段。折线自身在两像素内折返（两条几乎重合的平行段）时，两个不相邻的实例可能同时拥有同一个像素，那里仍会多混合一次（1px 折返实测最大偏差 0.25、无空洞）；三段窗口也可能漏掉更远的线段。这类自接近在指标线上不构成可观察差异，换来的是一份可预测的固定成本。

**不透明门槛不变**：半透明折线仍走三角化 + stencil。归属+并集已经不再依赖不透明度，但把半透明折线切到解析式描边会同时改变其边缘质量与自交叠色，属于独立决策。

## 验证

- `primitives/__tests__/prepare.test.ts` 覆盖 14 float 实例布局、`offsetX` 只扣一次、重复点回退到最近不同点，以及路径引用不变时跳过实例重写。
- 浏览器人工验收：MA 这类折点密集的指标线在拐点处不再出现硬边小结；折线首尾的圆角端帽、接近 180° 的折返、数据空间折线滚动与价格轴缩放都保持原样。
