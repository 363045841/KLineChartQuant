# 描边覆盖率区域：胶囊与凸四边形

## 问题

解析式描边最初只接管"不透明、实线、圆角连接 + 圆端帽"的开放折线。这个集合是按着色器好写的程度挑的，不是按成本或语义挑的：

- 指标线全在这个集合里，所以它们有抗锯齿；
- 画线图元（趋势线、射线、通道、箭头翼）用的是默认的平头端帽 + 尖角连接，被挡在集合外，退回三角化；
- 目标级 MSAA 是关闭的（`docs/design/scene-owned-composition.md`），三角化边缘没有采样平滑，于是斜直线在屏幕上就是像素台阶。

同一张图里两套线、两种观感，是这条边界切错的直接后果。

第一阶段的修复（逐段胶囊 + 角平分面归属）解决了圆角折点重复混合：

```
c + c(1 − c) = 2c − c²
```

相邻两段在公共顶点画的是**同一个圆盘**，边缘 c=0.5 会被压到 0.75，看起来像串珠小结。但那只覆盖了圆角一种连接方式。

## 决策

一个描边原语按样式选择两种**覆盖率区域**，共用同一个实例缓冲、同一个着色器程序：

| 区域 | 几何 | 连接 / 端帽 | 归属 |
| --- | --- | --- | --- |
| `capsule` | 每段一个胶囊 | 圆角 + 圆端帽 | 端点角平分面切分，像素只归一个实例 |
| `polygon` | 每段一个凸四边形 | 尖角 + 平头/方头 | 相邻段共享同一条切边，互不重叠，不需要归属 |

选择规则（`strokeRegions.ts` 的 `strokeRegion`）：

- `join === 'round' && cap === 'round'`、非虚线 → `capsule`；
- `join === 'miter' && cap ∈ {butt, square}` → `polygon`；
- 其余（闭合路径、`bevel`、圆角尖角混用、数据空间折线、半透明）→ 三角化。

### 凸四边形的切边

每段描边的区域由两条切边夹住，两条切边分别取在该段的两端：

- 端帽：平头是过端点的垂线，方头整体外推一个半线宽；
- 折点：取相邻两段**同一侧偏移线的交点**。左右各有一个交点，两者连线就是折点切边，且必然经过折点。

相邻两段对同一个折点算出的是同一对交点，所以两段共享同一条切边：四边形恰好拼接，既不留缝也不重叠。像素只会落在一个四边形里，因此不需要归属判断，也不会重复混合——拐角处的抗锯齿来自四边形自身的距离场。

两个退化处理：

- **近共线折点**（`|sin δ| < 0.02`）：两侧偏移线几乎重合，直接用过折点的垂线切割，与极限位置一致；
- **斜接超限**：斜接长度与半宽之比为 `1 / cos(δ/2)`，超过 `miterLimit` 时把两个交点沿角平分线按同一比例收回。收回后仍落在两条段的内侧，四边形保持四个角、两侧仍共用同一条切边。三角化路径在这种情况下画的是斜切（bevel），两者在最尖的角上有亚像素级差异，实测影响 2 个像素。

### 数据布局

实例仍是 14 个 float：四个点、半宽、颜色、标志位。胶囊把四个点解释为「起点、终点、前一点、后一点」并填半宽；四边形把四个点解释为角点，半宽写 0。标志位一个 float 承载两个标记：bit0 是数据空间，bit1 是凸四边形区域（`SEGMENT_FLAGS`）；合用一个字段是为了给 WebGPU 的顶点属性上限留出余量。片元按解码后的区域分支。

覆盖率为 `clamp((半宽 + 0.5px − 距离) / px)`，两种区域共用同一个公式：四边形自带线宽，所以半宽为 0 时自然退化成"内部为 1、外部 1px 过渡"。

## 取舍

**为什么不用凸多边形接管填充。** 凸多边形距离场同样可以给填充边缘抗锯齿，但填充的绝大多数边界被同色描边压住，优先级低于线；非凸、自交、多轮廓的填充靠 stencil 并集，片元里没有距离信息，SDF 无从下手。填充是否接入单独决策。

**为什么不开目标级 MSAA。** MSAA 的成本按目标面积付，与画了多少内容无关：主图带 1200×700 @ dpr 2 约 340 万像素，4× 颜色缓冲约 54MB，再加 resolve，滚动时每帧都要付。绘图层内容极少，却同样要按整块面积付，性价比最差。解析式覆盖率只按被覆盖的像素付。

**为什么保留胶囊而不是全部改成四边形。** 圆角连接的并集是圆盘，用四边形表达不了；而指标线（圆角、数据空间、每帧数千点）正是胶囊路径的主要用户，它按段一个实例、不需要额外几何。

**精度。** 四边形距离场取"四条边的最短距离 + 内外判定"，是精确的欧氏距离（不是半平面取最大值那种近似），因此抗锯齿带宽度与理想形状一致。与 8×8 超采样的真实形状覆盖率对比：平均偏差 0.0002~0.0015，最大偏差 0.23（出现在斜向平头端帽的角点），局部重叠只发生在相邻四边形的抗锯齿带内，且重叠处相邻边已是满覆盖率，观感无差。

## 验证

- `rendering/primitives/__tests__/strokeRegions.test.ts`：区域选择矩阵；平头/方头端帽；直角折点的切边坐标；两侧切边逐值相同（拼接不重叠）；近共线垂切；斜接上限收回；虚线展开；重复点剔除。
- `rendering/primitives/__tests__/prepare.test.ts`：15 float 实例布局、共享折点写入同一组端点、四边形区域标记。
- 浏览器人工验收：画线图元的斜直线、折线拐角、箭头翼在 webgl / webgpu 后端都有 1px 过渡；指标线观感不变。
