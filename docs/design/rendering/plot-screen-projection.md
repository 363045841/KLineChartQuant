# Plot 的屏幕坐标与柱体基线

Plot 层负责把价格转换为 pane 内的屏幕 Y 坐标，折线与填充共享投影结果。
描边的线宽、端帽和连接使用逻辑像素，不能仅因上下文存在 dataTransform 就发送原始价格。
移除 Plot 层的数据空间分支，避免把不支持的数据空间描边送入 GPU 三角化路径。
投影缓存统一包含 Y 轴范围、刻度类型、padding 和 pane 高度；这些输入变化时重新投影。
代价是轴缩放时重新构建折线几何，保持现有保留几何缓存与公共 GPU 描边算法。

柱图和直方图的 baseline 若构成可见值域的某一侧边界，该侧不再添加数值留白。
正成交量从零起算，顶部仍有留白；负柱体对称处理，跨基线数据两侧均保留留白。
混合折线与 drawing 仍按完整值域判断边界，显式 range 声明继续最后应用。

验证覆盖有 dataTransform 的折线提交坐标，以及正、负和跨零柱体范围。
