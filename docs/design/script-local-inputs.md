# 脚本局部输入参数

脚本在 `onBar` 顶层通过 `const period = input.int(20, { min: 1 })` 声明参数，不再公开 `inputs` 对象或 `params` 全局。

编译器以变量名作为稳定参数身份，将默认值和选项提取为初始化注册语句，将调用替换为参数读取。配置只接受常量字面量，禁止在分支、循环和辅助函数内声明，因此空行情注册时也能生成完整面板，无需运行指标计算。

内部继续使用共享输入元数据供参数面板消费。数值范围和步长沿 `InputDef`、`IndicatorInputDef` 传递到面板，默认值只保留在输入定义中。用户修改参数后重新计算时，局部变量读取宿主覆盖值。
