# 分时面积渐变底色

`drawAreaFill` 的渐变终点使用主题 `colors.chartBackground` 的同色 0 透明度值，不再写 `rgba(0, 0, 0, 0)`。

Canvas 渐变会插值颜色通道：从 `rgba(213, 19, 26, 0.15)` 这类基准色收敛到透明黑时，中段 RGB 会向黑色偏移，面积在浅色画布上偏灰、在深色画布上发暗。终点换成背景色的同色透明值后，颜色只在 alpha 上收敛，面积看起来直接融进画布。

背景色通过 `ctx.fillStyle` 的 getter 规范化成 `#rrggbb` 或 `rgba(...)` 后再取 RGB 通道，因此主题预设与颜色覆盖的任意合法写法都落到同一结果，渲染端不需要各自解析颜色字符串。

单日分时与五日分时共用同一实现；五日按交易日分段绘制时，每段同样向背景收敛。

同一模块的昨收虚线按横坐标区间绘制：单日分时用可见画布的左右边界，两端不再内缩到首尾数据点；五日分时用各自交易日的区段边界。
