# 期权关键位参考：OI 墙与 Γ 加权墙

本文是使用手册，不是采集口径的规格。采集与字段的口径见
[option-collection.md](./option-collection.md)，主图指标的实现见
[option-script-api.md](./option-script-api.md)。

## 1. 这份文档解决什么问题

期权面板会同时给出两条墙位（Call/Put 各一条），一条标「Γ 加权」，一条标「OI」。
两者经常不在同一个行权价上，看盘时容易误判成数据出错。

本文说明：两者各算的是什么、为什么不一样、在什么尺度上可信、怎么用于观察与过滤。

## 2. 四个术语

| 术语 | 含义 | 单位 |
| --- | --- | --- |
| OI | 未平仓合约数，某行权价上还在生效的合约张数 | 张 |
| Γ（gamma） | 标的价格每变 1 美元，delta 变化多少；衡量「调仓速度」 | delta/USD |
| Γ·OI | 该行权价上所有合约的 gamma 总和，代表「价格动 1 美元要买卖多少」 | 无 |
| GEX | 净 gamma 敞口，按 call 记正、put 记负，乘上 `S² × 1%` 换算成美元 | USD / 1% |

翻转位（Gamma flip）是「净 GEX 过零的现价」。现价高于翻转位是正 gamma，低于它是负 gamma。

## 3. 两条墙位分别是什么

| 字段 | 口径 | 回答的问题 | 时间尺度 |
| --- | --- | --- | --- |
| `callWall` / `putWall` | 该方向**原始 OI 最大**的行权价 | 仓位堆在哪 | 日线、周线 |
| `callGammaWall` / `putGammaWall` | 该方向**Γ·OI 最大**的行权价 | 对冲流集中在哪 | 日内 |

面板把两条都列出来，主图指标与快速解读只用 Γ 加权墙。理由是主图是分钟级看盘工具，
需要的是当天真有对冲行为的位置。

## 4. 为什么两条会分开（实测）

2026-11-14 23:40 左右，BTC 现价 65,327，近月桶 2026-11-20（DTE 5.5）：

| 行权价 | Call OI | Call Γ·OI | Put OI | Put Γ·OI |
| --- | --- | --- | --- | --- |
| 70,000 | 120 | 0.0066 | 1,843 | 0.1014 |
| 73,000 | 3,114 | **0.0651** | 192 | 0.0040 |
| 76,000 | 3,154 | 0.0247 | 396 | 0.0031 |
| 80,000 | 729 | 0.0026 | 52 | 0.0002 |

- 76,000 与 73,000 的 call 张数几乎相同（3,154 对 3,114），但加权值差 **2.6 倍**。
- 原因只有距离：现价到 73,000 是 11.8%，到 76,000 是 16.3%。DTE 5.5 天、IV 约 49% 时
  一倍标准差只有 6%，16.3% 已在约 2.7 倍标准差外，那边的 Γ 接近 0。

机制：Γ 按行权价呈钟形，平值附近最大，越远衰减越快。远端大持仓多是彩票仓，持有者不动，
做市商不需要调仓；近端持仓哪怕少一半，Γ 也大几倍，做市商每动一档就要买卖现货。

## 5. 一个反直觉但重要的事实

**Γ 加权墙会随现价移动，OI 墙不会。**

- 现价 65,850 时，Put 的 Γ 加权墙是 70,000。
- 现价跌到 65,327 后，65,000 的权重升到 0.1071，高过 70,000 的 0.1014，Put 加权墙跳到 65,000。
- 同期 Put 的 OI 墙一直是 70,000。

推论：Γ 加权墙适合日内跟随，OI 墙适合看结算目标；把 Γ 加权墙当成「不变的支撑阻力」会反复出错。

## 6. 读法：先定基调，再看墙位

第一步看翻转位与现价的关系，它决定当天波动是被放大还是被压制。

- 现价 < 翻转位（负 gamma）：做市商对冲是反着价格做的，跌了卖、涨了买，波动被放大。
- 现价 > 翻转位（正 gamma）：反过来，跌了买、涨了卖，波动被压制，区间更容易维持。

基调确定后，再按用途选墙：

| 用途 | 用哪条墙 | 读法 |
| --- | --- | --- |
| 日内边界 | Γ 加权墙 | 靠近时对冲流集中，穿过之后波动常加速 |
| 结算目标 | OI 墙、最大痛点 | 到期日前后，价格向持仓密集处靠拢的概率更高 |
| 突破有效性 | 两条都看 | 收在 Γ 加权墙外侧，且 GEX 更负，才算脱离原区间 |
| 假突破识别 | Γ 加权墙 | 冲过墙位又快速收回，说明对冲流把价格推了回去 |

四条可立即使用的检查：

1. **两墙相距很远**：日内对冲焦点与月度结算焦点不一致，突破更容易来回扫。
2. **DTE 变小**：Γ 加权墙更尖、更有效；OI 墙磁吸增强，两者逐渐重合。
3. **IV 突然抬升**：Γ 整体下移，远端权重掉得更快，墙位向现价靠拢。
4. **P/C 高 + 负 GEX**：put 侧持仓重，下跌时做市商卖压更集中。

## 7. 容易误读的地方

| 误读 | 事实 |
| --- | --- |
| 墙位是挂单，可以撤 | 期权 OI 是持仓，不撤单；但会因平仓减少，大额平仓能让墙位一夜消失 |
| OI 盘中会变 | Deribit 在 UTC 08:00 附近更新 OI，盘中几乎不动 |
| Γ 加权墙 = 铁顶/铁底 | 它随现价移动，越靠近越强，穿过后反而可能加速 |
| 正 gamma 一定震荡 | 前提是做市商净空头期权；真实库存反过来时符号会解读错 |
| 只看 Deribit 就够 | ETF、现货、其他交易所的对冲不在这个口径里 |

还有两个数据层面的坑：

- **单一大户可能主导一个行权价**。看到某档持仓异常集中，先怀疑是不是单独一笔头寸。
- **P/C 与 GEX 的分子分母不同**：P/C 是全部持仓比，GEX 是资金加权后的净敞口，两者矛盾时先信 GEX。

## 10. 结构判断（脚本层，已上线）

面板 ④ 卡片与「快速解读」胶囊共用 `describeOptionStructure(view)`，输出三行：

| 行 | 内容 | 例子 |
| --- | --- | --- |
| 基调 | 现价与翻转位的关系、gamma 状态标签、净 GEX 与 DTE | `现价 65,180 在翻转位 68,563 下方 4.94%（负 gamma · 顺势放大 · 净 GEX -10.9M · DTE 5.5 天）` |
| 走廊 | 上下最近的参考位（翻转位 / 两条加权墙），需要时补一条同侧更远的墙 | `下方紧贴 Put 对冲带 65,000（−0.28%）；上方 反转界 68,563（+5.19%）；远端 Call 对冲带 73,000（+12.00%）` |
| 注意 | 按重要性最多三条：贴着参考位、两墙错位、临近到期、P/C 与净 GEX 矛盾 | `Put 两条墙相差 7.7%（65,000 对 70,000），日内焦点与结算焦点不一致` |

口径说明：

- 「紧贴」阈值 0.5%，「两墙错位」阈值 5%，DTE 提示阈值 1 天。
- 三行是条件描述：说「破哪里换基调」，不说「会涨到哪」。
- 没有翻转位时退回墙位口径；没有现价时只给「期权数据暂不可用」。

## 11. AI 解读层（设计建议，未上线）

结论来自外部评审（Gemini 4 Argon）：**AI 不要重复 L2 已报的数字**，只补两类增量——
跨指标矛盾识别、结构失效条件推演。

### 分工

| 层 | 负责 | 禁止 |
| --- | --- | --- |
| 脚本（L2） | 现价锚点、走廊、口径错位、到期与矛盾提示 | 预测方向、给点位建议 |
| AI（L3） | 指出最突出的跨指标矛盾、说明改变结构的具体价位与条件 | 重述单值、自己算百分比、给入场/止损/目标价 |

### 提示词骨架（两行输出，≤110 字）

```text
【角色】你是加密期权微观结构审阅员，只汇报脚本未覆盖的背离与临界条件。
【输出】严格两行：
- 【博弈焦点】<一句话指出最突出的跨指标矛盾，必须带原数字>
- 【切换边界】<一句话说明触碰哪个具体价位会改变当前对冲性质>
【禁止】自行心算百分比；出现「入场/做多/做空/止损/目标价/抄底/必涨/必跌/必然」；
只允许条件句（「若…则更容易…」）。
【兜底】各指标同向时只输出：当前结构同向，无背离，沿用区间观察。
```

### 质量校验（可自动拦截）

1. **黑名单正则**：命中 `做多|做空|开仓|平仓|止损|止盈|目标价|建议|必然|必涨|必跌` 即丢弃 AI 输出，回退到 L2 三行。
2. **数字白名单**：抽取 AI 输出里的所有数字，必须全部出现在传入的格式化数字集合中。
3. **边界完整性**：必须含至少两个原始价格，且「切换边界」行命中 `若|一旦|突破|跌破|守住|失守` 之一。

### 现状

- 已实现：L2 三行结构 + 胶囊里写死的解读约束（只解读结构、只引用已有数字、条件句、无点位建议）。
- 未实现：L3 输出校验（黑名单与数字白名单）——需要接管模型回复的渲染路径，暂缓。

## 12. 什么还没验证

- **壳层**：没有对墙位或正负 gamma 做过历史检验。本项目订单流面板做过同类检验（去重后胜率 49.8%，无统计优势），期权部分尚未做。要做需要积累 30 天以上快照，测「未来 N 小时价格是否向最近墙位靠拢」。
- **口径假设**：GEX 符号沿用「做市商净空头期权」的通用约定，真实库存可能相反。
