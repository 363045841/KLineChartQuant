# K 线槽位导航边界

K 线与对比视图保留统一的槽位坐标网格，过去和未来槽位仍能参与十字线与指针缩放计算。
可导航视口由视图策略限制：两侧空白空间各最多一屏，数据至少有两根时，视口必须保留两根完整 K 线实体。
数据不足两根时保留全部已有 K 线；视口窄到无法容纳两根实体时，将可保留的数据居中。

策略在每次投影时按数据长度、视口宽度与物理像素几何计算 `scrollBounds`，并约束输出滚动量。
导航使用同一边界，因此拖拽、原生滚动、程序导航、缩放、数据缩减和尺寸变化都遵循相同规则。
DOM 内容两侧各预留一屏，内容宽度不再随滚动请求无限增长。

缩放先保存鼠标下的连续槽位坐标，用目标网格求解滚动量。
若解位于合法区间，鼠标槽位保持不动；若超出边界，只将滚动量修正到最近边界，允许缩放中心向左或向右偏移。
普通单日分时和多日分时继续采用各自的视图策略。
