# 主图指标绘制使用实例身份

脚本定义的 position 可以在保存时从副图改为主图。位置由定义派生，已有实例的 instanceId 保持不变，计算结果与图例也继续按该身份读取。

主图 Layer 创建和参数更新时直接传入当前实例的 instanceId，不再根据指标定义 ID 拼接 `main:` 前缀。这样绘制层和计算层使用同一身份，副图迁入主图后也能读取 Plot 数据。

新建主图实例的身份分配集中在实例 API。修改参数、替换主图定义和整体更新主图集合均保留已有实例 ID。Layer 投影记录同时比较实例 ID 与展示参数，实例改变后重新绑定绘制层。

渲染工厂契约要求显式传入实例身份。通用 Plot 和专用指标 Layer 不再接受缺失 instanceId 后静默跳过，也不再保存默认 pane 作为底层补偿；位置由上层实例投影传入。

状态快照要求调用方提供 instanceId，不再以 `legacy:窗格ID` 补造身份。副图新增入口通过实例 API 分配独立 ID，已有副图更新和替换保留原身份。测试读取 API 返回的身份，不依赖窗格 ID 推算实例 ID。

回归测试沿用已有脚本更新用例，将副图定义迁入主图，保留原实例身份并调用实际 Layer 绘制，断言折线产生绘制指令。
