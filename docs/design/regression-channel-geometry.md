# 回归通道几何设计

## 问题

回归区间按数据索引从小到大拟合，但旧实现把拟合线的起点和终点按锚点数组顺序绑定。用户从右向左拖拽时，左侧拟合值会被写入右侧锚点，导致上涨区间显示为下降趋势。渲染和命中测试还各自复制了一份这套计算，修复容易再次分叉。

## 决策

回归模型统一以数据索引为坐标轴。先在 `[min(anchorIndex), max(anchorIndex)]` 上拟合，再用每个真实锚点的索引计算拟合值：

`value(index) = intercept + slope * (index - minIndex)`

因此锚点顺序只决定几何端点归属，不改变趋势方向。渲染和命中测试都调用 `computeRegressionChannel`，共享数据有效性、sigma 和端点映射规则。

回归使用中心化最小二乘计算，避免价格较大时直接累加 `x²` 与 `x*y` 造成数值误差。残差标准差仍采用总体标准差 `sqrt(sum(residual²) / n)`，保持通道宽度语义稳定。

## 边界规则

- 少于两个样本、非有限价格或越界索引不生成几何。
- 非有限或负 sigma 使用默认值 2。
- 两个锚点可以按任意方向创建，端点价格始终绑定实际索引。
