# 价格轴范围与逐轴状态

## 范围模式

价格轴只有一份范围状态，模式决定每帧是否重新拟合：

| 模式 | 界面文案 | 行为 |
|------|----------|------|
| `all` | 全部数据 | 指标、绘图、足迹、比较都参与轴范围 |
| `bars` | 仅缩放价格图表 | 只取可见 K 线 |
| `ratio` | 固定 K 线占比 | 只取可见 K 线，按 `PRICE_AXIS_RATIO_SHARE`（70%）向上下留白 |
| `manual` | 手动 | 不再拟合，停在切换时保存的范围 |

`all` / `bars` / `ratio` 是自动口径，`manual` 就是「自动」没勾的状态。自动口径的全部取值由
`AUTO_PRICE_AXIS_RANGE_MODES` 声明，界面顺序与校验共用这一份。

`ratio` 的范围是 `振幅 / 占比`，上下等分留白；振幅为 0（平盘）时保持基准本身。它与投影层的
`yPaddingPx` 无关：占比只定义轴范围，像素内缩照旧。

`bars` / `ratio` 只描述行情本身，只对主价格轴开放。可用与否只由一条能力决定：该轴当前模式是否按可见
K 线定轴（`ChartModeHandler.fitsPriceBars`）。可用集合由轴配置（`configuration().availableRangeModes`）
下发，宿主按它渲染菜单，不自行判断视图或轴角色；分时没有可拟合的 K 线，因此只有 `all` / `manual`，
状态里残留的 K 线口径按全并执行，条件恢复后自动生效。

## 逐轴独立

范围状态以轴 ID 为键原子保存 `rangeMode` 与 `range`：

- 自动口径下 `range` 为 `null`，轴范围每帧由收集结果直接投影；
- 手动模式把切换时的显示范围写进 `range`，之后平移 / 缩放只修改它；
- 品种变化清空所有 `range`、保留模式，首个有效帧按全并口径回填。

每个轴的 `rangeMode` 随布局文档的 `panePriceAxisModes` 切片持久化，手动模式的 `range`
写入 `panePriceAxisRanges`。自动口径不保存范围，恢复后由当前行情重新拟合。

## 纵向交互

绘图区拖动在所有 Pane 中共享时间视口的横向滚动；纵向平移与轴缩放只修改按下时所在 Pane，
且该轴必须处于 `manual` 并已有保存范围，否则拒绝写入。运行时轴只投影内核范围，不参与交互。

指标图形与指标刻度只读取 Pane 的当前显示范围，不向 `getDisplayRange` 传入自动范围。

## 品种切换

手动范围只属于当前这次品种展示，不跨品种继承，也不按品种缓存。Kernel 在主品种身份变化时
原子提交品种并清空范围，保留模式；身份沿用 `symbolSpecIdentityKey`，周期变化或相同品种的行情
更新不触发重置。

空数据帧不初始化手动范围。新行情首个有效帧先按全并口径算出候选范围，再写入该轴；
A → B → A 每次均重新初始化，即使行情 Buffer 已缓存，也不恢复旧价格轴状态。

## 轴栏按钮

每个轴底部有自己的 A / L 悬停快捷按钮。A 控制自动开关（勾选回到 `all`，取消进入
`manual`），与刻度类型独立；L 选中表示对数轴，再次点击取消选中切回常规价格轴。
主图百分比选项只保留在设置菜单。按钮的位置使用 Core 轴画布的实际几何，随调整高度和排序变化。
相关菜单、重置与滚轮缩放见 [价格轴菜单与滚轮交互](price-axis-interaction.md)。
