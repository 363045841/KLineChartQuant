# 价格轴范围与逐 Pane 状态

## 主图范围来源

主图价格轴使用 `auto | hand` 两种范围来源。

- `auto`：每帧依据当前可见数据计算并投影范围。
- `hand`（锁定价格对 K 线比例）：切换时将当前显示范围快照为 `handRange`；横向平移仍计算自动范围，但不改变显示范围。

`mainPriceAxisState`（历史命名，实际承载逐 Pane 状态）是手动范围的唯一业务状态源；`PriceScale` 只投影该帧最终范围。绘图、K 线、Y 轴刻度和命中测试统一通过 `PriceScale` 的 `priceToY` 与 `yToPrice` 投影，避免为水平线引入屏幕坐标锚点或渲染层特例。

切换到 `hand` 后，主图允许纵向平移和右轴缩放；切回 `auto` 后清除手动变换，立即改用 `PriceScale` 逐帧计算的自动范围。

## 逐 Pane 独立

刻度类型复用 `kernel.pane.paneScaleTypes`，快捷命令仅写目标 Pane。主图设置只决定主图，副图默认线性，不再继承主图对数设置。已有工作区快照继续保存各 Pane 的刻度类型。

主副图快捷按钮与菜单统一调用逐 Pane 轴命令。选中态和渲染均读取 Pane 状态；主图设置仅记录用户偏好，不用于判定轴命令是否需要执行。恢复工作区后，即使偏好已经为 Linear、实际刻度为 Log，关闭对数命令仍必须更新实际刻度。主图命令完成后向宿主通知当前偏好，用于保存设置。

范围状态以 Pane ID 为键原子保存 `rangeMode` 和 `handRange`。主图原有范围信号由这份状态派生。关闭自动时锁定该 Pane 当前显示范围，开启自动时清除手动范围和纵轴变换。渲染时先计算对应数据的范围，再应用该 Pane 的手动范围。品种变化清除所有手动范围，保留模式；移除 Pane 时释放状态。每个 Pane 的 `rangeMode` 随布局文档的 `panePriceAxisModes` 切片持久化，切换到对应布局时恢复各轴自动/手动开关；具体 `handRange` 价格值属于本次展示，不落盘，恢复后由首个有效帧初始化。

绘图区拖动在所有 Pane 中共享时间视口的横向滚动；纵向平移仅修改按下时所在 Pane，且该 Pane 必须处于 HAND。不再通过主图 ID 限制纵向平移。

指标图形与指标刻度只读取 Pane 的当前显示范围，不向 `getDisplayRange` 传入自动范围。指标状态里的极值仅用于 Core 自动范围计算，避免绘制时旁路覆盖手动范围。

## 品种切换

手动范围只属于当前这次品种展示，不跨品种继承，也不按品种缓存。Kernel 在主品种身份变化时原子提交品种和清空手动范围，保留 `auto | hand` 模式偏好；身份沿用 `symbolSpecIdentityKey`，周期变化或相同品种的行情更新不触发重置。

空数据帧不初始化手动范围。新行情首个有效帧先计算该品种的自动范围，再清除 PriceScale 的纵向偏移和缩放，以新范围初始化 `handRange`；后续帧继续遵循手动范围。A → B → A 每次均重新初始化，即使行情 Buffer 已缓存，也不恢复旧价格轴状态。

锁定模式只保留模式偏好，不保留上一品种手动调整后的价格对 K 线比例。新品种首屏以自身可见行情的 Range 上下限初始化，让 Max、Min 均可见；之后用户可重新平移和缩放。

`handRange === null` 同时表示等待首帧初始化。在该阶段禁止价格轴交互写入范围或改变旧轴变换，避免切换后、绘制前的拖动将旧品种范围写回。只有渲染首个有效帧可以完成初始化；初始化后的交互继续通过 `setHandRange` 更新当前范围。

## 轴栏按钮

每个轴底部有自己的 A / L 悬停快捷按钮。A 控制范围来源，与刻度类型独立；L 选中表示对数轴，再次点击取消选中切回常规价格轴。主图百分比选项只保留在设置菜单。按钮的位置使用 Core 轴画布的实际几何，随调整高度和排序变化。齿轮设置入口只保留一个，位于轴栏最下方；轴类型与范围菜单操作主图，位置菜单控制整个价格轴栏左右摆放。相关菜单、重置与滚轮缩放见 [价格轴菜单与滚轮交互](price-axis-interaction.md)。
