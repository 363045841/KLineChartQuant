# 轴视图统一提交

轴身份属于 Pane 内的量纲组。指标跨 Pane 迁移时，源组失去最后一个对象就释放轴，目标组创建或复用轴；不能假设对象迁移后仍使用同一条轴。

StateKernel 是业务配置唯一来源。RuntimeProjectionCoordinator 按 Pane、轴绑定、轴配置、指标图层的顺序投影，收敛提交期间的再入更新后，统一发布 paneGeometry。每条轴列同时包含身份、配置和几何，布局模块不再独立发布宿主状态。帧测量得到新宽度后仍经过协调者发布，未完成或失败的资源投影不能发布视图。

发布时依据已安装的有效轴重排列，复用仍有效轴的测量宽度；新轴由列布局算法分配空间，下一帧再提交实际测量。轴列布局同时写入 Pane，画布、命中和宿主控件共享列几何。

Vue 只通过信号桥读取这份已提交视图，不保存轴配置，不独立订阅范围和类型后反查运行时轴。菜单目标使用 getter，展示和命令都从当前视图解析目标。轴已从视图移除但 Vue 尚未卸载旧控件时，菜单禁用，延迟到达的点击不提交命令。严格轴 API 继续对显式访问不存在轴的程序调用抛异常。

工作台捕获子组件异常后向宿主报告，不再把任何局部异常都转换成永久失败状态并卸载整个工作台。
