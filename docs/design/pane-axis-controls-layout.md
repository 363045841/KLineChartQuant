# Pane 轴控件与公共右轴宽度

右轴总宿主承载 Core 画布与 Vue 控件，占满整图高度，分隔线和底角都到底。`PaneAxisControls`
是每个 Pane 的控制层，消费 Core 已提交的 top / height / axisWidth；它内部按 `axisColumns`
为每条轴渲染一个 `PaneAxisSettings`，入口绑定的轴就是它所在的那一列，菜单不再列轴供用户选择。
原先挂在价格轴与时间轴交叉处的整图单一入口（`PriceAxisSettingsMenu`）已删除。悬停快捷按钮
（自动/对数）属于 Pane 级控件，向上让出 24px 避免覆盖列底部 20px 的设置入口。

所有 Pane 共用右侧栏宽度。逐轴标签宽度决定每条轴的最低需求，剩余宽度由该 Pane
第一条轴吸收，保证单轴 Pane 的文字和快捷按钮都居中于完整右栏。多轴 Pane 继续按列布局。
原先只为最宽 Pane 补齐宽度，会使其它 Pane 的画布、文字中心和公共右栏不一致。

右轴宿主占满整图高度，分隔线和底角都到底。轴列控制层按**上下界**分区，不按"高度"定位：
带子上界是本 Pane 的 `top`，下界是下一个 Pane 的 `top`；最后一个 Pane 没有下一条，直接用
宿主的 `bottom: 0`。于是最后一条带子自然覆盖底部时间轴在右轴上的那一行，代码里不出现
`bottomAxisHeight`，也不必给最后一条写特判。槽设置入口贴这条带子的底部；悬停快捷按钮属于
绘图带，仍在各 Pane 自己的 `height` 内、距带底 24px，不会跟着落进时间轴那一行。

Core 在布局和轴列提交后都发布 paneGeometry，控件使用与画布相同的已提交宽度；
Vue 不读取 DOM 反推尺寸，不添加另一份宽度计算。轴列几何逐列参与相等比较：列宽不变但列的
轴身份变化时同样重发，避免入口指向已经换掉的轴。
