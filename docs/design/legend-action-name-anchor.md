# 图例操作框以指标名定位

主图与副图共用 DOM 图例渲染器。原操作框以整行文本宽度定位，按钮出现在全部参数与数值之后。

将首个文本片段作为名称放入独立定位容器，操作框挂载在名称容器内，沿用名称宽度加按钮区宽度的布局。后续参数、数值、加载态与错误提示保留在可裁剪文本容器中。悬停和键盘聚焦时，名称容器的层叠上下文让操作框覆盖后续参数，按钮紧跟名称，不随参数或实时数值的宽度变化而移动。

定位完全由 CSS 完成，继续复用文本节点，不读取布局。按钮能力、事件入口及主图收起行为仍由原有领域契约管理。

名称容器采用 Flex 居中对齐，名称在继承的行高中与参数和操作按钮保持中心对齐，避免主图行高大于文字行高时名称偏向顶部。

首段参数的 gapBefore 由名称与参数容器之间的 gap 实现，不再用参数容器内部的负 margin 补偿，避免左括号越过裁剪边界而消失。后续片段继续按文本流间距处理。
