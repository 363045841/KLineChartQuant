## 相比 v0.10.1 的变更 / Changes since v0.10.1

### ✨ 新功能 / Features
- **对比模式建模为独立图表模式**: 将对比（comparison）从数据视图提升为独立的图表模式，集中处理其模式切换、渲染器归属与状态派生，并新增设计文档 `docs/design/comparison-chart-mode.md`。

### 🐛 Bug 修复 / Fixes
- **离开分时后恢复 K 线视口**: 修复从分时图返回 K 线后位置与缩放不恢复的问题——分时宽度与 K 线缩放宽度解耦（`timeShareKWidth` 仅在分时视图生效），视口快照改为按标的/周期/复权/视图键存储 `anchorTimestamp + offsetPx + zoomLevel`，并在 `setCurrentPeriod`、`setSymbols` 与首帧数据到达时恢复；新增设计文档 `docs/design/data-view-viewport-snapshots.md`。
- **WebGPU 后端渲染成交量柱**: 修复 WebGPU 后端下成交量柱不渲染的问题。

### 🏗️ 架构与重构 / Architecture & Refactoring
- **引入视图与周期常量**: 新增 `ChartDataViewId`（kline/timeshare/comparison）与 `TIME_SHARE_PERIOD` 常量，替换散落的字符串字面量，统一视图模式与数据周期两种语义。

### 📚 文档 / Documentation
- **刷新 README 预览图链接**: 更新各 README 与 fragments 中的预览图链接。
