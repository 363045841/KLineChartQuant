## 相比 v0.11.0 的变更

### ⚠️ Breaking Changes & Migration

- **市场数据标识统一为 `instrumentType`**：`InstrumentDescriptor.assetClass`、`SourceCapabilities.assetClasses` 和 `AssetClass` 枚举分别改为 `instrumentType`、`instrumentTypes` 和 `InstrumentType`；`isFilterableAssetClass` 改为 `isFilterableInstrumentType`。迁移：更新字段名、枚举导入与筛选辅助函数；`unknown` 仍表示不参与筛选。([73f1d866](https://github.com/363045841/KLineChartQuant/commit/73f1d866))

### ✨ 新功能

- **指标模板**：把当前图表的指标组合保存为具名模板，支持应用、重命名、删除、最近使用和跨品种复用；保存前可移除本次不写入模板的指标。([#369](https://github.com/363045841/KLineChartQuant/pull/369), [#372](https://github.com/363045841/KLineChartQuant/pull/372))
- **工作区标签页**：Web 与桌面端共享标签页，统一顶部工具栏和绘图价格区间。([#367](https://github.com/363045841/KLineChartQuant/pull/367))
- **K 线密度与图表交互**：新增紧凑 / 标准 / 宽松三档密度，支持绘图复制粘贴、Ctrl 拖拽复制、Shift 45° 锁角、命令导航与重置时间轴。([#355](https://github.com/363045841/KLineChartQuant/pull/355))
- **实时订阅池与自选分组**：实时订阅统一到共享连接池，自选按来源或品种分组并显示报价，绘图磁吸与手柄能力统一。([#352](https://github.com/363045841/KLineChartQuant/pull/352))
- **桌面端**：升级 Electron 45，新增自定义标题栏，并打包 gotdx / Binance 后端。([#347](https://github.com/363045841/KLineChartQuant/pull/347), [1114f7ce](https://github.com/363045841/KLineChartQuant/commit/1114f7ce))
- **市场时段与图表样式**：统一市场时段查询；新增折线、面积与全宽高低点样式；Mock 数据源支持连续日线。([0bab7c24](https://github.com/363045841/KLineChartQuant/commit/0bab7c24), [99286202](https://github.com/363045841/KLineChartQuant/commit/99286202), [f877620e](https://github.com/363045841/KLineChartQuant/commit/f877620e))

## Changes since v0.11.0

### ⚠️ Breaking Changes & Migration

- **Market data identity now uses `instrumentType`**: `InstrumentDescriptor.assetClass`, `SourceCapabilities.assetClasses` and the `AssetClass` enum are renamed to `instrumentType`, `instrumentTypes` and `InstrumentType`; `isFilterableAssetClass` becomes `isFilterableInstrumentType`. Migration: update the field names, enum imports and filter helper; `unknown` still means no filtering. ([73f1d866](https://github.com/363045841/KLineChartQuant/commit/73f1d866))

### ✨ Features

- **Indicator templates**: save a named combination of the chart's indicators and apply, rename, delete or reuse it across symbols; indicators can be removed before saving the template. ([#369](https://github.com/363045841/KLineChartQuant/pull/369), [#372](https://github.com/363045841/KLineChartQuant/pull/372))
- **Workspace tabs**: shared tabs for web and desktop, with a unified top toolbar and drawing price ranges. ([#367](https://github.com/363045841/KLineChartQuant/pull/367))
- **K-line density and chart interaction**: compact / standard / loose density presets, drawing copy-paste, Ctrl-drag duplicate, Shift 45° angle lock, command navigation and time-axis reset. ([#355](https://github.com/363045841/KLineChartQuant/pull/355))
- **Realtime subscription pool and watchlist groups**: shared realtime connection pool, watchlist grouping by source or instrument type with quotes, unified drawing magnet and handles. ([#352](https://github.com/363045841/KLineChartQuant/pull/352))
- **Desktop**: Electron 45, custom title bar, and bundled gotdx / Binance backends. ([#347](https://github.com/363045841/KLineChartQuant/pull/347), [1114f7ce](https://github.com/363045841/KLineChartQuant/commit/1114f7ce))
- **Market sessions and chart styles**: unified market session lookup; line, area and full-width high-low styles; continuous daily bars from the mock source. ([0bab7c24](https://github.com/363045841/KLineChartQuant/commit/0bab7c24), [99286202](https://github.com/363045841/KLineChartQuant/commit/99286202), [f877620e](https://github.com/363045841/KLineChartQuant/commit/f877620e))

### 🐛 Fixes

- **Indicator selector**: lists every registered indicator and picks up script definitions immediately. ([#368](https://github.com/363045841/KLineChartQuant/pull/368))
- **Theme colors**: preserve runtime `light-dark()` colors and add the `color-scheme` anchors required by consumer builds. ([0722c92e](https://github.com/363045841/KLineChartQuant/commit/0722c92e), [5053b926](https://github.com/363045841/KLineChartQuant/commit/5053b926))
- **Entry stylesheet**: keep the entry stylesheet when consumers tree-shake. ([21492e09](https://github.com/363045841/KLineChartQuant/commit/21492e09))
- **Time-share and rendering**: include the previous close in automatic price ranges; fix first-paint layout shifts, legend background padding and axis-width jumps during zoom. ([97e3d6fe](https://github.com/363045841/KLineChartQuant/commit/97e3d6fe), [54333551](https://github.com/363045841/KLineChartQuant/commit/54333551), [9b6261f1](https://github.com/363045841/KLineChartQuant/commit/9b6261f1), [#355](https://github.com/363045841/KLineChartQuant/pull/355))
- **Workbench script service**: share the page-level script service across workbenches. ([24843596](https://github.com/363045841/KLineChartQuant/commit/24843596))
- **Template registration**: resolve template indicators through the unified registration pipeline so missing definitions no longer break templates. ([2b6d826c](https://github.com/363045841/KLineChartQuant/commit/2b6d826c))

### 🏗️ Architecture & Refactoring

- Converged indicator registration into one pipeline and removed the old `registerIndicatorDefinition` / `registerPlotIndicator` paths. ([99e13d02](https://github.com/363045841/KLineChartQuant/commit/99e13d02))
- Migrated time-share rendering to unified primitives; desktop now runs the shared workbench with a persisted market host. ([5c6295a4](https://github.com/363045841/KLineChartQuant/commit/5c6295a4), [211c7544](https://github.com/363045841/KLineChartQuant/commit/211c7544))
- Removed unused rendering helpers and deduplicated symbol picker / popover surface code. ([72007623](https://github.com/363045841/KLineChartQuant/commit/72007623), [#355](https://github.com/363045841/KLineChartQuant/pull/355))

### ⚡ Performance

- Unified incremental execution for SVP / PVP, reducing script and rendering memory. ([#363](https://github.com/363045841/KLineChartQuant/pull/363))
- Reused zoom geometry per frame, reducing per-frame recomputation and pixel jitter. ([#355](https://github.com/363045841/KLineChartQuant/pull/355))

### 📚 Documentation

- Added the indicator template design document and removed stale architecture documents. ([#369](https://github.com/363045841/KLineChartQuant/pull/369), [725dd254](https://github.com/363045841/KLineChartQuant/commit/725dd254))
