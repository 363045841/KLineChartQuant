# 相比 v0.11.0-alpha.2 的变更 / Changes since v0.11.0-alpha.2

## ✨ 新功能 / Features

- **Provider 配置与模型池管理**: Rename and delete saved Provider profiles with hover actions, and rebuild the cross-Provider model pool on a single shared CRUD writer.
- **模型选择移至输入区底栏并支持内联搜索**: Move model selection into the composer footer with inline search, syncing context window, max tokens, and reasoning efforts.
- **Provider 草稿自动持久化**: Persist Provider drafts automatically.
- **模型上下文能力**: Use model context capabilities.
- **Dropdown 搜索过滤**: Add searchable mode to Dropdown for model filtering.
- **展示 Provider 原始错误**: Surface error.raw from OpenAI-compatible responses in the Agent UI.
- **联网搜索与统一工具注册表**: Add the unified runtime tool registry with a web search tool and a citation rendering pipeline.
- **外部服务分区与 Exa API Key**: Merge the settings and tools dialogs, add collapsible Provider / External Services / Tools sections, and move the Exa API key into External Services.
- **用量与运行状态 UI 打磨**: Refine usage and run status UI.
- **指标选择器新增清除按钮**: Add a clear button to the indicator selector.
- **UI 控件背景 token**: Add colors.ui.controlBackground for triggers and inputs.
- **对比品种 CRUD 统一写原语**: Add comparison symbol CRUD through the unified primitive API, resolving instruments and registering specs before writing.
- **绘图文本换行改用字面量 `\n`**: Use literal `\n` for drawing text wrap and remove width-based wrapping.

## 🐛 Bug 修复 / Fixes

- **修复右侧边缘像素对齐**: Fix right-edge pixel alignment in the viewport.
- **对比错误码补齐恢复提示**: Add recovery hints for the new comparison error codes.
- **按装饰器方法身份路由图表工具**: Route chart tools by decorated method identity so primitive this binding is correct.
- **不持久化回退 contextWindow**: Prevent persisting the fallback context window to localStorage.

## 🏗️ 架构与重构 / Architecture & Refactoring

- **UI 语义 token 统一（破坏性）**: Unify generic UI chrome on colors.ui semantic tokens, add shared BaseButton / BaseTabs / SegmentedTabs, and rename --klc-color-agent-* to --klc-color-ui-* (BREAKING).
- **抽取共享 SymbolPopover**: Extract a shared SymbolPopover for the symbol and comparison pickers.
- **移除旧 Provider 版本兼容**: Remove legacy Provider settings version compatibility and use profile.connection directly.
- **Provider 连接与模型状态拆分**: Separate Provider connection state from model selection state.
- **RuntimeToolRegistry 重命名为 RuntimeToolCatalog（破坏性）**: Rename RuntimeToolRegistry to RuntimeToolCatalog with a check() predicate.
- **ChartController 测试替身收窄**: Narrow the Vue/Angular ChartController mocks to the consumed surface.
- **AI runtime 包废弃**: Deprecate klinechart-ai-runtime in favor of klinechart-agent-runtime.

## 🔧 工程 / Engineering

- **忽略 Serena 项目数据**: Ignore Serena project data.
- **移除 viewport resize observer 调试日志**: Drop the viewport resize observer debug log.
