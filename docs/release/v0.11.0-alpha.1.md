## 相比 v0.10.4 的变更 / Changes since v0.10.4

### ✨ 新功能 / Features
- **AI Agent 运行子系统**: 新增 agent-runtime 与 AI runtime，支持 OpenAI Responses 协议与浏览器内对话；新增真实 302.ai Provider 与持久化原生 Pi runtime，Web 与 Electron 共享同一 Agent 工作区。
- **AI Agent runtime subsystem**: Adds agent-runtime and AI runtime with OpenAI Responses protocol support and in-browser conversations, a real 302.ai provider, a persistent native Pi runtime, and a shared Agent workspace across web and Electron.
- **@Tool 注册基础设施**: 引入 @Tool 注册基础设施、只读工具迁移与工具启用中心；新增行情查询 API、缓存中间件与运行稳定性保障（#139、#142）。
- **@Tool registration infrastructure**: Introduces the @Tool registration infrastructure, read-only tool migration, and a tool enablement center; adds market query APIs, a cache middleware, and run stability guarantees (#139, #142).
- **绘图 Agent 工具**: 注册绘图 Agent 工具，建立绘图声明式 CRUD 边界，支持可修正错误与统一写链路。
- **Drawing agent tools**: Registers drawing Agent tools with a declarative CRUD boundary, recoverable errors, and a unified write pipeline.
- **五天分时图**: 新增五日分时图表与加载逻辑，支持水平平移缩放，基线锚定首日昨收价（#136）。
- **Five-day timeshare**: Adds five-day timeshare rendering and loading with horizontal pan and zoom, with the baseline anchored to the first-day previous close (#136).
- **分时指标原生支持**: 分时指标原生支持，并按视图隔离指标与布局。
- **Native timeshare indicators**: Adds native timeshare indicator support with per-view indicator and layout isolation.
- **持久化视图工作区**: 持久化视图工作区并在启动阶段投影渲染。
- **Persistent view workspaces**: Persists view workspaces and projects their rendering at startup.
- **图表 Agent 门面**: 新增稳定的图表 Agent 门面与精简指标输出。
- **Chart agent facade**: Adds a stable chart agent facade and compact indicator output.
- **多 Provider 配置**: 支持多个 Provider 配置档案与流式推理输出。
- **Multiple provider profiles**: Supports multiple provider profiles and streamed reasoning output.
- **共享 UI 组件**: Agent 会话与模型选择器迁移到共享 Dropdown，新增 floatingSurface token 统一浮层色彩；新增交互式窗格头部操作组。
- **Shared UI components**: Migrates session and model selectors to the shared Dropdown, centralizes agent UI colors into theme tokens, and adds an interactive pane header action group.

### 🐛 Bug 修复 / Fixes
- **Agent 对话与流式体验**: 保留连续对话上下文，修复首条用户消息重复与流式期间的强制自动滚动；工具错误转为可恢复结果供模型反馈；预览构建从源码解析 agent-runtime 根路径。
- **Agent conversations and streaming**: Preserves continuous conversation context, fixes duplicate first user messages and forced auto-scroll during streaming, converts tool errors into recoverable results, and resolves the agent-runtime source root in preview builds.
- **绘图锚点与分页**: 绘图锚点按交易日匹配并统一分页游标为时间戳。
- **Drawing anchors and pagination**: Matches drawing anchors by trading day and unifies pagination cursors as timestamps.
- **图例清理**: 数据视图切换时清理并过滤主图指标图例。
- **Legend cleanup**: Cleans up and filters main-pane indicator legends when switching data views.
- **比较序列历史加载**: 可见范围出现缺口时触发比较序列历史加载。
- **Comparison history loading**: Triggers comparison history loading when the visible range has gaps.
- **Dropdown 交互**: 支持外部点击关闭与弹出层越界上翻。
- **Dropdown interactions**: Closes on outside clicks and flips teleported popups upward when out of viewport.
- **比较视图坐标与品种显示**: 隐藏比较视图中的最新价坐标轴标签并整理品种显示；按来源限定品种身份键。
- **Comparison view axis and symbol display**: Hides the last-price axis label in comparison view, tidies symbol display, and scopes instrument identity keys by source.
- **五日分时网格与基线**: 绘制五日分时网格边界并锚定首日昨收基线；缓存会话槽格式化结果。
- **Five-day timeshare grid and baseline**: Draws five-day grid boundaries, anchors the baseline to the first-day previous close, and caches session slot formatters.
- **工具栏溢出**: 支持工具栏溢出滚动。
- **Toolbar overflow**: Supports overflow scrolling in the toolbar.

### 🏗️ 架构与重构 / Architecture & Refactoring
- **窗格管理器收敛**: 窗格布局与子指标状态收敛进 PaneManager。
- **PaneManager consolidation**: Consolidates pane layout and sub-indicator state into PaneManager.
- **只读 shallow ref 信号桥**: Vue 统一将核心信号桥接为只读 shallow ref。
- **Readonly shallow-ref signal bridge**: Unifies Vue core signal bridging to readonly shallow refs.
- **Provider 配置统一**: 将 Provider 配置收敛为单一 name-keyed 数组。
- **Provider config unification**: Unifies provider configs into a single name-keyed array.
- **Agent 上下文来源**: Agent 图表上下文改由 StateKernel 提供。
- **StateKernel-sourced agent context**: Sources agent chart context from StateKernel.
- **AgentSettingsDialog 重构**: 用 Pinia store 重写 AgentSettingsDialog。
- **Pinia-based settings dialog**: Rewrites AgentSettingsDialog with a Pinia store.
- **Agent 结果池移除**: 移除 Agent 结果池写入与 owner model（breaking change）。
- **Agent result pool removal**: Removes agent result pool writes and the owner model (breaking change).
