# v0.9.5

## 相比 v0.9.4 的变更 / Changes since v0.9.4

### 🐛 Bug 修复 / Fixes
- **分时图右缘裁剪**: 分时可见区间与渲染落点统一为同一套 slot 网格，修复缩小窗口时右侧数据被排除出渲染范围
- **timeshare right-edge clipping**: unify timeshare visible range with the rendering slot grid so narrow windows no longer drop the rightmost points
- **分时数据重复请求**: 避免进入分时图时重复请求分时数据
- **duplicate timeshare fetch**: prevent duplicate timeshare data requests when entering the chart
- **桌面端别名**: 修复桌面端迁移后的 core 模块别名解析
- **desktop aliases**: resolve migrated core module aliases in the desktop shell

### 🏗️ 架构与重构 / Architecture & Refactoring
- **指标颜色 token 化**: atr/fib/gmma/pivot 与虚线颜色、ichimoku 五线颜色接入 token 系统，移除硬编码配色
- **indicator color tokens**: wire atr/fib/gmma/pivot dashed-line colors and ichimoku five-line colors into the token system, removing hard-coded palette
- **开发依赖升级**: 升级开发依赖至最新版本
- **dev deps**: upgrade development dependencies to latest versions
