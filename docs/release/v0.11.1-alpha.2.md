## 相比 v0.11.1-alpha.0 的变更

### ⚠️ Breaking Changes & Migration

- **脚本 API 升级到 v2**：`defineIndicator` 的 `scriptVersion: 2` 改为 `version: 2`，旧字段在注册期直接拒绝；Agent 脚本工具与按来源隔离的 SharedWorker 宿主一并切换。迁移：把所有指标脚本的 `scriptVersion` 改名为 `version`，并按 v2 契约更新实现。([#396](https://github.com/363045841/KLineChartQuant/pull/396), [9b056b6d](https://github.com/363045841/KLineChartQuant/commit/9b056b6d))
- **绘图标签目标改为具名标识**：公开类型 `DrawingLabelIndex` 改为 `DrawingLabelTarget`，标签不再按索引定位。迁移：更新导入与字段类型，按具名目标传参。([678b3082](https://github.com/363045841/KLineChartQuant/commit/678b3082))
- **主图纵轴设置键移除、布局文档升版**：`mainPriceAxisRangeMode` 与 `mainPriceAxisPriceOnly` 两个公开设置键删除，纵轴模式改由逐轴状态持久化；布局文档升到 v4，旧文档按既有 alpha 策略丢弃。迁移：不要再传这两个设置键，改用右键价格轴的纵轴模式菜单或 `axes.setRangeMode`；旧布局需重新保存。([#402](https://github.com/363045841/KLineChartQuant/pull/402), [#399](https://github.com/363045841/KLineChartQuant/issues/399))

### ✨ 新功能

- **第三种纵轴口径**：新增「固定 K 线占比」，主轴只按可见 K 线定轴并让 K 线约占窗口高度的 70%，越界指标照常绘制、裁在窗格边缘；「仅缩放价格图表」同时可用，默认仍是全并口径。([#402](https://github.com/363045841/KLineChartQuant/pull/402))
- **Agent 支持指标脚本编写**：Agent 可以直接创建和修改指标脚本，并按需加载脚本 DSL 与 API 参考；脚本校验与启用走同一条注册管线。([#396](https://github.com/363045841/KLineChartQuant/pull/396), [0e2672c6](https://github.com/363045841/KLineChartQuant/commit/0e2672c6))
- **图表交互**：对象树与统一 pane 轴、十字线锁定、绘图右键菜单、指标移除、交易日分隔线。([#380](https://github.com/363045841/KLineChartQuant/pull/380), [#379](https://github.com/363045841/KLineChartQuant/pull/379), [#385](https://github.com/363045841/KLineChartQuant/pull/385))
- **主题与界面**：浅色主题、品牌绿图标、暗色表面与统一菜单契约。([#381](https://github.com/363045841/KLineChartQuant/pull/381), [#383](https://github.com/363045841/KLineChartQuant/pull/383), [1eedf70c](https://github.com/363045841/KLineChartQuant/commit/1eedf70c))
- **桌面端**：macOS 13+ 打包统一。([#373](https://github.com/363045841/KLineChartQuant/pull/373))

### 🤖 Agent 架构

- **运行时按 origin 隔离**：Agent 运行时迁入每个 origin 独立的 SharedWorker 宿主，供应商设置收敛到宿主自有 API，解决同页多图表争抢独占锁导致 AI 面板不可用。([6e4dc2ec](https://github.com/363045841/KLineChartQuant/commit/6e4dc2ec), [50d0ee68](https://github.com/363045841/KLineChartQuant/commit/50d0ee68), [#396](https://github.com/363045841/KLineChartQuant/pull/396), [#382](https://github.com/363045841/KLineChartQuant/issues/382))
- **会话以官方 Pi 记录为准**：面板直接渲染官方 transcript 条目，支持原生继续运行、Plan/Build 切换与 `ask_user` 卡片。([bbb980db](https://github.com/363045841/KLineChartQuant/commit/bbb980db), [#387](https://github.com/363045841/KLineChartQuant/pull/387))
- **工具面与绘图锚点重建**：工具改为声明式目录，统一品种路由与工具契约，只持久化被禁用的工具，跨模式稳定工具集与提示词。([0e55c108](https://github.com/363045841/KLineChartQuant/commit/0e55c108), [c7a72f68](https://github.com/363045841/KLineChartQuant/commit/c7a72f68), [9cd9dd85](https://github.com/363045841/KLineChartQuant/commit/9cd9dd85), [834e2679](https://github.com/363045841/KLineChartQuant/commit/834e2679), [#389](https://github.com/363045841/KLineChartQuant/pull/389))
- **联网检索**：网页搜索改走 Exa MCP 通道。([523f5006](https://github.com/363045841/KLineChartQuant/commit/523f5006))

## Changes since v0.11.1-alpha.0

### ⚠️ Breaking Changes & Migration

- **Script API moves to v2**: `scriptVersion: 2` in `defineIndicator` becomes `version: 2`; the old field is rejected at registration. Agent script tools and the per-origin SharedWorker host move with it. Migration: rename `scriptVersion` to `version` in every indicator script and update implementations to the v2 contract. ([#396](https://github.com/363045841/KLineChartQuant/pull/396), [9b056b6d](https://github.com/363045841/KLineChartQuant/commit/9b056b6d))
- **Drawing label targets are named**: the exported `DrawingLabelIndex` type becomes `DrawingLabelTarget`; labels are no longer located by index. Migration: update imports and field types, and pass named targets. ([678b3082](https://github.com/363045841/KLineChartQuant/commit/678b3082))
- **Main price-axis settings removed, layout document bumped**: the public `mainPriceAxisRangeMode` and `mainPriceAxisPriceOnly` settings are gone; range mode is now per-axis state. The layout document moves to v4 and older documents are discarded under the existing alpha policy. Migration: stop passing those settings, use the price-axis context menu or `axes.setRangeMode`, and re-save existing layouts. ([#402](https://github.com/363045841/KLineChartQuant/pull/402), [#399](https://github.com/363045841/KLineChartQuant/issues/399))

### ✨ Features

- **Third price-axis mode**: fixed K-line share fits the axis to visible bars with the candles occupying about 70% of the pane; out-of-range plots still render and are clipped at the pane edge. "Scale price chart only" is also available; the default remains the all-sources mode. ([#402](https://github.com/363045841/KLineChartQuant/pull/402))
- **Agent can author indicator scripts**: the Agent can create and edit indicator scripts, load the scripting DSL and API reference on demand, and route validation and activation through one registration pipeline. ([#396](https://github.com/363045841/KLineChartQuant/pull/396), [0e2672c6](https://github.com/363045841/KLineChartQuant/commit/0e2672c6))
- **Chart interaction**: object tree with unified pane axes, crosshair lock, drawing context menu, indicator removal and trading-day separators. ([#380](https://github.com/363045841/KLineChartQuant/pull/380), [#379](https://github.com/363045841/KLineChartQuant/pull/379), [#385](https://github.com/363045841/KLineChartQuant/pull/385))
- **Themes and UI**: light theme, brand-green icons, unified dark surfaces and menu contracts. ([#381](https://github.com/363045841/KLineChartQuant/pull/381), [#383](https://github.com/363045841/KLineChartQuant/pull/383), [1eedf70c](https://github.com/363045841/KLineChartQuant/commit/1eedf70c))
- **Desktop**: unified macOS 13+ packaging. ([#373](https://github.com/363045841/KLineChartQuant/pull/373))

### 🤖 Agent Architecture

- **Per-origin runtime isolation**: the Agent runtime moves into a SharedWorker host per origin and provider settings converge on a host-owned API, fixing the AI panel being unusable when several charts on one page fight over the exclusive lock. ([6e4dc2ec](https://github.com/363045841/KLineChartQuant/commit/6e4dc2ec), [50d0ee68](https://github.com/363045841/KLineChartQuant/commit/50d0ee68), [#396](https://github.com/363045841/KLineChartQuant/pull/396), [#382](https://github.com/363045841/KLineChartQuant/issues/382))
- **Official Pi records as the session source**: the panel renders official transcript entries directly, with native run continuation, Plan/Build switching and an `ask_user` card. ([bbb980db](https://github.com/363045841/KLineChartQuant/commit/bbb980db), [#387](https://github.com/363045841/KLineChartQuant/pull/387))
- **Rebuilt tool surface and drawing anchors**: a declarative tool catalog, unified instrument routing and tool contracts, persistence of disabled tools only, and stable tool sets and prompts across modes. ([0e55c108](https://github.com/363045841/KLineChartQuant/commit/0e55c108), [c7a72f68](https://github.com/363045841/KLineChartQuant/commit/c7a72f68), [9cd9dd85](https://github.com/363045841/KLineChartQuant/commit/9cd9dd85), [834e2679](https://github.com/363045841/KLineChartQuant/commit/834e2679), [#389](https://github.com/363045841/KLineChartQuant/pull/389))
- **Web search**: search now runs over the Exa MCP channel. ([523f5006](https://github.com/363045841/KLineChartQuant/commit/523f5006))

### 🐛 Fixes

- Pass through unknown fields on status frames. ([#392](https://github.com/363045841/KLineChartQuant/pull/392))
- Anchor VWAP to market sessions and skip missing volume. ([#378](https://github.com/363045841/KLineChartQuant/pull/378))
- `immutableMap` now returns a real `Map`; incremental indicator recomputation no longer stays in loading. ([d83bc483](https://github.com/363045841/KLineChartQuant/commit/d83bc483), [d8ff63d8](https://github.com/363045841/KLineChartQuant/commit/d8ff63d8))
- Commit axis views through the coordinator; fix selector row alignment and label truncation. ([833943c1](https://github.com/363045841/KLineChartQuant/commit/833943c1), [95baa559](https://github.com/363045841/KLineChartQuant/commit/95baa559))

### 🏗️ Architecture & Refactoring

- Removed dead script code and duplicate calculation paths; deduplicated Vue formatters, symbol specs and overlays. ([#395](https://github.com/363045841/KLineChartQuant/pull/395), [#393](https://github.com/363045841/KLineChartQuant/pull/393), [#394](https://github.com/363045841/KLineChartQuant/pull/394))
