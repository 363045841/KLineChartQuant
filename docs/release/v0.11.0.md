## 相比 v0.10.4 的变更

### ⚠️ Breaking Changes & Migration

- **单一发布包与完整工作台**：对外只发布 `@363045841yyt/klinechart`，`KlineWorkbench` 是完整界面的唯一入口，内部包不再单独发布，运行时代码、类型与页面资源随产品交付；完整产品含 AGPL 脚本模块，按 AGPL-3.0-or-later 交付。迁移：只安装该包，Agent 高级 API 改从 `/agent` 子入口导入，移除对 `klinechart-core` 等内部包的直接依赖。([#337](https://github.com/363045841/KLineChartQuant/pull/337))
- **行情数据源改为注册式**：宿主通过 `createMarketDataHost` 注册数据源并注入 `marketDataContext`，控制器不再接受行情数组或请求器，历史、增量、逐笔与跨品种请求统一走仓储。迁移：删掉传给控制器的 `bars` / 请求器参数，改为注册数据源并在挂载时注入上下文。([#337](https://github.com/363045841/KLineChartQuant/pull/337))
- **扩展渲染改用 Layer 契约**：`RendererPlugin` 及其管理器移除，第三方渲染通过 `Layer` / `Scene` 注册；`Layer` 以具体 `paneId` 标识，pane 匹配、可见性、z 排序与错误隔离统一由 `Scene` 处理。迁移：实现 `Layer<RenderContext>`，改用新的层注册 API 挂载。([#277](https://github.com/363045841/KLineChartQuant/pull/277)、[364c671a](https://github.com/363045841/KLineChartQuant/commit/364c671a))
- **指标改为实例与脚本**：指标按实例运行，移除 `IndicatorScheduler`、`chart.getIndicatorScheduler()`、旧 worker 协议与 `indicatorResultState`；指标身份统一为 `displayName`；内置指标迁移为脚本定义。迁移：改用实例 API 增删改指标，自定义指标通过 `defineIndicator` 注册。([dafac705](https://github.com/363045841/KLineChartQuant/commit/dafac705)、[c9287382](https://github.com/363045841/KLineChartQuant/commit/c9287382)、[20a88946](https://github.com/363045841/KLineChartQuant/commit/20a88946))
- **图例改由 DOM 渲染**：指标标题、参数与数值由 DOM renderer 负责，`CanvasLegendOptions` 更名为 `LegendOptions`，`LegendRenderMode` 的 `canvas` 改为 `dom`，图例增删改查与投影收敛到 `LegendManager`。迁移：替换类型名与枚举值，自定义图例改走 `LegendManager`。([0236d804](https://github.com/363045841/KLineChartQuant/commit/0236d804)、[63fe3cf5](https://github.com/363045841/KLineChartQuant/commit/63fe3cf5))
- **图表配置与视图契约调整**：`mainPriceAxisRangeMode` 取代 `disableMainPaneVerticalScroll`；`futureScreens` 移除，未来区改按视口推导（默认 1 屏并保留末尾两根数据位）；比较品种并入主图，`comparisonState.specs` 是唯一写入源，`Chart.setSymbols` 拒绝多个主品种；`SemanticChartConfig` 与 `./semantic` 子路径移除。迁移：按新的配置项改写价格轴与比较视图调用，删除对已移除导出与子路径的引用。([95320ef3](https://github.com/363045841/KLineChartQuant/commit/95320ef3)、[1dc9d8e8](https://github.com/363045841/KLineChartQuant/commit/1dc9d8e8)、[fe076b1d](https://github.com/363045841/KLineChartQuant/commit/fe076b1d)、[45221f49](https://github.com/363045841/KLineChartQuant/commit/45221f49))
- **运行环境与许可证**：`engines` 要求 Node `>=26.0.0`；许可证由 MIT 改为 Apache-2.0，完整产品含 AGPL-3.0-or-later 模块。迁移：把构建与 CI 升级到 Node 26，核对许可证与第三方声明。([#338](https://github.com/363045841/KLineChartQuant/pull/338)、[07c69710](https://github.com/363045841/KLineChartQuant/commit/07c69710))
- **Agent 契约**：agent-runtime 升级到 Pi 1.0.2 并由 pi-durable 管理会话，`RuntimeToolRegistry` 更名为 `RuntimeToolCatalog`，`ask_user` 的 `selectedLabels` 更名为 `selectedValues`，`lookupInstrumentsBySymbol` 改为返回字符串表格。迁移：更新导入名与字段名，按新的返回类型解析查询结果。([540ad152](https://github.com/363045841/KLineChartQuant/commit/540ad152)、[9ce1a85c](https://github.com/363045841/KLineChartQuant/commit/9ce1a85c)、[f2b34440](https://github.com/363045841/KLineChartQuant/commit/f2b34440))

## Changes since v0.10.4

### ⚠️ Breaking Changes & Migration

- **Single package and complete workbench**: Only `@363045841yyt/klinechart` is published; `KlineWorkbench` is the single UI entry, internal packages are no longer published separately, and runtime code, types, and page assets ship with the product. The full product includes AGPL script modules under AGPL-3.0-or-later. Migration: install only this package, import advanced Agent APIs from the `/agent` subpath, and drop direct dependencies on internal packages such as `klinechart-core`. ([#337](https://github.com/363045841/KLineChartQuant/pull/337))
- **Market data sources are registered**: Hosts register sources through `createMarketDataHost` and inject `marketDataContext`; controllers no longer accept bar arrays or requesters, and history, incremental, trade, and cross-symbol requests share one repository. Migration: remove `bars` / requester arguments from controllers, register sources, and inject the context when mounting. ([#337](https://github.com/363045841/KLineChartQuant/pull/337))
- **Renderer extensions use the Layer contract**: `RendererPlugin` and its manager are removed; third-party rendering registers through `Layer` / `Scene`. A `Layer` is identified by a concrete `paneId`, while pane matching, visibility, z-ordering, and error isolation move into `Scene`. Migration: implement `Layer<RenderContext>` and mount it through the new layer registration API. ([#277](https://github.com/363045841/KLineChartQuant/pull/277), [364c671a](https://github.com/363045841/KLineChartQuant/commit/364c671a))
- **Indicators are instances and scripts**: Indicators run per instance; `IndicatorScheduler`, `chart.getIndicatorScheduler()`, the legacy worker protocol, and `indicatorResultState` are removed; indicator identity is unified on `displayName`; builtin indicators ship as script definitions. Migration: manage indicators through the instance API and register custom indicators with `defineIndicator`. ([dafac705](https://github.com/363045841/KLineChartQuant/commit/dafac705), [c9287382](https://github.com/363045841/KLineChartQuant/commit/c9287382), [20a88946](https://github.com/363045841/KLineChartQuant/commit/20a88946))
- **Legends render through the DOM**: Indicator titles, params, and values are rendered by a DOM renderer; `CanvasLegendOptions` is renamed to `LegendOptions`; `LegendRenderMode` changes from `canvas` to `dom`; legend CRUD and projection consolidate into `LegendManager`. Migration: replace the type name and enum value, and route custom legends through `LegendManager`. ([0236d804](https://github.com/363045841/KLineChartQuant/commit/0236d804), [63fe3cf5](https://github.com/363045841/KLineChartQuant/commit/63fe3cf5))
- **Chart options and view contracts**: `mainPriceAxisRangeMode` replaces `disableMainPaneVerticalScroll`; `futureScreens` is removed and future space is derived from the viewport (one screen by default, retaining the last two data slots); comparison symbols merge into the main chart with `comparisonState.specs` as the only writable source, and `Chart.setSymbols` rejects multiple primary symbols; `SemanticChartConfig` and the `./semantic` subpath are removed. Migration: rewrite price-axis and comparison calls for the new options and delete references to removed exports and subpaths. ([95320ef3](https://github.com/363045841/KLineChartQuant/commit/95320ef3), [1dc9d8e8](https://github.com/363045841/KLineChartQuant/commit/1dc9d8e8), [fe076b1d](https://github.com/363045841/KLineChartQuant/commit/fe076b1d), [45221f49](https://github.com/363045841/KLineChartQuant/commit/45221f49))

### ⚡ Performance

- **Draw-call batching**: Circles, rects, rounded rects, and anchor rings share one instance layout, and adjacent shapes batch even across colors; opaque strokes expand to triangles instead of running a full-frame stencil cover per polyline; same-color bars become one instanced `rects` batch. In a measured scene of 4096 shapes, 128 lines, and 256 off-screen objects, the whole layer costs 2 draws and 1 submit with every off-screen object culled, and on redraw the lines hit the geometry cache with zero geometry builds and zero uploads. ([5f2fed75](https://github.com/363045841/KLineChartQuant/commit/5f2fed75), [ebbee425](https://github.com/363045841/KLineChartQuant/commit/ebbee425), [52f49bb8](https://github.com/363045841/KLineChartQuant/commit/52f49bb8))
- **Imperative submission, one composition per target**: Layers submit incremental primitives only; Scene gives each paint target one composer that runs one offscreen render and one full-target copy at frame end, so cost scales with targets instead of layers, and batches covering less than 6% of the target go straight to Canvas. WebGPU folds 7 command buffers into one `queue.submit`, cutting P50 from 0.025 ms to 0.003 ms (8.33×). ([5f2fed75](https://github.com/363045841/KLineChartQuant/commit/5f2fed75), [65c45586](https://github.com/363045841/KLineChartQuant/commit/65c45586))
- **Offscreen batching for text**: A batch containing text is replayed once by Canvas as a whole, removing the N offscreen renders and N+1 full-canvas copies that used to be paid per text run, so composition count no longer grows with text count. ([24c53703](https://github.com/363045841/KLineChartQuant/commit/24c53703))
- **Direct GPU surface**: Main-band geometry writes straight into the visible GPU canvas, dropping the full-canvas `drawImage` on the Canvas side; WebGPU renders the canvas's current texture with no multisample target or resolve. ([bcafd8be](https://github.com/363045841/KLineChartQuant/commit/bcafd8be), [e2031dec](https://github.com/363045841/KLineChartQuant/commit/e2031dec))
- **Analytic distance-field anti-aliasing**: Target-level 4× MSAA is off; lines, circles, rounded rects, and rect batches compute coverage from distance in the fragment shader, removing 4× sampling resolve and bandwidth for the whole target while keeping 1px lines crisp at any DPR. ([851e8d1b](https://github.com/363045841/KLineChartQuant/commit/851e8d1b), [8695a95e](https://github.com/363045841/KLineChartQuant/commit/8695a95e))
- **Geometry and buffer reuse**: Indicator lines and fill bands keep world coordinates, so scrolling and price-axis zoom only change uniforms; the cache is bucketed by half a screen and a pure scroll hits it wholesale, while fill-band `Path2D` is reused by reference. Unchanged wide-line geometry is not rebuilt and uploads compare by float32 bits; bar world and screen buffers only grow across frames, only visible bars are written, and at minimum zoom the body and wick merge into one bar. ([a5d08d74](https://github.com/363045841/KLineChartQuant/commit/a5d08d74), [6ca57eeb](https://github.com/363045841/KLineChartQuant/commit/6ca57eeb), [70c214e5](https://github.com/363045841/KLineChartQuant/commit/70c214e5))
- **Unchanged frames are skipped**: Frame content is versioned by value, so a hit skips prepare, clear, and paint while reusing K-line and Ichimoku geometry; indicator implementations load on demand, plot bounds are indexed by block for visible ranges, and off-range drawings are culled before projection. On WebGPU, 10k Ichimoku bars go from 116 FPS to 185–200 FPS and jank drops from 63.7% to 8.0% / 0.2%. ([df8841d0](https://github.com/363045841/KLineChartQuant/commit/df8841d0), [be5afd3c](https://github.com/363045841/KLineChartQuant/commit/be5afd3c), [219ace9f](https://github.com/363045841/KLineChartQuant/commit/219ace9f))
- **Market loading**: Now that aggregation is part of series identity, ordinary K-line loads no longer pull H1/D1 from MT5 for resampling. ([560674e8](https://github.com/363045841/KLineChartQuant/commit/560674e8))
