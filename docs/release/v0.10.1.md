# v0.10.1

## 相比 v0.10.0 的变更 / Changes since v0.10.0

### ✨ 新功能 / Features
- **指标渲染器迁移**: 将 9 个指标从纯函数 API 迁移到引擎渲染器
- **migrate indicators to engine renderers**: migrate 9 indicators from the pure-function API to engine renderers
- **可折叠自选股面板**: 新增可折叠的自选股面板，状态迁移至 IndexedDB
- **collapsible watchlist panel**: add a collapsible watchlist panel and persist its state to IndexedDB
- **可选连接器启动**: 开发环境可选择启动指定的行情后端连接器
- **selectable connecter startup**: allow selecting which market-data connecters to start in the dev environment

### 🐛 Bug 修复 / Fixes
- **分时固定像素网格**: 分时槽位对齐固定整数像素网格，量柱间隙恒定，消除小刻度下的错位
- **fixed timeshare grid**: place timeshare slots on a fixed integer pixel grid so volume bars keep a constant gap even on small ticks
- **午间收盘映射**: 午间结束时间戳映射到分时边界槽位
- **lunch-end boundary slot**: map the lunch-end timestamp to the boundary slot in timeshare
- **分时网格线**: 分时模式跳过月度网格线
- **skip month grid lines**: skip month grid lines in timeshare mode
- **分时量柱标签**: 小分时刻度下展示有意义的量柱标签
- **meaningful volume labels**: show meaningful volume labels on small timeshare ticks
- **分时左轴百分比**: 分时左轴保持百分比
- **timeshare percent axis**: keep the timeshare left axis in percent

### 🏗️ 架构与重构 / Architecture & Refactoring
- **指标实例身份拆分**: 将副图指标实例身份与 pane id 拆分，新增独立 instanceId / indicatorId / ordinal 字段，分时模式按 canonical 指标复用用户 VOL 面板
- **separate indicator identity**: separate indicator instance identity from the pane id with independent instanceId / indicatorId / ordinal fields; timeshare mode reuses the user's VOL pane by canonical indicator id
- **模式系统实例化**: 图表模式建模为系统实例，统一主副指标实例与活动渲染器推导
- **modes as system instances**: model chart modes as system instances, unify main and sub indicator instances, and derive active renderers from kernel state
- **框架 x 几何中心化**: 所有框架 x 几何从 K 线中心推导，分时时间轴首尾标签共用中心网格
- **center-based frame geometry**: derive all frame x-geometry from K-line centers and share the center grid with timeshare axis labels
- **Vue 信号桥接**: Vue 层订阅控制器信号驱动视口/数据/缩放状态，自选股状态迁移至 IndexedDB
- **Vue signal bridge**: subscribe viewport/data/zoom state to controller signals and move watchlist state to IndexedDB
- **升级工具链依赖**: 升级工作区工具链与依赖
- **bump toolchain**: bump the workspace toolchain and package dependencies
