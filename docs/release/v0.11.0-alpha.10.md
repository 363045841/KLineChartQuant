## 相比 v0.11.0-alpha.9 的变更 / Changes since v0.11.0-alpha.9

### ✨ 新功能 / Features

- **完整工作台交付（破坏性）**: 唯一对外发布包收敛为 `@363045841yyt/klinechart`，`KlineWorkbench` 成为完整界面的唯一组装入口，内部包运行时代码、类型与页面资源随产品交付，Vue 保持外部 peer；完整产品含 AGPL 脚本模块，按 AGPL-3.0-or-later 交付，内部 Apache 模块保留原许可证。
- **Complete workbench delivery (breaking)**: Ships `@363045841yyt/klinechart` as the only published package with `KlineWorkbench` as the single UI entry, bundling internal runtime code, types, and page assets while keeping Vue an external peer; the full product includes AGPL script modules under AGPL-3.0-or-later while internal Apache modules keep their license.
- **注册式行情数据源（破坏性）**: 宿主只通过 `createMarketDataHost` 注册数据源并注入 `marketDataContext`，控制器不再接受行情数组或请求器，历史、增量、逐笔与跨品种请求走统一仓储，行情会话按品种与周期收敛。
- **Registered market data sources (breaking)**: Hosts register data sources through `createMarketDataHost` and inject `marketDataContext`; controllers no longer accept bar arrays or requesters, history, incremental, trade, and cross-symbol requests share one repository, and market sessions are scoped by symbol and period.
- **指标脚本引擎**: 基于 QuickJS 的 TypeScript 指标脚本，提供 `defineIndicator`、`defineLibrary`、统一的 Plot/Fill 绘制 API（Line、Box、Label、字符、箭头、hline、带状填充、OHLC）、`request.security` 跨周期数据、`ta.direction` 辅助函数与 `Timeframe` 枚举，可信脚本可跳过 QuickJS 直接执行。
- **Indicator script engine**: Adds QuickJS-based TypeScript indicator scripts with `defineIndicator`, `defineLibrary`, a unified Plot/Fill API (Line, Box, Label, chars, arrows, hline, bands, OHLC), `request.security` cross-period data, `ta.direction` helpers, and the `Timeframe` enum, while trusted scripts bypass QuickJS and run directly.
- **内置指标脚本化（破坏性）**: MACD、SuperTrend、均线族、通道类、Fib/FRAMA、AO/CCI/HMA/KST/DMA、SMC 以及全部 maxsum 指标迁移为脚本实现，展示元数据随脚本发布，core 不再保留同名内置实现。
- **Builtin indicators as scripts (breaking)**: Migrates MACD, SuperTrend, moving averages, channels, Fib/FRAMA, AO/CCI/HMA/KST/DMA, SMC, and all maxsum indicators to script definitions with display metadata shipped alongside, dropping the duplicate core implementations.
- **脚本库与多标签编辑器**: 脚本工作区支持用户库、多标签、目录、搜索、保存与运行，库可被指标脚本导入并参与信任校验。
- **Script libraries and multi-tab workspace**: The script workspace supports user libraries, multiple tabs, folders, search, save, and run, and libraries can be imported by indicator scripts with trust validation.
- **独立编辑器页与语言服务**: 编辑器页按需构建并自包含 JS/CSS，与宿主共享同一 CodeMirror 实例；语言服务提供补全、悬浮文档、跳转与重命名，独立窗口只同步可克隆数据。
- **Detached editor page and language service**: The editor page builds on demand with self-contained JS/CSS and shares a single CodeMirror instance with the host; the language service adds completion, hover docs, navigation, and rename, with detached windows syncing cloneable data only.
- **主题感知脚本配色**: 脚本颜色改为随主题解析的 token，编辑器面板、语法高亮与图表绘制跟随有效主题。
- **Theme-aware script colors**: Script colors resolve through theme tokens, so editor panels, syntax highlighting, and chart drawing follow the effective theme.
- **设计 Token v2 与交互原语**: 重建设计 Token 与快捷键系统，统一交互原语与共享控件样式，浅色模式与图表边框重新打磨。
- **Design Token v2 and interaction primitives**: Rebuilds design tokens and the keyboard-shortcut system, unifies interaction primitives and shared control styling, and refreshes light mode and chart chrome.
- **Footprint 重建（破坏性）**: FootPrint 改为独立 K 线显示模式，基于 Binance 聚合逐笔成交计算价格行与 Delta，支持自适应行高、按成交额展示、以成交量判定失衡，标题与加载状态进入图例。
- **Footprint rebuild (breaking)**: Turns FootPrint into a standalone candle display mode backed by Binance aggregated trades, with adaptive row sizing, traded-amount cells, volume-based imbalance, and legend title and loading state.
- **图例统一（破坏性）**: 图例的增删改查、投影与操作收敛到 core `LegendManager`，指标标题、参数与数值改由 DOM 渲染，支持隐藏/显示与指标设置。
- **Unified legend (breaking)**: Consolidates legend CRUD, projection, and actions into the core `LegendManager`, renders titles, params, and values through DOM, and adds hide/show plus indicator settings.
- **布局与设置持久化（破坏性）**: 图表设置、工具栏管理、视口位置与用户图元统一通过布局文档持久化，布局命名改为弹窗输入且列表顺序稳定。
- **Layout and settings persistence (breaking)**: Persists chart settings, toolbar management, viewport position, and user drawings through layout documents, with layout naming in a dialog and a stable list order.
- **GPU 可见表面与绘制分层**: 主图带可由 `createSurface` 提供可见 GPU 直出表面，draw-list 图层不再持有 `ctx`，每个目标只有一个合成器。
- **Visible GPU surface and draw targets**: The main band can present a visible GPU surface through `createSurface`, draw-list layers no longer carry `ctx`, and each target composites once.
- **Agent 面板双侧停靠**: Agent 面板支持左右任一侧停靠，供应商设置弹窗重做，锁定会话可重试。
- **Agent panel docking**: The Agent panel docks on either side, the provider settings dialog is reworked, and locked sessions are retryable.
- **界面细节**: 文档标题展示现价与涨跌幅、命令面板入口按钮、页脚下拉改为文字操作、十字线时间标签带星期、图元标签支持垂直偏移与绘图上限提升到 2000。
- **UI details**: Shows price and change in the document title, adds a command-palette button, renders footer dropdown triggers as text actions, prefixes crosshair time labels with the weekday, and supports drawing label offsets with a 2000-drawing cap.

### 🐛 Bug 修复 / Fixes

- **脚本服务就绪前打开编辑器**: 脚本服务异步初始化完成前不再暴露编辑器入口，避免生成没有模板、无法运行的空草稿。
- **Editor opened before the script service is ready**: Hides the editor entry until the asynchronous script service has initialised, so no template-less, unrunnable draft can be created.
- **脚本 Worker 自包含**: 编辑器页 chunk 与 Worker 一并内联，修复发布包中首次运行用户脚本失败的问题。
- **Self-contained script worker**: Inlines the editor page chunks and worker, fixing user scripts that failed on their first run in the published package.
- **单一编辑器实例**: CodeMirror 外部化，避免编辑器弹窗与独立窗口各持一份实现。
- **Single editor instance**: Externalises CodeMirror so the dialog and the detached window no longer load separate copies.
- **指标实例身份与主图脚本绘制**: 统一指标实例身份，修复主图脚本绘制、参数保存目标错误与图例操作按钮锚点。
- **Indicator identity and main-chart script drawing**: Unifies indicator instance identity, fixes main-chart script drawing, parameter save targets, and legend action anchoring.
- **跨后端与绘制顺序**: 恢复各后端线段渲染，修正子图十字线轴标签与时间轴尺寸的提交时机、填充颜色与数据空间批次。
- **Backends and paint order**: Restores segment rendering on every backend and fixes sub-pane crosshair labels, time-axis sizing, fill colors, and data-space batching.
- **行情与订阅**: 修正 live bars 能力与流身份、运行时连接器请求能力、离线数据源搜索以及订阅者异常隔离。
- **Market data and subscriptions**: Fixes live-bar capability and stream identity, runtime connector request capabilities, offline source search, and subscriber error isolation.
- **界面回归**: 修复窗格分隔线层级、图例内边距、图表品牌锚点、截图边框与轴控件排除、工具栏按钮压缩、菜单标题重复与勾选内边距。
- **UI regressions**: Fixes pane separator stacking, legend insets, chart brand anchoring, screenshot borders and axis-control exclusion, shrinking toolbar buttons, duplicated menu headings, and checkmark padding.
- **设备与主题**: 桌面 UA 平板不再启动语言服务 Worker，深色预设的十字线标签保持深色。
- **Devices and theme**: Desktop-UA tablets no longer start the language-service worker, and dark-preset crosshair tags stay dark.

### 🏗️ 架构与重构 / Architecture & Refactoring

- **发布形态拆分（破坏性）**: Web Component 与编辑器页从产品包拆分，产品只经 Vue 交付，内部包版本不再与产品同步。
- **Delivery split (breaking)**: Separates the Web Component and editor page from the product package, delivers the product only through Vue, and decouples internal package versions from the product.
- **脚本服务与编辑器单元拆分**: 脚本服务拆为文档读模型、执行器、持久化与目录操作，编辑器拆为会话与窗口，运行与保存互不耦合。
- **Script service and editor units**: Splits the script service into document reads, executor, persistence, and folder operations, and the editor into session and window units so running and saving stay independent.
- **core 模块重定位**: 抽出 chart 与 pane 模块，重定位 comparison、scale、labels、frame、market 等模块，移除死导出、重复回退与未集成渲染路径。
- **Core module relocation**: Extracts chart and pane modules, relocates comparison, scale, labels, frame, and market modules, and removes dead exports, duplicate fallbacks, and unintegrated rendering paths.
- **Vue 语义目录与别名**: 组件与组合式函数按语义目录归组，跨目录导入统一使用 `@vue-src` 与 `@/` 别名。
- **Vue semantic folders and aliases**: Groups components and composables into semantic folders and routes cross-directory imports through the `@vue-src` and `@/` aliases.
- **许可证边界**: AGPL 脚本包与 Apache 包物理隔离，产品携带模块许可证与第三方声明。
- **License boundary**: Physically isolates AGPL script packages from Apache packages and ships module licenses and third-party notices with the product.

### ⚡ 性能 / Performance

- **渲染批处理**: 每个目标只合成一次，文本批次在 Canvas 重放一次，复用 K 线缓冲并剔除不可见矩形，以解析式抗锯齿替代目标级 MSAA。
- **Render batching**: Composites once per target, replays text batches once on Canvas, reuses bar buffers and culls invisible rects, and replaces target-level MSAA with analytic anti-aliasing.
- **指标与图元**: 指标实现按需加载，可见范围按块索引 plot 边界，时间线投影避免帧数组克隆，范围外图元在投影前剔除。
- **Indicators and drawings**: Loads indicator implementations on demand, indexes plot bounds by block for visible ranges, avoids frame-array cloning during timeline projection, and culls off-range drawings before projection.
- **布局与开发体验**: 视口变化不再反复重置自动保存计时器，开发服务器限制 rolldown worker 池以降低内存。
- **Layouts and dev experience**: Stops rearming the autosave timer on every viewport change and caps the dev-server rolldown worker pool to cut memory.

### 🔧 工程 / Engineering

- **产品发布链路**: `build:product`、`pack:product`、`test:product` 串联，只上传通过隔离消费验收的 tarball（公开类型、生产构建、源码与打包截图一致、真实运行脚本），校验 `verified.json` 后才发布。
- **Product release pipeline**: Chains `build:product`, `pack:product`, and `test:product`, uploads only the tarball that passed isolated consumer acceptance (public types, production build, source-vs-packed screenshots, real script execution), and publishes only with a matching `verified.json`.
- **CI 门禁**: 双 Node 矩阵跑类型检查、包测试与 attw，包测试限制并发，UI token 门暂时降级为警告。
- **CI gates**: Runs type checks, package tests, and attw on both Node lines, bounds package-test concurrency, and temporarily demotes the UI token gate to a warning.
- **性能基准**: 新增分辨率预设与 1080p/2k 图表基准，输出基准图表与报告管线。
- **Benchmarks**: Adds resolution presets with 1080p/2k charts and a report pipeline that renders benchmark charts.
- **依赖与仓库卫生**: 升级 typebox、happy-dom、@types/node、style-dictionary，清理 Playwright 与一次性脚本，新增 PR 模板。
- **Dependencies and hygiene**: Bumps typebox, happy-dom, @types/node, and style-dictionary, removes Playwright and one-off scripts, and adds a PR template.
