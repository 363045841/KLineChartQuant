## 相比 v0.11.0-alpha.10 的变更 / Changes since v0.11.0-alpha.10

### ✨ 新功能 / Features

- **主图图例头占位（破坏性）**: 主图按图例实际高度预留内容区，价格刻度、指标与用户绘图随之让位；行盒几何、文本间距、行情读数格式与图例语义色收敛到 `legendGeometry`、`legendRow`、`legendQuote`、`legendColors`，主图整块收起归入图例领域，副图标题仍叠加在指标上。
- **Main pane legend header inset (breaking)**: The main pane reserves content space from the legend's real height so the price scale, indicators and drawings shift accordingly; row geometry, text gaps, quote formatting and legend colors live in `legendGeometry`, `legendRow`, `legendQuote` and `legendColors`, main-legend collapse belongs to the legend domain, and sub-pane titles still overlay indicators.
- **K 线图例涨跌读数**: K 线图例在收盘价右侧依次显示涨跌额与涨跌幅（如 `+2.00(+20.00%)`），基准为十字线所指 K 线的前一根收盘价，首根 K 线直接省略文本；分时图例复用同一套读数、精度与颜色规则。
- **K-line legend change readout**: The K-line legend shows the change amount and percent next to close (e.g. `+2.00(+20.00%)`), based on the previous close of the crosshair bar and omitted for the first bar; timeshare legends reuse the same readout, precision and color rules.
- **分时面积渐变与昨收虚线**: 面积渐变终点改用主题背景的同色透明值，浅色与深色主题下面积不再偏灰发暗；昨收虚线按单日可见区段或五日各交易日区段绘制，单日与五日分时共用同一实现。
- **Timeshare area gradient and pre-close line**: The area gradient now fades into the theme background's own transparent color, so the fill no longer turns grey or muddy in either theme; the pre-close dashed line follows the visible range or each five-day session, shared by single-day and five-day timeshare.
- **工具栏 GitHub 入口与构建元数据**: 左侧工具栏新增仓库入口，产品导出构建提交短哈希与提交时间（`COMMIT_HASH`、`COMMIT_TIME`），由 `scripts/build-commit.mjs` 从 HEAD 注入构建配置，仓库地址收敛到 `productLinks.ts`。
- **Toolbar GitHub entry and build metadata**: The left toolbar gains a repository entry, and the product exports the build commit hash and time (`COMMIT_HASH`, `COMMIT_TIME`) injected from HEAD by `scripts/build-commit.mjs`, with the repository URL centralised in `productLinks.ts`.
- **五日分时返回操作**: 返回按钮从顶部工具栏左侧移入右侧图表操作区，与撤回、截图并列，仅在存在可返回的上层视图（如五日分时）时出现。
- **Five-day timeshare back action**: The back button moves from the left of the top toolbar into the right-hand chart action group beside undo and screenshot, and only appears when an upper view (such as five-day timeshare) can be left.

### 🐛 Bug 修复 / Fixes

- **设计原语内边距被宿主重置剥掉**: 恢复按钮、弹窗与文本框的内边距，宿主样式重置不再把原语间距清零；品种弹窗标签的内边距保持在紧凑默认值之上。
- **Host resets stripping primitive padding**: Restores padding on design primitives so host style resets no longer clear it from buttons, modals and textareas, and the symbol popover tab keeps its padding above the compact default.
- **工作台表头与工具栏间距**: 对齐工作台表头行高度，修正顶部工具栏操作区间距以及 Agent 面板头部与时间线的排版。
- **Workbench header row and toolbar spacing**: Aligns the workbench header row height and fixes toolbar action spacing plus Agent panel header and timeline layout.
- **网格背景与数据层裁剪**: 网格背景不再被内容区裁剪，数据层按 pane 内容区裁剪，价格滚动时不再越界绘制。
- **Grid background and data layer clipping**: The grid background is no longer clipped by the content area while data layers clip to the pane content area, so price scrolling no longer paints outside it.

### 🏗️ 架构与重构 / Architecture & Refactoring

- **分时几何统一**: 单日与五日分时合并到同一套几何与基线计算，`timeShareGeometry` 与 `timeShareMath` 成为唯一实现，移除五日分时独立的几何模块，返回上层视图与视口平移行为保持一致。
- **Unified timeshare geometry**: Single-day and five-day timeshare share one geometry and baseline implementation in `timeShareGeometry` and `timeShareMath`, the separate five-day geometry module is removed, and back-navigation and pan behaviour stay consistent.
- **构建环境升级到 Node 26（破坏性）**: workflows、`engines` 与 tsconfig 统一要求 Node `>=26.0.0`，类型配置切换到 `@tsconfig/node26`。
- **Node 26 build baseline (breaking)**: Workflows, `engines` and tsconfig now require Node `>=26.0.0`, switching type configuration to `@tsconfig/node26`.
- **预览页精简**: 移除预览页的 debug 弹窗与内嵌尺寸控件，预览只保留产品实际入口。
- **Leaner preview page**: Removes the preview debug modal and embedded size controls, leaving the preview to the product's real entry.

### 📚 文档 / Documentation

- **单包安装与数据源注册**: README 说明只安装 `@363045841yyt/klinechart`，并给出通过 `createMarketDataHost` 注册行情数据源的完整接入流程。
- **Single-package install and data source registration**: The README now documents installing only `@363045841yyt/klinechart` and the full data-source registration flow through `createMarketDataHost`.
