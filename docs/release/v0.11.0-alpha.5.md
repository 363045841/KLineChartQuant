# 相比 v0.11.0-alpha.4 的变更 / Changes since v0.11.0-alpha.4

> 本版本接续未完成发布的 `v0.11.0-alpha.4`，包含其全部变更。`v0.11.0-alpha.4` 在 npm 上仅有 core 与 agent-runtime，且 agent-runtime 的依赖损坏，请改用本版本。

## 🐛 Bug 修复 / Fixes

- **修复发布流水线在冻结锁文件下失败**: Publish prebuilt tarballs through `pnpm pack` + `npm publish <tarball>`, so pnpm resolves the `workspace:` protocol at pack time and no pnpm script runs against a rewritten manifest.
- **修复 agent-runtime 发布依赖损坏**: Translate the missing `workspace:` specs — agent-runtime's core dependency and vue's devDependency — when publishing the GitHub Packages mirror.

## 🔧 工程 / Engineering

- **发布文档同步**: Update the release guide to OIDC trusted publishing and the `pnpm pack` + `npm publish <tarball>` flow.
