# 相比 v0.11.0-alpha.6 的变更 / Changes since v0.11.0-alpha.6

## ✨ 新功能 / Features

- **全局绘图锁定**: Add a global drawing lock toggle that freezes movement of every drawing, resolved by one pure predicate and leaving deletion, undo/redo, style, visibility and hit-testing unaffected.
- **绘图设置与文本控件**: Add a drawing settings dialog with color controls, text controls, per-kind template persistence, and split tool selection from group expansion.
- **图表级绘图撤销/重做（破坏性）**: Keep a single drawing history per chart so interaction, controller, facade and Agent edits share one undo sequence, exposed in the left toolbar. (BREAKING)
- **价格轴锁定价 K 线比例（破坏性）**: Keep the main price axis stable while panning by storing the locked display range in StateKernel. Replaces `disableMainPaneVerticalScroll` with `mainPriceAxisRangeMode`. (BREAKING)
- **最新价标签涨跌着色与收线倒计时**: Color the last price label by trend and show the current bar close countdown for supported periods, refreshed on second boundaries.
- **4 小时周期档位**: Add `4h` to the period SSOT and the core initial-window policy.
- **欧洲传统 K 线聚合**: Add the Europe-traditional bar aggregation value to the protocol and core.
- **Agent 面板启动器与引用角标重做**: Restyle the panel launcher as an edge strip with a tooltip, and render citation markers as neutral gray pills.
- **Agent 会话操作弹窗化**: Replace `window.prompt` / `window.confirm` with styled base modals for session rename and delete.
- **绘图锚点数量提示**: Derive per-kind anchor counts from the domain and state them in the `drawing_create` / `drawing_update` tool descriptions.
- **左边界增量加载集中化**: Centralize left-gap incremental loading in `Chart`.
- **数据源后端安装脚本更名**: Rename `pnpm setup` to `pnpm setup:backends` and add layered ANSI coloring to the install output.

## 🐛 Bug 修复 / Fixes

- **绘图锁定语义修正（破坏性）**: Locked drawings now only block drag and removal; style, params, labels, visibility and z-index writes are accepted again. (BREAKING)
- **轴刻度平移跟随**: Anchor vertical grid marks to readable price values so the same label and gridline move together during vertical panning.
- **双击切换分时能力校验**: Validate the symbol's time-share capability before double-click switching, writing to the existing symbol error state instead of throwing on unsupported sources.
- **指标定义分类与挂载**: Classify indicator definitions and mount mode renderers correctly.
- **WebGPU 空帧清屏**: Clear the WebGPU surface on empty frames.
- **绘图锚点日期失败按原因区分**: Resolve trading dates to a discriminated result and raise a distinct error code per cause, carrying the loaded range in out-of-range details.
- **绘图标签拒绝非索引键**: Reject extra keys at both the label object and map level in the Agent schema.
- **Agent Web 搜索密钥引导与存储**: Guide web search key setup, and store Exa keys globally with legacy profile-key migration so configured search survives a profile switch.
- **Agent 工具失败分类与结果高度**: Classify tool failures and cap tool result content height.
- **工具栏滚动与分组菜单**: Refine toolbar scrolling and grouped tool menu behavior.
- **当前品种选中不再空转加载**: Ignore the data manager's no-op active selection so the symbol chip does not stay pending.
- **dev connector 进程树关闭**: Kill the whole connector process tree on `SIGINT`/`SIGTERM` and wait for shutdown before returning the prompt.
- **bench 别名与独显**: Resolve core source aliases in the benchmark config and force the discrete GPU.

## 🏗️ 架构与重构 / Architecture and Refactoring

- **绘图模块语义分层（破坏性）**: Split the drawing module into `model` / `session` / `geometry` / `interaction` / `render` submodules with a single barrel, and move the primitive domain model out of `foundation`. (BREAKING)
- **移除 semantic 配置 API（破坏性）**: Delete the deprecated JSON semantic chart config and the `./semantic` subpath export, moving marker shape rendering to `engine/marker/shape`. (BREAKING)
- **Core 模块语义布局**: Migrate modes, scale, replay/chartTypes, alerts, advanced chart components, plugin and the agent feature module to the `<module>/types.ts + impl/` layout.
- **Controllers 语义模块化**: Route controller public exports through semantic modules and migrate the toolbar, indicator selector, drawing and chart controllers.
- **Agent/agent-runtime 语义布局**: Organize agent feature modules, separate provider settings contracts, modularize the browser bridge, and move search implementations and the Pi run driver into `impl/`.
- **价格刻度类型词汇统一**: Centralize price scale type vocabulary.
- **绘图标签键不变量归入领域**: Move the drawing label key invariant into the domain and rename the session overlay to `DrawingSessionOverlay`.
- **导入别名统一**: Replace relative `../..` imports with `@` aliases.

## ⚡ 性能 / Performance

- **WebGPU 线条几何缓存**: Skip rebuilding wide-line vertices and upload-data comparison for unchanged strips while preserving pixel-aligned rebuilds.
- **WebGPU 渲染路径减负**: Compare uploaded strip geometry by float32 bits and batch deferred buffer retirement behind queue completion.
- **K 线帧准备减负**: Reuse physical pixel coordinates and avoid volume-price analysis when markers cannot be visible.
- **日期与提示框复用**: Reuse calendar indexes across render frames and skip redundant tooltip display writes during high-frequency interaction.
