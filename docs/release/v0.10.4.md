## 相比 v0.10.3 的变更 / Changes since v0.10.3

### ✨ 新功能 / Features
- **统一指标查询管线**: 新增可复用注册指标计算器的受限 Agent 查询能力；图表与 Agent 共享指标结果池，支持稳定实例 ID、时间戳、预热信息以及独立参数。
- **Unified indicator query pipeline**: Adds bounded Agent queries backed by registered indicator calculators. Charts and Agents share an indicator result pool with stable instance IDs, timestamps, warm-up metadata, and independent parameters.
- **标注绘图工具**: 新增 Fibonacci 回撤、矩形和箭头图元，并接入工具栏与 AI runtime。
- **Annotation tools**: Adds Fibonacci retracement, rectangle, and arrow primitives with toolbar and AI runtime integration.
- **韩国市场时段**: 新增韩国市场配置，采用 Asia/Seoul 时区和 09:00-15:30 常规交易时段。
- **Korean market session**: Adds the Korea market configuration with the Asia/Seoul timezone and a 09:00-15:30 regular session.
- **表现色彩语义**: 新增涨、跌、平表现色彩 token，区间工具栏展示首尾收盘价收益率。
- **Performance color roles**: Adds positive, negative, and neutral performance tokens; the range toolbar now shows first-to-last close return.

### 🐛 Bug 修复 / Fixes
- **指标坐标轴与 MACD**: 根据显示范围推导小数精度并归零舍入值；MACD 柱与坐标轴共用已提交范围，修复小幅波动显示为 `-0.00` 及坐标不一致的问题。
- **Indicator scale and MACD**: Derives decimals from the display range and normalizes rounded zero values. MACD bars share the committed scale range, fixing `-0.00` output and mismatched coordinates.
- **成交量坐标轴刻度**: 从已提交的帧投影发布可见成交量范围，恢复活动成交量窗格的动态刻度。
- **Volume axis ticks**: Publishes visible volume ranges from the committed frame projection, restoring dynamic ticks for active volume panes.
- **亚洲市场 MACD 颜色**: 校正基础主题的正负柱配色，使红涨绿跌设置得到正确的 MACD 柱颜色。
- **Asia-market MACD colors**: Corrects base positive and negative histogram colors so the Asia-market setting produces the expected MACD colors.
- **类型与构建契约**: 修复 vue-tsc 合约错误，并由 Core exports 推导构建别名，避免预览、Electron 与测试环境发生路径漂移。
- **Type and build contracts**: Fixes vue-tsc contract errors and derives build aliases from Core exports to prevent path drift across preview, Electron, and tests.

### 🏗️ 架构与重构 / Architecture & Refactoring
- **指标状态与 Worker 协议**: 指标结果统一接入 ChartStateKernel，以数据和配置 revision 标识结果来源；Worker 协议精简为纯计算结果并升级至 v4，渲染器改读帧级已提交状态。
- **Indicator state and Worker protocol**: Routes indicator results through ChartStateKernel using data and config revisions as source identity. The Worker protocol now returns pure calculation results at v4, and renderers read committed frame-level state.
- **指标配置模型变更**: 指标运行时描述符以 `defaultParams` 取代 `defaultConfig`；展示选项改由 `presentation.defaultOptions` 声明。
- **Indicator configuration model change**: Runtime descriptors replace `defaultConfig` with `defaultParams`; presentation options are declared through `presentation.defaultOptions`.
- **绘图与语义配置 API 变更**: 移除旧 DrawingToolType 别名；移除 `semanticConfig` 和 `SemanticChartController`，改用 `toKLineChartProps` 将语义 JSON 映射为图表属性。
- **Drawing and semantic configuration API changes**: Removes legacy DrawingToolType aliases, `semanticConfig`, and `SemanticChartController`; use `toKLineChartProps` to map semantic JSON into chart props.
- **市场数据 Buffer 收敛**: K 线与分时 Buffer 统一由 SeriesRepository 管理；比较序列可随主图可见范围继续加载历史数据。
- **Market-data Buffer consolidation**: SeriesRepository now owns K-line and timeshare Buffers, and comparison series can continue history pagination as the main chart requires earlier ranges.
- **React 绑定改为 Web Component 适配器**: React 包改用 SSR 安全的 KLineChartWC；不再导出直接 Core 图表工厂、hooks 或 KLineChart 组件。
- **React bindings use the Web Component adapter**: The React package now uses the SSR-safe KLineChartWC and no longer exports the direct-Core chart factory, hooks, or KLineChart component.
- **渲染后端目录调整**: WebGPU、WebGL2 与 Canvas2D 后端迁入 `rendering/backend`，并更新模块边界与渲染管线说明。
- **Rendering backend organization**: Moves WebGPU, WebGL2, and Canvas2D backends into `rendering/backend` and updates rendering boundaries and pipeline documentation.

### 📚 文档 / Documentation
- **指标与渲染模块文档**: 新增 indicators 模块 README，更新渲染管线文档与模块 README，说明边界、数据流和扩展方式。
- **Indicator and rendering module docs**: Adds the indicators module README and refreshes the rendering pipeline and module README with boundaries, data flow, and extension guidance.
