# v0.10.0

## 相比 v0.9.6 的变更 / Changes since v0.9.6

### ✨ 新功能 / Features
- **对比视图（Percent-Normalized）**: 以百分比归一化的折线渲染对比视图，Y 轴拟合可见折线极值，图例展示主标的
- **comparison view (percent-normalized)**: render comparison rows as percent-normalized lines, fit the y-axis to visible line extremes, and show the main symbol in the legend
- **游标历史状态**: 新增游标历史状态（`feat(data)!: add cursor history status`）
- **cursor history status**: add cursor history status to the data layer
- **FinShare 游标分页加载**: 新增 FinShare 基于游标的 bar 分页加载
- **FinShare cursor-based bar loading**: add cursor-based paged bar loading for the FinShare source
- **基于能力的数据源路由**: 实现 capability-based 数据源路由，V1 源级能力声明契约与可流转错误码
- **capability-based source routing**: implement capability-based source routing, plus a V1 source capability declaration contract and transportable error codes
- **可见重试进度**: 加载 K 线数据时展示可见的重试进度
- **visible retry progress**: surface visible retry progress while loading K-line data
- **tradingview / baostock 源注册**: 通过 V1 provider 注册 tradingview 与 baostock 数据源
- **register tradingview and baostock sources**: register the tradingview and baostock sources via the V1 provider
- **聚合源会话记忆**: 符号选择器在会话内记忆聚合源 tab 选择
- **aggregation source session memory**: remember the aggregation source tab selection within a session
- **聚合源对话框打磨**: 优化聚合源对话框交互
- **polish aggregation source dialog**: refine the aggregation source dialog interactions

### 🐛 Bug 修复 / Fixes
- **对比视图 Y 轴拟合**: 对比视图 Y 轴拟合到可见折线极值，避免折线超出可视区间
- **fit comparison y-axis**: fit the comparison view y-axis to visible line extremes so lines stay in view
- **图例标的解析**: 对比行按标的身份解析，主标的正确显示在图例中
- **resolve legend rows by identity**: resolve comparison legend rows by symbol identity so the main symbol renders correctly
- **统一错误契约**: 将数据源 fetch 失败统一收敛到 KLineChartError 契约
- **unify fetch failures**: unify data source fetch failures into the KLineChartError contract

### 🏗️ 架构与重构 / Architecture & Refactoring
- **数据层按领域重组**: 数据层按领域文件夹重组，补充数据层职责文档
- **reorganize data layer by domain**: reorganize the data layer by domain folders and document its purpose, responsibilities and structure
- **移除 DataBuffer 旧适配器**: 移除 DataBuffer 中遗留的 setFetcher 日期适配器
- **remove legacy DataBuffer adapter**: remove the legacy setFetcher date adapter from DataBuffer
- **gotdx 迁移 V1 Provider**: gotdx 迁移到 V1 provider 抽象
- **migrate gotdx to V1 provider**: migrate the gotdx source to the V1 provider abstraction
- **更新依赖与开发文档约定**: 更新依赖与开发文档约定
- **update dependencies and dev docs**: update dependencies and development documentation conventions
