# v0.9.6

## 相比 v0.9.5 的变更 / Changes since v0.9.5

### ✨ 新功能 / Features
- **行情数据 V1 Provider 模型**: 定义前端侧 instrument / capability / query / series 契约，支持 provider 注册与运行时数据源配置（#116）
- **market data V1 provider model**: define frontend-owned instrument, capability, query and series contracts, plus provider registration and runtime source configuration (#116)
- **gotdx 接入 V1 协议**: 通达信数据源与聚合源健康检查统一走 V1 协议，保留旧 fetcher 兼容路径
- **gotdx via market data v1**: route the GOTDX provider and aggregation-source health checks through the unified V1 protocol while preserving legacy compatibility
- **V1 Provider 迁移完成**: 图表加载、分时、搜索与数据源配置全部经 MarketDataProvider 路由，移除旧 GOTDX fetcher 路径（#116）
- **complete V1 provider migration**: route chart loading, timeshare, search and source configuration through MarketDataProvider, removing the obsolete GOTDX legacy fetcher path (#116)
- **KDJ J 线**: 新增 KDJ 指标 J 线
- **KDJ J line**: add the KDJ J line

### 🐛 Bug 修复 / Fixes
- **内置指标注册保留**: 修复构建时内置指标注册被清理的问题
- **preserve builtin indicators**: keep builtin indicator registrations intact across builds
- **分时均价线区间**: 分时价格区间计算包含均价线，避免均价线超出可视区间
- **timeshare average line range**: include the average line in the timeshare price range
